# 02 — 线框与交互路径

> **系统栏约定（it-002 O2）**：四页根布局统一套 `Modifier.pageInsets()`
> （状态栏 + 手势导航条 insets）——下文所有页的顶行均指安全区之内的顶行。
> **视觉基线（it-006）**：W1–W4 页面与交互采用中性黑白灰 token；功能文字为 Sans，展示标题只少量使用 Serif；中文不加字距。

## W2 显影台（DEVELOP）

```
┌──────────────────────────────┐
│ ← DEVELOPING     标准 · 浮现  │
│                              │
│         ┌──────────┐         │
│         │  显影中的   │         │ ← DevelopCard，确定性不规则药膜扩散：
│         │  相纸卡片   │         │   自槽口有重量地升起，轻微一次回正
│         └──────────┘         │ ← 卡宽 = min(可用宽, 槽高÷1.2)（it-002 O3）
│         ▬▬▬▬ 槽口 ▬▬▬▬        │ ← 深色圆角条，画在卡片之上
│                              │
│                           63% │ ← 百分比读数（石墨/银灰 accent）
│  潜影      浮现      定影       │ ← 阶段名按各自阶段宽度居中，当前阶段 ink、其余 faint
│ ▬▬|▬▬|▬▬▬●▬▬▬▬|▬▬▬▬▬▬▬▬▬▬▬ │ ← 自绘药水刻度条（ChemicalGauge，it-007 M1）
│ 让回忆慢慢浮出来                │ ← 随进度切换阶段短句（文案按模式分套）
│ 轻轻晃动，亲手唤醒这张相纸       │ ← 或提示拖动刻度条倒放
└──────────────────────────────┘
```

刻度条：未显影段 1.5dp hairline 细线、已显影段 2.5dp 实心 accent；每 5% 短刻度、每 25% 长刻度、
阶段分界最长且带分界标记；手柄 8dp 圆点 + 2dp 纸色描边（拖动放大到 12dp），触控区 44dp。
按下暂停 → 拖动/点击 seek → 松手续播，支持倒放（原 Material Slider 已移除）。
出纸动画按模式分派：拍立得自槽口升起（快推—微顿—缓出，槽口下压回位）、
数码原地开机（0.96→1 缩放 + 扫描线自上而下）、胶片自片盒口横向卷出（片盒口竖条）。

显影中段的过程动效（it-008，全部 progress 确定性、倒放一致、85% 后归零）：
化学工艺模式（拍立得/胶片）照片区内有种子气泡自下而上浮起（暗晕+白芯）与随显现前沿推进的
软湿光带；数码模式不给（网格显现 + 扫描线已是其语言）。阶段陪伴文案换句 fade+rise 过场，
百分比读数用 tabular figures。

定影到达 → Confirm 触感 + 落定轻弹 + 600ms 对角光泽扫（并发，750ms 内完成）→ 750ms 后 crossfade 进 W3。
签名区（常规衬线作品标题/灰阶日期/水印）恒在浅灰白卡面内；标题最多两行；标题域 0.52w ≤ 日期域 0.54w（互斥）。

## W4 设置页（SETTINGS）

返回 + 「设置」标题（安全区之下）；三张 Surface 圆角卡：
显影速度（Radio 三档，带秒数）/ 互动（甩一甩、水印默认值两个 Switch 行）/ 关于（版本 + 离线声明）。

## 交互路径

- W1 → W2：任一选图入口；W2 → W3：定影自动；W3 → W1：返回/再洗一张（会话即弃无确认，未保存无损失）。
- 显影模式在 W1 选择、进入 W2 即生效并跨会话保留；W3 不提供改模式入口（模式属于整次显影会话，
  换模式需返回 W1 重选）。
- W1 ⇄ W4：顶行 ⚙（唯一入口）；全局返回键按此栈回退。
- 消息：保存成功 snackbar（带「分享」action）；错误走单弹窗（不套弹窗）。
- 导出中：进度条 + 「冲洗中 n%」位于存图/存视频正上方，不需滚动即可见（US-10）。
- W3 切换分享画幅会立即重绘相同布局的预览；切换后旧保存结果失效，避免预览与分享文件错配。
- W3 选择照片风格立即更新预览；切换后旧图片/视频导出失效；新照片从原色开始，风格同步用于静图和视频。
- W3 每次显影会话首次到达时预览卡有亮相入场（rise 16dp + fade + pop，it-008）；消息 snackbar 用
  surface + hairline 边框的编辑式皮肤（非 M3 默认深色浮层）。
