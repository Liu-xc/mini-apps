# it-008 — 显影过程动效精修与上架级质感收口

状态：**实施完成（2026-09-29）**
日期：2026-09-29

## 背景与动机

it-007 后三显影模式闭环已经稳定，Leo 用过成包后的反馈：**效果不错，但整体仍像 MVP，不像能上架的应用商店产品**。两条明确要求：

1. **显影过程要更多精致动画**——现在 W2 除了照片按曲线变化、一次性出纸与落定轻弹外，显影中段（8 秒的主体时间）画面是「安静地等」，缺少化学过程该有的生命感。
2. **UI 整体再精调打磨**——冷启动白闪色不对、应用图标还是 it-006 改版前的墨绿+橙暖色身份、控件状态切换全部瞬跳、W1/W3 无入场编排。这些单看都是小事，叠起来就是「工程样板」和「成品」的差别。

对照基线（根 DESIGN.md）逐条盘点出的债务：图标/窗口底色与 it-006 黑白灰身份脱节（P0 级违和）；darkroom 05 自设「无入场 stagger」远低于基线允许（20–24ms/项、首屏允许 >200ms 编排）；阶段文案、chip 选中、样片按压全部硬切。

## 涉及的用户故事

- **US-2 显影**（补强）：显影中段加入 progress 确定性的药液气泡与前沿湿光，过程有生命感且倒放一致。
- **US-11 暗房仪式**（补强）：定影落定在轻弹之外加一次光泽扫过（定妆感）；阶段文案换句有过场。
- **US-14 显影模式**（补强）：过程动效按模式差异化——气泡/湿光只给化学工艺（拍立得/胶片），数码屏不给。
- 新增 **US-15 上架质感**：图标与窗口底色对齐黑白灰身份；W1 首次冷入场 stagger 编排、W3 成片亮相编排；控件状态过渡（chip 边框、样片按压、snackbar 编辑式）全部消灭瞬跳。

## 体验方案

### M1 — 显影过程动效（W2，全部 progress 确定性，倒放/seek 严格一致）

所有过程动效是「照片正在显影」这同一个运动焦点的一部分（都画在照片区内、都由 progress 驱动），维持基线「一屏自主运动 ≤1」的解释：运动焦点仍是卡片。

1. **药液气泡（ChemicalBubbles）**：显影中（15% 起、70% 峰、85% 归零）照片区内 12 个种子气泡自下而上浮起、横向微摆，到前沿自然消散。灰阶低透明（白 ≤16%），半径 1.5–3.5dp。位置 = 纯函数 `f(i, progress)`——暂停即冻结、倒放倒退，与「药水条倒放重看」的化学隐喻一致。数码模式不画（屏幕无药水）。
2. **前沿湿光（WetBand）**：一条随显现前沿推进的软亮带（白 ≤10%），像药水正在浸湿乳剂。胶片 SWEEP 前沿公式精确对位（`frontX = -0.22 + reveal·1.40`）；拍立得 CHEMICAL 用从滚轴入口（左下）向右上推进的对角近似。数码不给（开机扫描线已是其语言）。定影段淡出。
3. **定影光泽扫（GlossSweep）**：progress 首次抵达 100% 时，600ms 一次性对角高光带扫过整卡（峰值白 10%），与既有落定轻弹、Confirm 触感同拍——庆祝预算 ≤900ms、只挂在定影落定（基线 §3 合规）。
4. **阶段文案过场**：陪伴文案换句（每阶段一次）由硬切改为 fade+rise 6dp（160ms）；百分比读数加 tabular figures（数字跳动不再抖版）。

### M2 — 上架级收口

1. **图标重绘（中性石墨身份）**：背景墨绿 `#1E1F1A` → 中性 `#1B1B1B`；相纸米白 → `cardPaper #FBFBFA`；绿色山景/橙色落日/橙日期章 → 灰阶「显影中」构图（左下已显影灰阶山景 + 右上乳剂未显影浅灰 + 石墨日期章）——把产品核心隐喻直接画进图标。monochrome 同源（已有 themed icon 接线）。
2. **窗口底色对齐**：`window_background` 浅色 `#F6F4EB` → `#F3F3F1`（it-006 paper），夜间对齐 `#151515`——消灭冷启动从米白闪到灰纸的跳变。
3. **W1 冷入场编排（仅首次）**：标题组 / 主按钮组 / 模式行 / 样片行 / footer 五组 stagger 24ms、每组 fade 220ms + rise 14dp。flag 挂在导航壳（跨屏存续）：从 W2/W4 返回不重放（基线「二次进入走快路径」）；Activity 重建不重放。reduceMotion 全跳过。darkroom 05 的「无入场 stagger」自设预算更新为「仅 W1 首次冷入场」。
4. **模式 chip 选中过渡**：边框宽 animateDp 150ms smooth；选中瞬间示意图 pop 1→1.06→1。字重不动画（FontWeight 过渡会抖，保留瞬切）。
5. **样片卡按压反馈**：pressed scale 0.97、松手 pop 回弹；触感不加（基线 §4）。
6. **W3 成片亮相**：预览卡 rise 16dp + fade + pop 入场（每次新会话到 W3 播一次），到位后 GlossSweep 扫过预览一次——与 W2 定影光泽呼应，「刚定妆的相纸」。
7. **Snackbar 编辑式**：surface 底 + hairline 边框 + 14dp 圆角 + ink 文字，替换 M3 默认深色浮层。

不动：导航 crossfade 220ms（基线值）、零音效（ADR-002）、触感点位（§4 基线）、所有文案。

### 纯函数真源与测试

新增 `develop/DevelopFx.kt`：气泡相位/半径/透明度、湿光位置/强度、阶段包络——全部 `(mode, progress) → 参数` 的确定性纯函数，单测锁：同输入同输出、85% 后全归零（不污染定影与导出）、SWEEP 对位公式。预览端（Compose Canvas）只消费这些函数；导出端（PhotoCardPainter/视频）不画过程动效（成片在 progress=1，包络已为零，两端终态天然一致）。

## 验收标准

- AC1 W2 三模式显影全程无回归：进度/倒放/seek 与 it-007 行为一致（气泡、湿光随 progress 严格可逆）。
- AC2 气泡与湿光只在拍立得/胶片出现；数码模式 W2 无气泡无湿光；三种模式 85% 后画面与无动效版本逐像素一致（导出/预览不受污染）。
- AC3 定影落定：轻弹 + 光泽扫 + Confirm 触感同拍发生一次；seek 回退后再到 100% 重放（与既有 pulse 行为一致）。
- AC4 图标：浅色壁纸下 launcher 图标为新灰阶「显影中」构图；冷启动窗口底色与 W1 纸面同色无闪变（浅/深色分别验证）。
- AC5 W1 首次冷入场有 stagger 编排；从 W2/W4 返回无编排；系统「移除动画」下全部瞬时落位。
- AC6 chip 选中、样片按压、snackbar、阶段文案切换均有过渡无瞬跳；全部动效过 DESIGN.md §3 预算对表。
- AC7 单测全绿（56 + DevelopFx 新增 ≥6），三模式 AVD 走查 W1–W3 浅/深色无 P0/P1。
