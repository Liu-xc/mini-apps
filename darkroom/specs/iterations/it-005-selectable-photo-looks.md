# it-005 — 可选照片风格与成片质感

状态：**实施完成（2026-09-28）**
日期：2026-09-28

## 背景与动机

it-004 建立了稳定的显影过程、纸面卡片与三种社交画幅，但所有成片仍共用同一种颜色和质感。用户希望在原有暗房气质上继续打磨，并能为不同照片选择更有辨识度、适合分享的效果风格。

当前 W3 预览、静图导出和视频逐帧最终都经过 `PhotoCardPainter`；显影台由 Compose 使用 `DevelopVisual` 绘制。新增风格需要复用确定性参数，并保证 W3 预览、导出图片和导出视频最后一帧一致。

## 涉及的用户故事

- **US-4 成片卡片**（补强）：为照片选择有辨识度、但不过度修饰的成片风格。
- **US-5 保存与分享**（补强）：选择风格后，分享预览和保存的静态图片一致。
- **US-6 视频导出**（补强）：视频沿用所选风格，最后一帧与 W3 预览和静态导出一致。
- 新增 **US-12 可选照片风格**：用户可预览并选择适合这张照片的成片观感。

## 体验方案

### W3 风格选择

- 在成片预览下方加入横向风格选择列，放在标题/日期/水印编辑区之前；每项包含同一张照片的微型效果预览、风格名称和清楚的选中态。
- 选项可横向滚动，单项触控目标不小于 44dp；选中后立即更新大预览，给出即时反馈，不打开额外弹层。
- 风格作为会话内的成片选择，新选照片时回到「原色」默认值；不改 `CardSpec` 文件/存储格式，不新增设置页。

### 内置风格

| 风格 | 观感 | 处理边界 |
|---|---|---|
| **原色**（默认） | 保留 it-004 当前成片 | 现有输出不变，作为一键回到原始观感的选项 |
| **暖片** | 温暖的高光与略柔的暗部，细颗粒 | 肤色自然，不叠加橙色遮罩，不压掉阴影细节 |
| **银影** | 银盐黑白、层次清晰，保留细节 | 不做纯黑/纯白剪切，颗粒克制 |
| **青幕** | 低饱和冷影与微暖高光，电影式纵深 | 不整体套蓝，不损失肤色可读性 |
| **柔光** | 高光处轻微乳化晕光、整体柔和 | 晕光只沿亮部扩散，避免全图泛白或模糊主体 |

风格调节照片本身的色调和有限的胶片质感，不增加贴纸、漏光素材、边框装饰或多余文案。颗粒和晕光保持确定性，同一张图在重绘、seek 和导出时不闪变。

### 动画与导出

- W2 继续呈现 it-004 的药膜扩散和真实感，不在显影过程中途切换后期风格。
- W3 选定的照片风格应用到分享视频的每一帧；显影遮罩和相纸运动保持原有时间线。静态成片、视频结尾与当前 W3 大预览使用相同照片处理参数。
- 所有处理离线完成，不请求新权限，不引入第三方依赖。高光晕光采用有界半径和低强度，避免视频逐帧处理造成明显卡顿或内存峰值。

## 验收标准

- **AC1 可辨识**：五种风格名称与缩略预览清楚可见；每种对同一照片的差异易辨认，仍符合 `DESIGN.md` 和 darkroom 的纸面/编辑式基线。
- **AC2 选择反馈**：横向浏览和选择均可用；选择后 W3 大预览立即更新；选中状态不只依赖颜色表达，目标 ≥44dp。
- **AC3 视觉克制**：各风格保留主体细节和可读性；「原色」与 it-004 当前成片效果一致；柔光不造成显著泛白或主体失焦。
- **AC4 输出一致**：每种风格下，W3 预览、静态图片和视频最终帧在卡面、画幅、文字、色调和颗粒上相符；视频前段使用相同风格处理照片。
- **AC5 确定性**：相同照片、风格和显影进度重放无随机闪变；静图重复导出视觉一致；风格切换不影响显影进度、标题、日期和画幅。
- **AC6 状态与兼容**：新选照片默认「原色」；既有导出尺寸、分享链路、CardSpec 和离线要求不变；无障碍减弱动态仍可完成流程。
- **AC7 回归**：五种风格分别检查 1:1、4:5、9:16 预览与导出；检查浅色/深色主题、横向选择、视频最终帧与导出性能；同步更新常青 spec、CHANGELOG 和本迭代验证记录。

## 技术方案草案

- 新增纯 Kotlin `PhotoLook` 预设及其有界参数（色调矩阵、对比度、颗粒、暗角、可选高光晕光）；默认参数映射到现有原色绘制路径。
- `PhotoCardPainter.paintShareFrame` 接收所选 `PhotoLook`，让 W3 缩略图/大预览、静图和视频逐帧共用处理入口。缩略预览使用同一套参数，不另造滤镜实现。
- `DarkroomViewModel.UiState` 持有会话内选择；切换风格使已保存产物状态失效，避免把上一种风格的已导出文件误认为当前结果。
- 视频导出参数携带所选风格；逐帧稳定复用确定性颗粒种子与晕光中间结果，避免每帧分配大图或重新生成随机纹理。
- 不持久化风格选择、不修改 `CardSpec` 和导出格式、不增加依赖。若晕光实现需要高成本全尺寸中间位图，则收窄效果边缘和半径，优先保证导出稳定。

## 里程碑

- **M1 风格参数**：定义五种稳定预设，原色路径与现有成片保持一致。
- **M2 W3 选择与预览**：加入可滚动选择列和同步大预览。
- **M3 导出同步**：静态图片及视频逐帧、最终帧应用所选预设；检查性能和画幅一致性。
