# it-010 — 小而美布局收口与创作选项系统

状态：**实施完成（2026-09-29）**
日期：2026-09-29

## 背景与动机

Leo 对 v0.2.4 的两条反馈：

1. **整体布局杂乱、交互细节不到位、缺少「简洁大方小而美」的感觉**——W1 头部两行标签信息冗余、
   W3 分组样式不一（有的带边框卡有的裸行）、可点项缺统一按压反馈。
2. **要更多创作组合空间**——点名相纸（拍立得）、字体字号、脚注这些卡面信息应可自定义/可选，
   让用户有组合余地，而不是千篇一律的白框+衬线+固定水印。

## 方案

### M1 布局与交互减负（小而美 pass，手术式）

- **W1 头部合并**：`DARKROOM · 私人暗房` 一行 micro 标签（去掉第二行小字），信息不重复。
- **W4**：水印开关行移除（语义并入 W3 脚注输入），互动卡只剩甩一甩。
- **统一按压反馈**：新增 `Modifier.pressScale(source)`（按下 0.97、松手 pop、减弱动态不缩放），
  相纸/字体/字号等全部选择项接入。
- W3 分组统一为「标题行（左 title、右当前值 hint）+ 内容行」一种 section 模式，
  节间距统一 14dp（原 8/12/14 混用）。

### M2 创作选项系统（US-16 相纸 / US-17 字体字号脚注）

| 维度 | 取值 | 说明 |
|---|---|---|
| 相纸框型 | 经典白 / 暖米 / 墨框 / 灰板 | 仅拍立得可选（数码/胶片无相纸概念）；配色真源 `CardPalette.forFrame`，四款印字对比均 ≥ 打印可读线（单测锁 WCAG ink≥7 / faint≥3），预览/静图/视频三端一致 |
| 标题字体 | 衬线（默认）/ 黑体 | 双渲染端 typeface 同步切换 |
| 标题字号 | 小 0.85 / 标准 1.0 / 大 1.16 | 对 `CardLayout.titleSize` 的比例，限幅防溢出（单测锁 0.8..1.2） |
| 卡脚脚注 | 自定义文案（默认「显影 DARKROOM」，空 = 不印） | 替代原水印开关；超宽按域缩字；故事画幅品牌句随脚注非空打印 |

**持久化语义与显影模式一致**：上一次 W3 的选择即下一次会话的默认（footer_default 含旧
watermark_default=false → 空串迁移）；会话内即时生效，换相纸使旧导出失效（同风格切换语义）。
启动期回填用一次性 `first()` + `optionsChosen` 挡旧快照（沿用 it-007 模式回冲教训）。

**W3 信息架构（自上而下）**：顶行 → 大预览（it-009）→ 预览 caption → 照片风格 → 相纸（拍立得）
→ 标题字体（衬线/黑体 ｜ 小/标准/大）→ 卡面编辑（标题/日期章/脚注三行）→ 分享画幅 → 导出。
