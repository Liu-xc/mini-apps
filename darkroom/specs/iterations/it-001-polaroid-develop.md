# it-001 — 显影（darkroom）：拍立得显影工具（MVP）

状态：**提案待确认（v2，2026-09-27 增补视频导出 + 卡片结构）**
日期：2026-09-27

## 背景与动机

源自 2026-09-27 脑暴（数字胶卷方向的工具化落地）： Leo 想要一个**情绪价值优先**的小工具——
传入一张图片，像拍立得相纸一样**慢慢显影**：从一张空白灰相纸开始，药水浸润、影像浮现、
定影定格，然后「打印」成一张带白框和日期章的实体感照片，可保存/分享。

核心不是修图，是**仪式感**：慢、有触感、有声音、有惊喜。反精修——照片本来就是拍完就有的，
我们把它重新「洗」一遍给你看。

**v2 增补（Leo）**：显影的**过程**本身就是最强的传播素材——要支持**导出为视频**
（显影动画完整 playback，发朋友圈/小红书即内容），且成片是**结构化卡片 UI**，
图、视频双形态都方便分享。

- 名字：**显影**（目录 `darkroom`）——动词即产品，一句「把回忆洗出来」讲完定位。
- 平台：**Android + Compose**（仓库主线栈；显影动画吃 RenderEffect/graphicsLayer、
  甩一甩吃陀螺仪、触感吃 Haptics、视频导出吃 MediaCodec，原生最合适）。

## 体验设计（动效基调）

显影全程约 8–12 秒（可调），三阶段曲线：

| 阶段 | 进度 | 画面 | 声音/触感 |
|---|---|---|---|
| P1 潜影 | 0–15% | 相纸灰绿暗哑，隐约负片感 | 出纸摩擦声「沙——」 |
| P2 浮现 | 15–70% | 影像自中心向外晕开，低饱和渐显色，边缘漂移模糊 | 轻微药水白噪 |
| P3 定影 | 70–100% | 对比/锐度归位，颗粒沉降，最后轻微「呼吸」+ 定格 | 「嗒」+ 触感一下 |

交互彩蛋：
- **甩一甩**：真甩手机（陀螺仪）或手指甩动卡片，显影进度推进一段——「Shake it like a Polaroid
  picture」的梗，每次甩动给液体晃动般的进度反馈与触感。
- **药水条**：显影进度条做成药水浸润刻度，可拖动倒放/重看显影全程。
- **吐片**：打印时照片从槽口缓缓吐出（含电机声），像从相机里抽出来。

### 成片卡片（结构化卡面）

所有输出形态共用**同一张卡片结构**（单一组件 `PhotoCard`，一处定义、四处渲染：
显影台相纸 / 成片页预览 / 导出位图 / 视频帧）：

```
┌─────────────────────┐
│                     │
│      显影完成照片      │  ← 相纸区（方形，白边等宽）
│                     │
├─────────────────────┤
│  手写标题            │  ← 签名区：手写体一句话（可空）
│  1988 07 21  ● 显影  │  ← 橙色日期章 + 卡脚小字（App 签名，可关）
└─────────────────────┘  ← 白框下边更宽（经典拍立得比例），纸张纹理+轻微色偏
```

卡片字段（`CardSpec`）：照片 · 手写标题 · 日期章（默认拍摄日，可改任意日期）· 相纸类型 ·
卡脚水印开关。**所见即所得**：预览、位图、视频由同一 `CardSpec` + 同一渲染函数驱动。

### 视频导出（分享即内容）

- 内容 = 显影全程 playback：0.5s 空白相纸起手 → 三阶段显影 → 定影定格 **hold 1.5s** 收尾。
- 规格：H.264 MP4，30fps，1080×1080（方形）/ 1080×1350（竖版）两档；时长 ≈ 显影档位时长 + 定格。
- 音轨（spike 后定）：出纸/药水/定影三段音效按时间线混入；若编码链路超预算，降级为无声视频（M3 补）。
- 导出入口与位图导出并列：成片页「存图片 / 存视频」双按钮。

## 用户故事

- **US-1 选图**：相册选图或拍照，方形构图裁切（可拖动/缩放取景框）。
- **US-2 显影**：相纸吐出后从潜影到定影的三阶段显影动画；显影速度可调（慢洗 12s / 标准 8s / 快显 4s）；
  药水条可拖动重看任意时刻。
- **US-3 甩一甩**：甩动手机或甩动卡片可加速显影（单次推进 8–15% 进度），带液体晃动反馈与触感；
  也可在设置中关闭。
- **US-4 成片卡片**：显影完成进入结构化卡面（相纸区/手写标题/日期章/卡脚水印），
  卡面字段全部可编辑（标题、日期、水印开关）；吐片动画后展示成片页。
- **US-5 保存与分享**：成片以含完整卡面的位图保存到相册（MediaStore），可直出系统分享面板。
- **US-6 视频导出**：一键把显影全程导出为 MP4（规格见上），保存到相册并可直出分享面板；
  导出过程有进度反馈，完成后可直接预览播放。
- **US-7 全离线**：无网络、无账号；所有处理（含视频编码）在本机完成。

非目标（MVP）：不做滤镜/修图编辑器（不是 Snapseed）；不做 30 天延迟胶卷模式（后续迭代可选做
「胶卷」玩法：一卷 24 张、隔天显影）；不做云同步与社交；不做多模板商城（相纸类型 M1 先一种经典款）。

## 验收标准

- AC1 显影动画三阶段肉眼可辨（灰绿潜影 → 中心晕开渐显色 → 定影锐化），全程无掉帧（60fps 走查）。
- AC2 药水条拖动可在任意进度暂停/倒放/重看，画面与该进度一致（确定性曲线，状态机可单测）。
- AC3 甩一甩实测生效：真甩（陀螺仪）与手势甩动均推进进度并有触感；设置可关。
- AC4 卡片三处渲染一致：显影台相纸、成片页、导出位图由同一 `CardSpec` 驱动，字段改动即时全量生效。
- AC5 打印导出：成片含完整卡面（白框+手写标题+日期章+纹理），导出分辨率不低于原图短边；
  MediaStore 可见、分享面板直出。
- AC6 视频导出：生成的 MP4 可被系统播放器正常播放，30fps 无丢帧观感、起手空白与结尾定格齐全，
  画面观感与预览一致；1080 方形与竖版两档可用；导出有进度反馈不卡 UI。
- AC7 吐片动画 + 出纸/定影音效 + 关键帧触感齐备；系统静音时无声（尊重铃声流）。
- AC8 断网/无权限降级可用：未授相册权限时给拍照或示例图入口；任何一步不崩溃。
- AC9 构建 + 单测绿（显影曲线状态机、进度↔视觉参数映射、CardSpec→渲染参数、卡面布局计算、
  导出时间线（帧序列/音轨时间点））。

## 技术方案草案

- **栈**：Kotlin + Compose，BOM 对齐 wardrobe/eats；零新增第三方依赖（裁切/编码全用系统能力）。
- **显影渲染**：`Animatable(developProgress)` 单一进度源 → **确定性映射函数**
  `developSpec(progress) → DevelopVisual`（饱和度/对比度/色温三段曲线 + 模糊量 + 颗粒/暗角强度）
  → RenderEffect 链（Blur + ColorMatrix）+ graphicsLayer；颗粒用预生成噪声图多层叠加
  （不依赖 API 33 AGSL，minSdk 31 可跑）。
- **卡片单一渲染器**：`CardSpec`（数据类）→ `PhotoCardRenderer` 同一套函数三输出：
  ① Compose 实时预览（graphicsLayer）② 位图合成（软件层 Canvas 重绘，所见即所得）
  ③ 视频逐帧（按 30fps 采样 `developSpec(t)` 离线重绘）。
- **视频编码**：`MediaCodec` surface 输入 + `MediaMuxer` 封装 H.264；逐帧把确定性画面
  渲到编码器输入 surface（后台线程，进度回调），不录屏、不受实时帧率影响；
  音轨（若做）：现有 SoundPool 资产解码为 PCM 按时间线混音 → 独立音轨 mux；
  **spike 先行**：先用示例帧验证 MediaCodec+MediaMuxer 链路与耗时（预估 10s 视频编码 <10s）。
- **分层**：`develop/`（显影引擎：进度状态机 + 视觉参数映射，纯 Kotlin 可单测）·
  `card/`（CardSpec + PhotoCardRenderer）· `export/`（位图合成 + 视频编码器）·
  `ui/`（选图、显影台、成片页）· `data/`（设置 + 成片记录，MVP 文件存储即可，暂不接 libs/store）。
- **触感/声音**：对齐根 DESIGN.md 触感基线；音效走 SoundPool，跟随系统静音。
- **minSdk 31**（RenderEffect），targetSdk 对齐仓库现状——若需覆盖更老设备，备选 ColorMatrix
  软件路径，待确认。

## 里程碑

- **M1 显影核心**：选图→裁切→显影台三阶段动画 + 药水条重看 + 编码链路 spike（最难的先做）。
- **M2 卡片与导出**：结构化卡面（编辑字段）+ 吐片动画 + 位图导出分享 + **视频导出**。

## 验证记录

### 2026-09-27 UI 审查 + 功能自测（ui-audit 全流程，交付见 `reports/darkroom-ui-audit/`）

**P0 hotfix（已随审查落盘）**：`AndroidManifest.xml` 缺 `VIBRATE` → `Haptics.confirm`（`platform/Haptics.kt:28`）
在定影落定 `DarkroomViewModel.kt:228 onFixedReached` 抛 `SecurityException`，**每次显影到 100% 必崩**
（logcat 复现 3 次，force-finish）。修法：manifest 补 `<uses-permission android:name="android.permission.VIBRATE"/>`
（normal 权限、安装即授予，不破「零危险权限」策略）；补丁后全流程回归通过（定影→成片 crossfade、导出完成触感不再崩）。

**实测通过（11 项）**：三阶段显影（7%/54%/97% 可辨、线性时钟）· 药水条 seek+松手续播（82%→51%→续播）·
甩一甩 boost（传感器注入 t=3.1s 达 74%，自然上限 38.6%）· 存图片（`Pictures/显影` 119KB）·
存视频（`Movies/显影` 11.1MB）· 分享面板直出 · Photo Picker/相机/示例三入口 · 设置 DataStore 落盘 ·
顶行触摸死区定位（StatusBar 窗口 128px）。

**遗留问题（P1×5 / P2×5，证据与改版线框见审查报告）**：
- P1 速度档不生效：`DarkroomViewModel.kt:72` 固定 `DevelopClock(STANDARD)`，prefs 只进 UI 标签（US-2 12s/4s 失效，导出时间线与预览不一致）
- P1 四页页头无 statusBars insets：嵌状态栏窗口（128px），⚙/← 中心点（y=111）点击死区
- P1 卡面几何：W2 白框被 weight 槽高裁切（1028 vs 1158px）→ 日期章/水印溢出并撞进度读数；W3 标题域（右界60%）与日期章域（左界58%）交叉 → 字形重叠
- P1 成片页首屏 CTA（存图/存视频 y2343–2392）被手势条压住、导出进度条排在首屏外
- P2 槽口拟物对比度不足不可见 · W1/W4 底部约 800px 留白 · snackbar 遮挡 CTA 行
