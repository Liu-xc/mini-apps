# it-006 — 黑白灰编辑式视觉与字体重整

状态：**实施完成（2026-09-28）**  
日期：2026-09-28

## 背景与动机

it-004 和 it-005 完成了暗房显影仪式、分享构图与可选照片风格，但现有暖米纸、墨绿深色主题、橙色日期章，以及成片上的斜体标题和等宽日期字，组合起来更像随意的复古装饰，缺少统一、克制、适合分享的高级感。用户明确要求全应用转为黑白灰，并重新斟酌字体与字号。

这次把 W1–W4、显影交互、风格选择控件、相纸卡印字和分享画布的界面装饰统一到中性灰阶。照片内容继续由用户选择的 it-005 照片风格处理；黑白灰约束的是产品视觉系统与照片外的卡面印刷，不强制把用户照片去色。

## 涉及的用户故事

- **US-11 暗房仪式与分享**（补强）：以安静、统一的中性编辑式视觉呈现照片和分享作品。
- **US-4 成片卡片**（补强）：卡片标题、日期与水印采用清晰、有层次的排印，不使用手写感斜体和橙色印章。
- **US-12 可选照片风格**（补强）：照片风格选择控件本身使用灰阶选中态；各照片风格仍只改变照片内容。
- 新增 **US-13 黑白灰视觉与清晰排版**：所有页面在浅色与深色主题下共享黑白灰视觉 token 和明确的中文字级层级。

## 体验方案

### 全局色彩

移除界面与相纸卡上的橙色、棕色和墨绿色品牌强调。以中性冷灰取代暖纸色；强调仍以灰阶深浅、字重、边线和形状表达，不用彩色高亮。

| token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| paper | `#F3F3F1` | `#151515` | 页面背景，轻微离开纯白/纯黑 |
| surface | `#FBFBFA` | `#212121` | 卡片、弹层、编辑区 |
| ink | `#191919` | `#F2F2F0` | 主文字 |
| inkFaint | `#5B5B5B` | `#B9B9B6` | 次级文字与说明 |
| accent | `#414141` | `#D0D0CE` | 选中态、进度、交互强调；只用灰阶 |
| accentContent | `#FFFFFF` | `#171717` | 强调表面上的文字/图标 |
| hairline | `#D8D8D6` | `#383838` | 分隔和非选中边界 |
| cardPaper | `#FBFBFA` | `#FBFBFA` | 导出相纸，维持纸面可读性 |
| cardInk | `#191919` | `#191919` | 相纸主印字 |
| cardInkFaint | `#626262` | `#626262` | 相纸辅助印字 |
| cardAccent | `#414141` | `#414141` | 日期与印刷强调，恒定石墨灰 |
| cardHairline | `#DEDEDC` | `#DEDEDC` | 卡面细分隔线 |

深色主题只用于应用界面；成片相纸保持中性浅灰白，以保证图片、印字与社交分享的稳定对比。全局交互不再出现橙色、暖棕或墨绿品牌色；系统错误等语义反馈仍按可读性表达，不作为品牌强调色。

### 字体与字号

用 Android 系统 CJK 字体族，不新增字体依赖或素材：中文展示字使用系统 `serif`（Noto Serif CJK 回退），功能文字使用系统 `sans-serif`（Noto Sans CJK 回退）。衬线只承担少量编辑式标题；导航、表单、说明、按钮、日期和辅助标签统一用无衬线，保证中文小字号清楚。

| 层级 | 字体角色 | 字号 / 行高 | 用途 |
|---|---|---|---|
| Display | Serif / Semibold | 30 / 40sp | W1 主标题「显影」；每屏最多一个 |
| Page title | Sans / Semibold | 22 / 30sp | W2–W4 页面标题 |
| Section title | Sans / Semibold | 17 / 24sp | 卡面编辑、分享画幅、设置分组 |
| Body | Sans / Regular | 15 / 23sp | 正文、阶段陪伴文案、表单内容 |
| Supporting | Sans / Regular | 13 / 19sp | 辅助说明、次级操作 |
| Button | Sans / Medium | 14 / 20sp | 按钮和选择项 |
| Micro label | Sans / Medium | 11 / 15sp | `DEVELOPING` 等短标签；仅拉丁字母可用轻字距，中文不拉字距 |

相纸标题取消手写感和斜体，使用稳定的 Serif 常规体、Medium，按卡面宽度限制最多两行并保持字号下限；日期使用 Sans Medium 与等宽数字特性，移除粗体橙字；水印使用 Sans Medium、低对比灰。界面正文遵循系统字体缩放，卡面印刷仍按实际成片尺寸排版，并保证长标题、不同日期格式不会互相覆盖。

### 页面与分享表现

- W1–W4 背景、Surface、文字、图标、按钮、进度条、滑块和选中态全部走同一组双主题灰阶 token；控件选中态同时用边框/勾选或字重表达，不只依赖颜色。
- W2 槽口与相纸阴影以中性黑灰表达，保留现有显影扩散、纸张升起与落定动画，不改真实感动效时间线。
- W3 风格选择列缩略图可保留照片本身的色彩；选择边框、文字和勾选改为灰阶。标题输入、日期编辑和画幅选择统一灰阶。
- 相纸卡、1:1/4:5/9:16 分享装饰、水印与日期章全部黑白灰；照片本身继续使用 it-005 选择的「原色、暖片、银影、青幕、柔光」，且预览、静图、视频参数一致。
- 按钮用墨色表面配白字或透明/纸色表面配墨色文字；取消橙色主按钮和橙色光效，避免用大面积灰色底堆层次。

## 验收标准

- **AC1 全局灰阶**：W1–W4、对话框、输入控件、显影进度、风格选择、相纸印刷与分享画布中不存在品牌橙、棕、绿或其他彩色强调；浅色、深色都遵循 token 表。
- **AC2 可读对比**：浅色/深色主文字对背景达到 ≥7:1、次级文字对背景 ≥3:1、强调面上的文字 ≥4.5:1；选中态不只靠色差表达。
- **AC3 字体一致**：中文正文与功能控件统一 Sans；衬线限用于少量展示标题和相纸作品标题；移除斜体手写感、橙色等宽日期样式和 2sp 过度拉宽的小标签。
- **AC4 字级清楚**：实现 Display 30/40、Page title 22/30、Section 17/24、Body 15/23、Supporting 13/19、Button 14/20、Micro 11/15sp 的语义层级；页面层级明确，正文不小于 13sp。
- **AC5 分享统一**：相纸和三种分享画幅的日期、标题、水印、边线均为中性灰阶；横屏/竖屏、长标题与日期组合无重叠，照片颜色仍按所选照片风格输出。
- **AC6 可访问性**：系统字体放大时 W1–W4 的主要操作仍可读、可触达；相纸印刷不跟随系统字体缩放，但能按卡面宽度适配，标题不与日期重叠。
- **AC7 回归与记录**：浅色/深色对 W1–W4 及五种照片风格选中态完成视觉检查；1:1、4:5、9:16 分享预览与导出印字一致；更新常青 spec、根 `DESIGN.md` 中 darkroom 个性行、README、CHANGELOG 和本迭代验证记录。
