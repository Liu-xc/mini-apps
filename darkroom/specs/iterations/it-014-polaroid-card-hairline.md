# it-014 — 拍立得卡面外缘 hairline（卡片边缘「立」起来）

状态：**实施完成（2026-09-29）**
日期：2026-09-29
类型：视觉微调（it-013 收尾建议的后续；Leo「加一圈 hairline 试试」即确认）

## 背景与动机

it-013 去掉画册底衬色块后，卡纸分层只靠相纸自身明度 + 照片内容锚定。实测拍立得默认
相纸 `0xFFFAF9F4` 与纸底 `#F3F3F1` 仅差约 7/255——卡片外缘几乎不可见，边「立」不起来。
it-013 收尾时已向 Leo 提出补一圈极细 hairline，Leo 回复「加一圈 hairline 试试」。

现状：深色卡（数码/胶片/墨框）已有外缘 hairline 外框（`DevelopCard` / `PhotoCardPainter`
各一处 `if (mode != POLAROID)`），**唯独拍立得没有**——恰好是浅纸卡在纸底上最糊边的场景。

## 用户故事

- 无新 US；属 US-18（沉浸相册翻页）与 W2/W3 卡面观感的既有质量线（DESIGN.md 触感基线）。

## 验收标准

1. 拍立得卡面在亮/深两种主题的纸底上外缘都有一圈 1px 级 hairline，卡片边界清晰；
2. 预览端（`DevelopCard`：W2 显影台 + 画册）与导出端（`PhotoCardPainter`：查看器/
   分享图/视频）同参数同步——预览与成片不许错配（it-001 AC3）；
3. 深色卡既有外框观感不变；线宽沿用既有公式 `cardWidth×0.0018（≥1px）`、
   颜色沿用 `palette.hairline`（单一真源，不引新 token）；
4. 显影动画、末态保真（it-013）不受影响——只加静态描边。

## 影响范围

- 代码：`ui/develop/DevelopCard.kt`、`card/PhotoCardPainter.kt`（各 1 处条件移除）。
- spec：02（画册背景补注续写）、05（§9 深色卡外框句扩为全模式）。
- 版本：0.5.13。
