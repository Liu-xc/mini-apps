# it-015 - 安静界面与反馈闭环

状态：**实施完成（2026-09-30）**
日期：2026-09-30
类型：UI 优化（基于 2026-09-29 全页面 UI 走查）

## 背景与动机

全页面走查确认，显影的核心卡面与显影动画已具备作品感；体验被少数不随场景退场的说明、同一功能的重复入口，以及跨页面滞留的保存 snackbar 稀释。设置页还展示了过期版本号 `0.5.11`，与当前构建 `0.5.13` 不一致。

用户于 2026-09-30 明确要求「对显影 APP 也进行同样的 UI 走查和 UI 优化」，视为本提案及以下低风险优化范围的确认。

## 涉及用户故事

- US-4 成片卡片：作品预览应是成片页主角，进入大图的提示只保留一处。
- US-5 保存与分享：保存完成反馈只服务于当前操作页面，不能遮挡后续导航。
- US-8 设置：设置中的应用身份信息与安装包保持一致。
- US-10 首屏信息密度：非关键说明不应持续抢占画廊与成片页注意力。
- US-11 暗房仪式：界面应安静，控制与提示仅在需要时出现。

## 优化方案

1. W1 将「全程离线」从相册网格常驻页脚移至 W4 已有的关于说明，画册入口只保留内容和操作。
2. 画册与 W3 各保留一处大图行动线索：移除画册底部的「点按成片看大图」常驻文案；W3 去掉预览角标和重复言说，只保留预览下方一条可读提示。
3. W3 顶行去掉副标题与 `PRINTED` 装饰，保留返回、页名和编辑，降低顶部竞争。
4. 页面路由变化时立即关闭并清空 snackbar，防止保存消息停留到画册、设置等无关页面。
5. W4 版本号从当前安装包元数据读取；去掉「真机有效」这类实现细节文案。

## 验收标准

- W1 相册网格首屏无常驻离线说明，W4 仍可读到本地处理/相册写入说明。
- W3 顶行没有副标题或 `PRINTED`，成片预览只有一处「查看大图」提示且整张预览可点击。
- 画册底部不再出现「点按成片看大图」；模式与速度、重播仍可用。
- 保存后进入其他 screen 时 snackbar 消失，消息状态被清空；留在当前页时原有分享 action 正常。
- 设置「关于」展示当前构建版本；构建、单测和模拟器关键路径通过。
