# 05 — 设计系统（暗房相纸个性）

> 基线 = 根 `DESIGN.md`（红线不可破）；本文定义 darkroom 的**个性层**与特例声明。
> 个性轴：**暗房工艺（craft）**——相纸白是拟物焦点、橙色日期章是唯一强调、显影即动效。

## 1. 对基线的偏移声明（DESIGN.md §1 治理要求）

| 项 | 偏移 | 理由 |
|---|---|---|
| 个性定位（§1 表已登记） | **暗房工艺**：纸感基线上偏暖米；相纸白恒定 | 拟物对象是相纸，实物不分昼夜都是白纸 |
| 相纸卡恒定白 | `CardPaper #FDFCF6` 昼夜不翻色 | 同 xiangqi「棋盘唯一拟物焦点」先例；仅限卡面，页面仍按墨绿纸翻色 |
| **§4 不加音效（基线）** | **App 内仍零音效**（滑条/按钮/导航全部无声）；声音只存在于**导出视频的内容物**（出纸/药水/定影三段，`SfxSynth` 合成） | 视频是发到社交平台的内容，声轨属于内容而非 UI 音；ADT 见 06 ADR-002 |

## 3. 排版 / 形状 / 间距

继承基线：Display 衬线 32sp（「显影」大标题）、Title 衬线 20sp、Body Sans 15sp、
Label Sans 11sp letterSpacing 2（`DEVELOPING`/`PRINTED`/`DARKROOM` 印刷小标签母题）。
卡片圆角 20dp、弹层 28dp、按钮 14dp、chip 8dp、屏幕边距 20dp。

**卡面内部排版**（`CardLayout`，独立于系统字体缩放——印刷品不随 OS 字号变）：
手写标题 = 衬线斜体、日期章 = 等宽粗体橙 letterSpacing 0.06、水印 = Sans 0.22 字距。

## 4. 动效表（EditorialMotion）

| # | 动效 | 参数 | 触发 |
|---|---|---|---|
| 1 | 出纸 | smooth（noBouncy/MediumLow），位移 cardH，末尾微回正 | 进入显影台一次性 |
| 2 | 显影进度 | vsync 帧循环，无弹簧（真实时间线性）；照片以种子稳定的不规则药膜边缘逐步显现 | 播放/药水条/甩一甩 boost |
| 3 | 定影落定轻弹 | runSettlePulse 80ms↑ + pop(0.72,500)↓ | 进度抵达 100% 一次 |
| 4 | 屏幕切换 | crossfade 220ms | 导航 |
| 5 | 成片入场 | scale 0.96→1 pop | 进入成片页一次 |
| 6 | 槽口/卡片位移 | graphicsLayer 直写（1:1 跟手） | 药水条拖动 |
| 7 | 成片分享预览 | 使用最终导出布局即时预览；柔焦选图背景、纸卡阴影与暗角保持克制 | 选择 1:1 / 4:5 / 9:16 |

预算对表：交互反馈即时 ✓；一屏自主运动 ≤1（显影中只有卡片在变）✓；
无入场 stagger、无彩屑（保存成功不庆祝，仅 snackbar）✓；
减弱动态 = 出纸瞬时落位 + 显影直接跳定影（`EditorialMotion.reduceMotion`）✓。

## 5. 触感 / 声音

- Confirm 轻震：**定影落定**、**导出完成**（各一次）。

## 7. 分享成片

分享画布继续以相纸白和照片为焦点：1:1 与 4:5 保持无广告字的纯卡面构图；9:16 用低对比、低清晰度的同一照片延展画布，
只在顶部与底部平台 UI 安全区外加可随水印关闭的 `DARKROOM` 与「把回忆洗出来」。图片和视频同用 `ShareLayout`，预览直接采用最终构图。

## 8. 照片风格（it-005）

W3 在成片预览下提供横向照片风格缩略列：**原色、暖片、银影、青幕、柔光**。缩略图来自当前照片并复用成片渲染参数；accent 只用于选中边线、文字和勾选标记，不铺选项底色。点击即时切换，不打开弹层。

风格是固定且确定性的纸面处理预设：色调、颗粒与暗角范围克制；柔光仅提取亮部并叠加低强度晕光，保留主体细节。新照片默认原色。W2 的药膜显影过程不套后期预设；W3、静态导出和视频逐帧共享相同风格参数，视频最终帧与成片预览一致。
