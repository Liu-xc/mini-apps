# 05 — 设计系统（黑白灰编辑式暗房）

> 基线 = 根 `DESIGN.md`（红线不可破）；本文定义 darkroom 的中性灰阶个性与特例声明。
> 个性轴：**编辑式暗房（editorial darkroom）**——安静的灰阶纸面、精确的中文排版、照片是唯一保留影调的主角。

## 1. 对基线的偏移声明（DESIGN.md §1 治理要求）

| 项 | 偏移 | 理由 |
|---|---|---|
| 个性定位（§1 表已登记） | 页面与卡面印字均用中性黑白灰；强调采用石墨灰，不用品牌彩色 | 让留白、字级和真实照片建立作品感，避免橙色装饰抢焦 |
| 相纸卡恒定浅纸色 | `CardPaper #FBFBFA`，深浅主题一致 | 成片在不同系统主题与分享平台中保持相同印字对比 |
| 字体角色 | 中文功能字统一 Sans；Serif 只用于 W1 展示标题与相纸作品标题 | 中文小字号清楚，少量衬线保留编辑式性格 |
| **§4 不加音效（基线）** | **App 内仍零音效**（滑条/按钮/导航全部无声）；声音只存在于**导出视频内容**（出纸/药水/定影三段，`SfxSynth` 合成） | 视频是发到社交平台的内容，声轨属于内容而非 UI 音；ADR 见 06 ADR-002 |

照片内容保留用户选择的 it-005 影调。灰阶规范覆盖界面、控件、相纸边框、日期/水印印字和分享画布装饰；「暖片」「青幕」等预设仅影响用户照片，不用于界面镀色。

## 2. 色彩 token

| token | 浅色 | 深色 | 说明 |
|---|---|---|---|
| paper | `#F3F3F1` 中性浅灰纸 | `#151515` 石墨暗纸 | 页面底 |
| surface | `#FBFBFA` | `#212121` | 卡片/弹层 |
| ink | `#191919` | `#F2F2F0` | 主文字 |
| inkFaint | `#5B5B5B` | `#B9B9B6` | 次级文字 |
| accent | `#414141` 石墨 | `#D0D0CE` 银灰 | 进度、选中与小范围强调；不铺底 |
| accentContent | `#FFFFFF` | `#171717` | 强调表面上的图标/文字 |
| hairline | `#D8D8D6` | `#383838` | 分隔和未选中边界 |
| cardPaper | `#FBFBFA` 恒定 | 同左 | 分享相纸；不随主题翻色 |
| cardInk | `#191919` 恒定 | 同左 | 卡面标题 |
| cardInkFaint | `#626262` 恒定 | 同左 | 卡脚水印 |
| cardAccent | `#414141` 恒定 | 同左 | 日期印字（中性石墨） |
| cardHairline | `#DEDEDC` 恒定 | 同左 | 相纸内细线 |

对比度：浅色 ink/paper 15.82:1、inkFaint/paper 6.11:1、白字/accent 10.21:1；深色 ink/paper 16.29:1、inkFaint/paper 9.29:1、accentContent/accent 11.61:1，均高于 `DESIGN.md` §2.2 下限。强调面积保持小于 10%；系统错误等语义反馈服从系统可读性，不作为品牌色。

深色界面使用中性炭黑，不用带绿色的暗色；相纸维持浅灰白。照片、相纸底、卡面字与分享背景间以真实明度差分层，不叠加彩色遮罩。

## 3. 排版 / 形状 / 间距

Android 系统 CJK 字体族：Sans 使用 `FontFamily.SansSerif`（Noto Sans CJK 回退），Serif 使用 `FontFamily.Serif`（Noto Serif CJK 回退）；不新增字体依赖或随包字体。

| 层级 | 字体 | 字号 / 行高 | 用途 |
|---|---|---|---|
| Display | Serif Semibold | 30 / 40sp | W1 唯一主标题 |
| Page title | Sans Semibold | 22 / 30sp | W2–W4 页标题 |
| Section title | Sans Semibold | 17 / 24sp | 照片风格、分享画幅、设置分组 |
| Body | Sans Regular | 15 / 23sp | 正文、阶段文案、表单 |
| Supporting | Sans Regular | 13 / 19sp | 辅助说明、次级操作 |
| Button | Sans Medium | 14 / 20sp | 按钮 |
| Micro label | Sans Medium | 11 / 15sp | 短标签；仅短拉丁字母可用约 1.1sp 字距，中文不加字距 |

功能正文最小 13sp；系统字体缩放应用于 Compose 界面。卡片圆角 20dp、弹层 28dp、按钮 14dp、chip 8dp、屏幕边距 20dp；相纸边缘保持方正，阴影只用于分享卡片的轻微脱纸感。

**卡面印字**（`CardLayout`，独立于系统字号缩放，Compose 与 native 位图/视频共享布局）：作品标题使用常规 Serif Medium，最多两行并以省略号收尾；日期使用 Sans Medium + tabular figures，右对齐；水印使用 Sans Medium、石墨浅灰。日期和标题域互斥（0.52w / 0.54w），标题域不侵入水印区。

## 4. 动效表（EditorialMotion）

| # | 动效 | 参数 | 触发 |
|---|---|---|---|
| 1 | 出纸（拍立得） | `EditorialMotion.ejectEase` 分段曲线，850ms：快推 34% → 微顿 → 再推 → 微顿 → 缓出回正；末端微回正；槽口按下压再回位（sin 单峰） | 进入显影台一次性 |
| 1a | 开机点亮（数码） | 同一 850ms 曲线驱动 scale 0.96→1，扫描线自上而下扫过一次，无位移、无槽口 | 同上，模式为数码时 |
| 1b | 卷片（胶片） | 同一曲线驱动 translationX 自右向左卷入，附 0.8° 微摆；片盒口竖条随过片下压 | 同上，模式为胶片时 |
| 2 | 显影进度 | vsync 帧循环，无弹簧（真实时间线性）；照片以种子稳定的显现前沿逐步显露（三种前沿随模式） | 播放/刻度条/甩一甩 boost |
| 3 | 定影落定轻弹 + 光泽扫 | runSettlePulse 80ms↑ + pop(0.72,500)↓；并发 600ms 对角高光带扫过整卡一次（FastOutSlowIn，峰值白 12%），750ms 内完成、不被 W2→W3 切换切走 | 进度抵达 100% 一次 |
| 4 | 屏幕切换 | crossfade 220ms | 导航 |
| 5 | 成片亮相 | rise 16dp + fade + pop（it-008 升级，光泽扫归 W2 定影——避免 750ms 内连扫两遍） | 每次显影会话首次到达成片页 |
| 6 | 槽口/卡片位移 | graphicsLayer 直写（1:1 跟手） | 刻度条拖动 |
| 7 | 成片分享预览 | 使用最终导出布局即时预览；相纸卡走中性暗底、深色卡（数码/胶片）走亮场 | 选择 1:1 / 4:5 / 9:16 |
| 8 | 药液气泡 | `DevelopFx.bubbleAt` progress 确定性纯函数：12 个种子气泡自下而上浮起 + 横向微摆，暗晕打底 + 白芯（亮暗背景都可辨），峰值 16%；包络 15%–85%，倒放严格可逆 | 显影中（拍立得/胶片；数码无药水不给） |
| 9 | 前沿湿光 | `DevelopFx.wetBandAt`：**仅胶片 SWEEP**——与 RevealField.frontX 公式精确对位的湿边，白 ≤10%。拍立得不给（it-008 收尾修正：对角近似层与真实偏心前沿不重合，实机观感像胶水扩散、与「逐步浮现」语言冲突）；数码不给 | 显影中（仅胶片） |
| 10 | W1 冷入场编排 | `EditorialEntrance`：5 组 stagger 24ms，每组 fade 240ms + rise 14dp；flag 由导航壳跨屏持有，二次进入/Activity 重建不重放 | 首次冷进入 W1 |
| 11 | 阶段文案过场 | AnimatedContent fade 160ms + rise 6dp；百分比读数 tabular figures | 阶段切换（每会话 3 次） |
| 12 | 控件状态过渡 | 模式 chip 边框宽/色 150ms + 选中示意图 pop 1→1.08→1；样片卡按压 0.97 + 松手 pop 回弹；snackbar 编辑式（surface + hairline + 14dp 圆角） | chip 选择/样片按压/消息 |

**出纸只放一次**（it-007 修正）：由 `UiState.ejecting` 驱动而不是 `LaunchedEffect(Unit)`——
Activity 被系统重建时显影可能已过半，重放出纸会让进行中的会话又「吐」一次纸。

预算对表（it-008 修订）：交互反馈即时 ✓；一屏自主运动 ≤1 ✓——显影中的自主运动仍聚焦卡片一处：气泡与湿光都画在照片区内、由 progress 驱动，是「照片正在显影」这一个过程的两面，非第二个运动源（拍立得的湿光层已于收尾修正中移除——它不是前沿本身时就成了第二层「胶水」，胶片的湿边因与前沿精确对位而保留）；入场编排仅 W1 首次冷进入（stagger 24ms × 5 组，>200ms 编排只允许首屏）+ W3 亮相一次，返回/二次进入走快路径 ✓；无彩屑（保存成功仅 snackbar）✓；定影光泽扫 600ms 属庆祝预算（≤900ms），只挂在定影落定 ✓；减弱动态 = 出纸瞬时落位 + 显影直接跳定影 + 全部过程/入场动效瞬时（`EditorialMotion.reduceMotion`）✓。

**过程动效真源（it-008）**：`develop/DevelopFx.kt` 是气泡/湿光/包络的纯函数单一真源
（`(mode, progress) → 参数`，确定性、85% 后全归零）；导出端不画过程动效——成片在
progress=1，包络为零，预览与导出终态天然一致（单测锁定）。

## 5. 触感 / 声音

- Confirm 轻震：**定影落定**、**导出完成**（各一次）。
- DoubleTick 警示震：导出/读图失败。
- 拖动/导航/输入零触感零音效（基线 §4）；视频声轨见偏移声明。

## 6. 反例自查

无 emoji 功能图标（全 Material Icons）✓；强调不铺底 ✓；深色非纯黑 ✓；页面与印字无品牌彩色强调 ✓；空态有样片与行动按钮 ✓；进度数字逐帧连续（非跳变）✓；放弃会话（返回）不丢已保存产物 ✓。

## 7. 分享成片

分享画布的相纸、日期、标题和水印均用中性灰阶印字。1:1 与 4:5 保持无广告字的纯卡面构图；9:16 使用同一张已选风格照片的低对比延展背景，只在上下平台安全区外加可随水印关闭的 `DARKROOM` 与「把回忆洗出来」。图片和视频同用 `ShareLayout`，预览直接采用最终构图。

## 8. 照片风格（it-005）

W3 在成片预览下提供横向照片风格缩略列：**原色、暖片、银影、青幕、柔光**。缩略图来自当前照片并复用成片渲染参数；选择边线、文字和勾选都用灰阶表达，不铺选项底色。点击即时切换，不打开弹层。

风格是固定且确定性的照片处理预设：色调、颗粒与暗角范围克制；柔光仅提取亮部并叠加低强度晕光，保留主体细节。新照片默认原色。W2 的药膜显影过程不套后期预设；W3、静态导出和视频逐帧共享相同风格参数，视频最终帧与成片预览一致。

## 9. 显影模式与药水刻度条（it-007）

**W1 显影模式**：主按钮与样片区之间一行 Section title + 三枚等宽 chip（拍立得 / 数码相机 / 胶片），
每枚 chip 高 66dp、内含 22dp 的 Canvas 微型示意图（白框相纸 / 屏幕+OSD / 齿孔片条）与模式名。
选中态用 1.5dp ink 边框 + SemiBold 字重同时表达，未选中 1dp hairline + inkFaint——不靠颜色单独编码。
chip 下方一行 bodySmall 给出当前模式的说明。示意图是 Canvas 画的形体，不用 emoji（基线 §5 反例 2）。

**W2 药水刻度条**（`ChemicalGauge`，替换 Material Slider）：

| 元素 | 规格 |
|---|---|
| 轨道 | 未显影 1.5dp hairline；已显影 2.5dp 实心 accent |
| 刻度 | 每 5% 短刻度（5dp）、每 25% 长刻度（9dp）、阶段分界最长（13dp）；已显影段 accent、未显影段 hairline |
| 阶段名 | 轨道上方一排 labelSmall 11sp，按各自阶段宽度（15%/55%/30%）居中；当前阶段 ink、其余 inkFaint |
| 手柄 | 8dp 实心 accent 圆点 + 2dp paper 描边；拖动中放大到 12dp |
| 交互 | 按下暂停 → 拖动/点击 seek → 松手续播；触控区 44dp；支持倒放 |

进度读数只保留百分比（titleMedium + accent），阶段名由刻度条一排承担，不再重复。

**三模式卡面与分享底**：模式只改变卡面形态与照片影调，界面与印字仍守黑白灰。
拍立得保持浅纸卡 + 中性暗分享底；数码与胶片是深色卡面，分享底改为亮场（照片延展的浅色柔化）
以保证卡面可辨、投影可读，故事画幅的品牌短句相应翻成深色。深色卡额外补一圈 hairline 外框，
避免卡面在深色页底上糊成一片。胶片齿孔位由 `CardLayout.sprocketHoles` 单一真源解出，两端渲染器共用。

**上架质感基线（it-008）**：应用图标与窗口底色必须与灰阶 token 同源——图标为石墨底 `#1B1B1B` +
白框相纸 + 灰阶「显影中」构图（左下已显影山景、右上乳剂浅灰、石墨日期章），monochrome 同源；
`window_background` 浅 `#F3F3F1` / 深 `#151515` 与 paper 一致，冷启动无闪变。
过程动效按模式差异化：气泡与湿光只属于化学工艺（拍立得/胶片），数码屏以网格显现 + 开机扫描线为语言。
