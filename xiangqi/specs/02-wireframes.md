交互路径：
- **P1 开局**：选模型 → 开局 → spawn 两 pi 进程 → 回合循环自动推进 → 终局记分。
- **P2 介入**：暂停 → 单步 / 棋盘手动代走 → 继续。
- **P3 连战**：终局 → 勾选换先 → 再次开局（session 重建，记分板延续）。

## W2 · 错误态

- 模型 key 缺失 / pi 未安装：控制条下方红字一行，给出修复提示（如 `export ZAI_API_KEY`），开局按钮不禁用但点击即报。
- 非法走法重试：当前方思考栏顶部小徽标「重试 2/3」。
- 单回合超时：徽标变「超时」，提供 [重试] [判负]。
