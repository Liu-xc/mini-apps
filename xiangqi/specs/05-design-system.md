# 05 · 设计系统（Design System）

> 状态：it-001 起草（2026-09-23）。**基线 = 根 `DESIGN.md`**（纸感淡绿底、衬线 Display + Sans 正文、WCAG AA、触控 ≥44px、EditorialMotion 三弹簧），本文只记个性偏移与本应用 token。

## 个性偏移（DESIGN.md 个性轴表已登记一行）

- 基线之上偏移：**棋盘是唯一的「拟物焦点」**——保留 xiangqiboardjs 木纹暖棕（非纸感），界面其余部分维持纸感底 + 衬线标题，形成「纸上摆一盘木棋」的对比。
- 思考流栏用等宽/代码字体（模型输出性质），与正文 Sans 区分。

## 动效

- 落子：xiangqiboardjs 自带动画即达标，不叠加额外动效（动效预算）。
- 记分板数字变化：复用 count-up 语义（数值短暂过渡 ≥200ms）。
- 思考流新行：120ms 淡入，不滚动抖动（自动滚底但用户上翻时暂停）。
