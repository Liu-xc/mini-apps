# 00-overview · 赤峰环线（travel-rpg）

## 业务背景

把 2026 年秋的**赤峰环线自驾**（阿斯哈图石林 → 达里诺尔湖 → 乌兰布统）的经历，
做成一个**塞尔达式的 3D 网页 RPG**：第三人称角色在草原地貌中跑跳探索，
走到观景点触发真实旅行内容（照片/游记/纪念品），形成「探索 → 发现 → 回忆」的闭环。

- 目标平台：**PC web + mobile web 一套代码**（响应式 + 触屏控制），不发应用商店。
- 非目标：写实画质、多人、原生 App（Godot/APK 留给 mini-games 线）。

## 核心价值流

```
旅途素材（照片/路线/事件）
  → 美术基调（三站色板/光照，参考 reports/2026-09-24-travel-rpg-scenes 气氛稿）
  → 游戏世界（heightmap 地形 × 三站生物群系）
  → 探索玩法（跑跳/镜头/地标引导/观景点触发）
  → 内容消费（照片墙、里程成就、事件卡）
  → 分享（链接/截图）
```

## 里程碑（见 specs/iterations/）

- **M0 it-001**：Three.js 地基验证——地形、角色跑跳、跟随镜头、键鼠+触屏双控制。
- **M1**：塞尔达感底子——草地风动、云影、光照时序、地形扩展。
- **M2**：三站生物群系 + 地名揭示 + 里程/站点系统。
- **M3**：旅行内容接入（观景点照片、纪念品道具、事件卡）。
