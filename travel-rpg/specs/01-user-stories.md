# 01-user-stories · 用户故事

编号规则：US-N（故事）/ AC-N-M（验收标准）。

## US-1 地基可玩性（M0 · it-001）

作为玩家，我能在 3D 场景中控制角色自由移动、跳跃，并用跟随镜头观察世界。

- **AC-1-1** PC：WASD/方向键按镜头相对方向移动；鼠标拖拽环视；空格跳跃；滚轮缩放镜头。
- **AC-1-2** 移动端（粗指针或 `?touch=1`）：左下虚拟摇杆移动（推满=跑）；右半屏拖拽环视；跳跃按钮。
- **AC-1-3** 角色贴合地形高度行走，跳跃有重力弧线，落地不穿地；镜头不穿地。
- **AC-1-4** 镜头为第三人称弹性跟随，带阻尼与俯仰/距离限制。
- **AC-1-5** `npm run build`（tsc + vite）零错误，浏览器控制台零报错。

## US-4 画面品质基线（M1 · it-002 提案）

作为玩家，我进入的应该是一个「一眼认真做过的」风格化世界：高口碑素材、有风的草场、
干净的色彩与后期，而不是拼装感的低模 demo。

- AC-4-1 植被/地面/天空均来自调研验证过的高口碑 CC0 源（Quaternius / PolyHaven PBR），
  无自造锥体、无 canvas 手绘云。
- AC-4-2 草场随风起伏（≥1 万株、参数化风场），静止场景不成立。
- AC-4-3 阴影偏冷、无全屏土黄泥色；bloom/暗角/SMAA 后期在位。
- AC-4-4 既有 US-1 行为断言与零报错回归通过。

作为玩家/旅行者本人，我到达观景点后能看到当时的真实照片与游记片段，
收集纪念品与里程成就。

## US-5 场景快速编排（M2 前置 · it-003）

作为场景作者（Leo），我能在浏览器里快速摆放资产、即时看到最终画面，并把编排结果导出为可入库的数据。

- AC-5-1 资产面板按目录（catalog.json）分类浏览，选择后点地形即放置（贴地、朝向随机可改）。
- AC-5-2 已放物体可拖拽移动、点选后旋转/缩放/删除，操作有可见反馈。
- AC-5-3 每次改动即时写入 localStorage，刷新页面编排结果保留；「重置默认」恢复代码场景。
- AC-5-4 导出 JSON 与 SceneDef 同构（含 id/name/placements），可直接粘回 src/scenes.ts。
- AC-5-5 普通模式（?edit 不存在）行为与画面不受编辑器影响，US-1/US-4 断言全绿。
