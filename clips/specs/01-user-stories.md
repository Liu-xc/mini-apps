# 01 · 用户故事与验收标准

编号规则：`US-XX` 用户故事，`UC-XX` 对应用例/界面（W 编号见 [02-wireframes.md](02-wireframes.md)）。验收标准采用 Given/When/Then。涉及平台时以【Mac】【Android】标注。

## 捕获

### US-01 自动记录复制内容【Mac】
作为 Mac 用户，我想复制任何文本时自动进入历史，无需任何手动操作。
- **UC**：后台轮询（托盘常驻）
- Given 应用在菜单栏运行，When 我在任意应用复制文本，Then ≤1s 后该条目出现在历史最前
- Given 复制的内容与历史中某条完全相同，Then 不新增重复条目，而是把那条刷新到最前并 `useCount+1`（ADR-007）
- Given 复制空字符串/纯空白，Then 忽略
- Given 文本超过 10,000 字符，Then 截断保留首尾并标注「已截断」后入库
- Given 开启「暂停记录」，Then 停止入库直到重新开启（托盘菜单一键切换）

### US-02 打开即捕获【Android】
作为 Android 用户（系统不允许后台读剪贴板），我想打开应用时自动把当前剪贴板存进历史。
- Given 剪贴板有文本，When 打开 App（含磁贴入口），Then 该文本自动入库（同 US-01 去重规则），列表顶部短暂高亮「新捕获」
- Given 剪贴板为空或与最近条目相同，Then 无感，不弹任何提示

### US-03 分享存入【Android】
- Given 任意应用选中文字 → 系统分享，When 选择「存入剪贴盒」，Then 不经过剪贴板直接入库，Toast 确认后返回

## 呼出与复制回

### US-04 全局热键快速面板【Mac】
作为 Mac 用户，我想在任意应用里按 ⌘⇧V 呼出搜索面板，纯键盘完成「搜索→选中→粘贴」。
- **UC**：W1
- Given 任意应用在前台，When 按 ⌘⇧V，Then 面板出现且焦点在搜索框，历史按最近排序
- Given 输入关键字，Then 列表即时过滤（子串匹配，大小写不敏感）
- Given ↑↓ 移动选中，When 按 ⏎，Then 选中条目写回剪贴板、面板隐藏；若开启「自动粘贴」则向原前台应用发送 ⌘V（需辅助功能权限，失败降级为仅复制并提示一次）
- Given 按 Esc 或点击面板外，Then 隐藏面板但不退出应用
- Given 点击托盘图标，Then 同样打开该面板；托盘右键菜单含主窗口/暂停记录/退出（W2）

### US-05 磁贴一键到达【Android】
- Given 任意界面，When 下拉快捷设置点「剪贴盒」磁贴，Then 打开 App 并执行 US-02 捕获

### US-06 点选复制并返回【Android】
- Given 列表页，When 点某条目，Then 立即复制、行内 ✓ 反馈；若本次是从磁贴/桌面/分享进入（App 原本不在前台），Then 自动返回来源界面，否则仅复制不退出
- Given 长按条目，Then 弹操作单：复制 / 置顶 / 分享 / 删除（W4）

## 管理与检索

### US-07 搜索与类型过滤
- Given 搜索框输入关键字，Then 即时过滤；类型过滤条（全部/链接/邮箱/颜色/代码…）与关键字叠加生效
- 类型识别为纯本地启发式（URL/邮箱/电话/颜色值/JSON/代码/文本，见 [03-data-model.md](03-data-model.md)）；COLOR 类条目直接显示色块预览

### US-08 置顶收藏
作为用户，我想把取件地址、邮箱签名等常用片段置顶，永不淘汰。
- Given 条目操作单（或 Mac 右键），When 置顶，Then 进入「置顶」分组排在最前；再次操作取消
- Given 容量淘汰执行，Then 只淘汰未置顶条目

### US-09 删除与清空
- Given Android 列表左滑 / 操作单删除 / Mac 右键删除，Then 条目立即消失（动画回落）
- Given 设置页，When 清空全部（含置顶），Then 二次确认后历史清空

### US-10 容量与自动淘汰
- Given 容量上限（默认 50，可设 20–1000），When 入库后超限，Then 从最旧的未置顶条目开始淘汰
- Given 设置页修改上限，Then 立即按新上限执行一次淘汰

## 数据与设置

### US-11 设置
- 设置项：容量上限；暂停记录（双端）；【Mac】自动粘贴开关、热键展示（v1 固定 ⌘⇧V）
- Given 暂停记录开启，Then Mac 托盘图标呈暂停态、Android 列表顶部显示提示条
- 深色模式跟随系统（不设开关）

### US-12 备份导出/导入
- Given 设置页，When 导出，Then 生成 clips.json（Mac 走保存面板，Android 走系统分享/保存）
- When 导入，Then 与现有条目按全文去重规则合并，非法文件完整拒绝且不动现有数据

## 非功能需求

- NFR-01 Android 不申请 INTERNET 权限（构建产物核验）；桌面端无任何网络调用
- NFR-02 数据写入原子（tmp→rename）+ .bak，进程被杀不丢数据
- NFR-03 Mac 面板呼出 < 300ms（首次后常驻内存）；Android 冷启动 < 1.5s
- NFR-04 共享 domain/data 的 JVM 单测覆盖：去重、淘汰、截断、类型启发式、JSON 存取与迁移
- NFR-05 深色模式完整适配；视觉遵循 [05-design-system.md](05-design-system.md)
