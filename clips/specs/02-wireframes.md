## 交互路径总览

```
【Mac】 复制任意文本 ──(自动轮询)──▶ 历史库
   ⌘⇧V / 托盘左键 → [W1 面板] → 搜索/↑↓ → ⏎ 复制(→自动⌘V) → 回原应用
   托盘右键 → [W2 主窗口]（管理/右键删除/导出导入） → ⚙ [W5 设置]

【Android】 复制文本 → 磁贴 [W3 列表]（onResume 自动捕获）
   点条目 → 复制 ✓ → 返回来源
   任意应用分享 → 「存入剪贴盒」直接入库
   长按 → [W4 操作单]（复制/置顶/分享/删除/全文）
   搜索 + 类型过滤 · 左滑删除 · ⏸ 暂停

【共享】 W5 设置：容量/暂停/自动粘贴(Mac)/导出导入/清空
```
