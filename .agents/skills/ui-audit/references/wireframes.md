# 线框图 · 灰盒样式规范与自检

用 `scripts/wireframe_lib.py`（PIL）。所有画法以它为准，不要现场重造。

## 画布与风格

- 画布 **720×1600**（与 1080×2400 实机截图同比例 0.45，报告里左右等高对照）。
- 灰盒配色（已内置常量）：白底、容器 `FILL/FILL2` 灰、描边 `LINE`、主按钮 `PRIMARY` 深灰、
  文字 `INK/INK2`；**变更点一律用 `ACCENT` 蓝**（徽标圆底、注释文字、变更元素描边）。
- 字体：优先 PingFang.ttc，回落 `Hiragino Sans GB.ttc`（index 0=W3 常规 / 2=W6 加粗），
  再回落 STHeiti。字号 19–40px（缩到报告 76mm 宽时 ≈ 7–10pt，勿再小）。

## 铁律：符号自绘

CJK 字体**没有**这些字形，直接写字符会渲染成叉框/tofu：`✓ ‹ › ▸ ▾ ⌖ ✎ 📍 📷 🎲 📋 👤 🗑 🔍 ⟳ ↗ ✕`。
全部用库里的 `sym_check / sym_chev / sym_triangle_down / sym_crosshair / sym_magnifier /
sym_arrow_ne / sym_camera / sym_person / sym_x / sym_star_row` 替代。
可以安全直写的字符：CJK、ASCII、`● ○ ☆ ★ ＋ · — （）`。

## 变更点标注系统

- `badge(d, cx, cy, n)`：蓝色圆底白字①②③，**编号与报告页侧栏要点严格一一对应**。
- 徽标放置规则（验收门反复抓的就是这些）：
  - 不压任何文字——放在元素左/右上角外侧、注释行左侧空位；
  - 不贴画布边缘（留 ≥20px）；
  - 行内不放第二枚同号徽标（角标计数之类用矩形+文字，别用圆徽标，会读成重复标记）。
- 蓝色注释（`note()`）解释改版意图，放在所标注元素旁，同样不得压字。

## 组件库速览

`chip`（筛选 pill，可带自绘✓）/ `btn`（主/次按钮，可带✓/箭头）/ `imgph`（照片占位：灰底+对角叉）/
`dashrect`（虚线框：空槽/未就绪/占位）/ `pager_pill`（‹ n/m › 分页胶囊）/ `bottom_nav`（三 Tab 底栏）。
移动端惯用结构直接参考 `wireframe_lib.py` 底部的 `demo()`。

## 嵌入报告前必做自检

1. 拼 contact sheet（每行 4 张、缩至 ~340×756）。
2. `analyze_image` 逐张查：文字/元素出界、重叠遮挡、徽标压字贴边、图形畸形（尤其 FAB 圆形——
   坐标表达式写错会画出怪椭圆）、缺字方块。
3. 修完重画 → 再拼一次抽查修复页，然后才允许进报告。
