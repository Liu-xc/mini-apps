# 02-wireframes — 驿站（posthouse）

> 菜单栏应用无窗口界面；「线框」= 菜单展开结构与三条交互路径。W 编号即菜单区域。

## W1 菜单栏常驻（唯一入口标识）

```
[🔥 1]            ← 三态图标 + 异常计数（全绿无计数；狼烟/熄火带计数）
```
- 位置：macOS 菜单栏右侧系统图标区；LSUIElement 无 Dock 图标。

## W2 下拉菜单全貌

```
W3  2 仓在守 · 狼烟 1 · 探测 16:04          ← 概览行（静态文本）
─────────────────────
W4  ▼ mini-apps   main ↑0 ✎2                ← 每仓一个子菜单（图标+状态）
      ├ 推送 N 个提交 / 无积压可推（disabled）
      └ 在访达中打开
    ▼ mini-games  main ↑51 ↓116
      └ …

      立即探测全部
      网络诊断（network-rescue）…            ← 终端跑 network_doctor.sh

      <最近推送结果文本>（有则显示）
─────────────────────

      ☐ mini-apps    ☐ mini-games            ← 默认全关

      立即生成今日邸报

```

## 交互路径

1. **看火情（被动）**：瞥 W1 → 展开 W2 概览行 W3 → 按需看 W4 仓明细。无操作成本。
2. **处置积压（主动）**：W4 子菜单「推送 N 个提交」→ 安全校验（behind 拦截即弹通知说明）→
   推送结果通知中心 + W5 结果文本。分支：远端不通/分叉 → 通知引导（分叉自行处理、
   网络问题走 W5 网络诊断入口）。
3. **战报与成就（定时）**：每晚 22:30 自动生成 → 通知带路径 → W6「打开邸报目录」看战报；
   或 W6 手动即时生成（验收/补发用）。

## CLI 等价路径（与菜单同代码）

`--probe`（=W5 立即探测的文本版）、`--push <path>`（=W4 推送）、`--gazette`（=W6 手动生成）。

## 配置外置

无 GUI 设置页（M1 决策）：W2 末项「打开配置…」直达 config.json。
