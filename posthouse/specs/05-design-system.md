# 05-design-system — 驿站（posthouse）

> 菜单栏应用，遵循根 [`DESIGN.md`](../../DESIGN.md) 的触感基线；视觉面极小，token 从简。

## 菜单栏图标（唯一常驻视觉）

| 态 | SF Symbol | 附加 | 颜色语义 |
|---|---|---|---|
| ok | `circlebadge.fill` | — | 系统默认（中性） |
| backlog | `flame.fill` | 右侧计数 = 异常仓数 | 火=需处理 |
| unreachable | `bolt.slash.fill` | 右侧计数 | 断=熄火 |

聚合规则：任一熄火 > 任一狼烟 > 全绿（Arrays+RepoStatus 扩展 `overallBeacon`）。

## 菜单结构（menuBarExtraStyle `.menu`）

```
<聚合概览行>                 "2 仓在守 · 狼烟 1 · 探测 16:04"
──────────
▼ <仓名>（子菜单）           图标 + summaryLine（branch ↑↓✎）
    ├ 推送 N 个提交 / 无积压可推（禁用态）
    └ 在访达中打开
──────────
烽火台                        立即探测全部 / 网络诊断（network-rescue）… / 自动推送总开关 / 最近推送结果
自动推送白名单                 每仓 Toggle（仅列有远端的）
邸报                          立即生成今日邸报 / 打开邸报目录
──────────
打开配置… / 打开日志… / 退出驿站
```

仓库行点名称=打开目录，推送在子菜单（避免误触）。

## 通知文案（osascript 通知中心）

- `✅ <仓> 已推送` / `⚠️ <仓> 推送被拒（non-fast-forward）` /
  `🔀 <仓> 分叉` / `🔑 凭证失败` / `疑似代理故障` / `📜 今日邸报已送达`。
- 副标题统一「驿站 posthouse」；去重规则：分叉与代理故障各按周期只提醒一次。

## 邸报 Markdown 版式

`# 📜 驿站邸报 · yyyy-MM-dd` → 引语（生成时刻+连续活跃）→
`## 今日概览`（无序列表）→ `## 分仓战况`（表：提交/fix/feat/docs·spec/积压清零）→
`## 烽火传递`（时间戳列表）→ `## 今日成就`（emoji + 名称 + 细节）→ 分隔线 + 署名。
成就为空时显示斜体占位「今日无新成就，养精蓄锐。」

## 动效

菜单为系统 menu，不自定义动效（系统渲染）。不做进场/落地动画——保持原生感是本应用的质感选择。
