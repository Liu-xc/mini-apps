# 01 — 用户故事与验收标准

编号规则：US-n 本应用用户故事；UC-n 是其下可验收行为。与 [it-001](iterations/it-001-emotional-lottery-demo.md) 对齐。

## US-1 图片种子选号

- **UC-1.1** 未选图时生成按钮禁用，空态有图形 + 行动按钮（DESIGN §5.8）。
- **UC-1.2** 选图后显示缩略图 + 种子指纹（SHA-256 前 16 hex，分组显示）。
- **UC-1.3** 同图 + 同玩法 + 同主区个数 + 同批次（take）→ 号码恒相同；「再换一批」仅递增 take 得新号（单测钉死）。
- **UC-1.4** 号码落定有 stagger + pop 弹簧动画，落定瞬间一次轻触感；生成过程 ≤ 800ms。
- **UC-1.5** 复式：主区个数可调，实时显示注数 = C(m1,n1)×C(m2,n2)；超出档位禁用。
- **UC-1.6** 生成结果可「存入票夹」「导出图片」「再换一批」。

## US-2 开奖复现

- **UC-2.1** 开奖页默认选中最新一期（当日非开奖日则顺延至最近已开奖日），可左右切历史期。
- **UC-2.2** 「复现开奖」进全屏剧场：暖场翻滚 → 主区逐球出槽 → 换球 → 特号出槽 → 验票揭晓；总时长 ≤ 12s，提供「跳过」。
- **UC-2.3** 球在罐内是真实感受的物理运动（重力 + 壁面 + 球球碰撞 + 罐旋转摩擦），出球路径带弧线、落槽 pop 弹簧 + 触感。
- **UC-2.4** 特号与主区颜色区分（双色球红/蓝、大乐透前/后），换球有明确过渡节拍。
- **UC-2.5** 全程标注「演示数据 · 非官方」。
- **UC-2.6** reduce-motion（系统动画缩放 = 0）时直接呈现结果态，不播长编排。
- **UC-2.7** 中奖才有印章 + 彩屑（≤900ms）+ 确认触感；未中只给平静文案，永不庆祝。

## US-3 验票

- **UC-3.1** 单式按官方奖级表判一级（双色球 6 级 / 大乐透 9 级），单测覆盖每一级。
- **UC-3.2** 复式逐注展开判定，聚合各级中奖注数与「中奖总注数」，展开上限防爆（≤ 50,000 注）。
- **UC-3.3** 票夹列表即时显示每票状态（未开奖 / 中 N 等 / 陪跑）。

## US-4 导出购票图

- **UC-4.1** 票详情一键导出竖版图片到相册 `Pictures/拾彩/`（MediaStore，零权限），成功给 snackbar + 触感。
- **UC-4.2** 导出图与详情预览同渲染器（同一 `TicketCard` composable 录制），含玩法、期号、号码、种子指纹、注数、生成时间。
- **UC-4.3** 删除票必须可撤销（undo snackbar）或二次确认，二选一。
