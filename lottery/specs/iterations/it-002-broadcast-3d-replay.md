# it-002 — 拾彩：开奖复现重做（直播级 3D 摇奖机 + 演播室视觉 + 全站美化）

状态：**已授权开工（2026-09-30 用户验收反馈直接下需求：「动画完全不对，要直播里那种摇奖机与布局；没用 3D 技术；页面丑，无法接受」）**
日期：2026-09-30

## 背景与动机

it-001 交付后用户实测开奖复现，三条批评全部成立：

1. **动画概念错误**：现实现是俯视 2D 圆鼓 + 拨片 + 球飞向卡槽。用户要的是**开奖直播里的那种摇奖机**——
   透明玻璃球摇奖机、里面号码球被气流吹得乱飞、球从底部出球口落下进轨道排开、红球机/蓝球机切换、
   直播式的运镜与解说节奏。
2. **没有 3D**：原始需求就写了「尽量用开源渲染/3D 引擎」，it-001 ADR-002 选择了 Compose Canvas，
   实际观感撑不起「复现直播」的承诺。本次正面引入 **Filament**（Google 开源 PBR 引擎）。
3. **整体视觉不合格**：编辑部纸感（衬线标题 + 灰米纸）与「彩票开奖」的情绪世界不匹配，
   需要一套「福彩演播室」身份：中国红 + 金 + 深蓝舞台 + 票据质感。

## 用户故事

- **US-2R（重做）直播式开奖复现**：进入复现后是一场「转播」：
  - 顶部 LIVE 角标（脉冲）+ 期号台标 + 「演示数据 · 非官方」诚实标注 + 跳过；
  - 深蓝演播室舞台，聚光灯锥，**3D 玻璃球摇奖机**（Filament 渲染：磨砂底座、玻璃球壳、
    号码球带白底号码盘、气流搅动、出球口）；
  - 出球时「切镜」：3D 球坠出 → 底部 2D 出球轨道上号码球滚入对应槽位，大号读数 + 解说字幕
    （「第 3 个红球 · 17」）；
  - 红球出完**切蓝球机**（换机动画：聚光灯切换 + 机台标签变化），蓝球单独出球；
  - 全部出完：号码板金色扫光 → 验票卡（中奖印章/彩屑，非中奖不庆祝）→ 关闭。
  - reduce-motion（系统动画缩放 0）时直接落到号码板 + 验票终态（红线不变）。
- **US-5 视觉身份升级**：全站换「福彩演播室」皮肤——暖票纸底 + 福彩红 + 金线 + 深蓝舞台；
  号码球 2D 绘制升级为「白底号码盘 + 镜面高光 + 边缘光」的印刷品质感；选号/开奖/票夹/详情
  按新身份重排（大标题层级、票据卡、金色分隔）。

## 验收标准

1. `./gradlew assembleDebug` / `testDebugUnitTest` 绿（核心逻辑不动，27 测保持绿）。
2. 复现剧场含 **Filament 3D 场景**（玻璃机内 ≥20 颗号码球实时搅动、透视相机、灯光），
   出球→轨道滚入→大号读数→换蓝球机→验票全链路可走通；跳过、reduce-motion 直落终态。
3. 直播式布局元素齐备：LIVE 角标、期号台标、解说字幕条、出球轨道、号码板、诚实标注。
4. 全站视觉对表新 05-design-system（红金票纸 + 深蓝舞台 token 落到每一屏，反例清单无违例）。
5. 模拟器走查截图回填本文件「验证记录」；DESIGN.md §2–§5 对表结论一并回填。
6. APK 可安装启动（新增 native 依赖后真机可跑为最终判据；模拟器 SwiftShader 可跑即可）。

### Hotfix 2（同夜，真机二轮反馈：卡顿 + 缺出球过程）

- **卡顿根因**：时钟 State 在组合作用域读取 → 每帧整树重组 + 每球每帧 TextMeasurer 排版。
  **修法**：时钟只在 Canvas/graphicsLayer 绘制 lambda 内读；语义状态（字幕/计数/读数）仅值变才写；
  号码排版与渐变刷按 (颜色,号码) 缓存，热路径零分配。
- **补出球旅程**（用户：「球要滚到下边儿」）：新增 T_FLIGHT=640ms 飞行段——机内吸顶（加速收拢）
  → 冲出出球口 → 三次贝塞尔弧线（上抛出管再落槽）+ 拖尾残影 → 落槽弹跳（bouncy）→ 大号读数。
  飞行层为根级 Canvas，出球口/槽位坐标经 onGloballyPositioned 捕获。

### Hotfix（2026-09-30 深夜，真机验收反馈）

- **现象**：真机一进剧场即「开奖结束」，无动画。
- **根因**：用户手机系统「动画时长缩放」为 0（开发者选项/ROM 省电常见），旧代码将其当作
  减弱动态红线 → 整场直达终态。
- **修法**：剧场是**内容而非装饰**——animator=0 也照常播时间轴；reduceMotion 只关装饰动效
  （彩纸/LIVE 脉冲/落球弹簧改瞬时）。跳过只走「跳过」按钮。模拟器 animator=0 实测剧场正常播放。
