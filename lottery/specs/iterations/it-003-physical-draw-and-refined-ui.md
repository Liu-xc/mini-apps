# it-003 — 拾彩：物理摇奖与精致界面

状态：用户已于 2026-09-30 回复「实施」确认；实现完成，模拟器验证通过；真机性能与用户视觉体验待验。
日期：2026-09-30

## 背景与动机

用户反馈 UI、动画无法接受，摇奖机缺少真实世界的物理感觉。核心价值是期待、悬念、揭晓的情绪体验，因此本次按体验重做，而非局部换色。

### 已核实的问题

- `CanvasStage.fly` 用正弦轨迹直接指定位置，没有速度积分、重力或球球/球壁接触；静止时全部球同点重叠，无法形成自然堆积。
- `ReplayOverlay.FlightLayer` 用三次贝塞尔将球上抛到槽位，缺少实体管道、重力加速、轨道摩擦与滚动；槽位用缩放弹簧替代接触停稳。
- 当前舞台启用 Canvas；Filament 虽在工程内，但未启用，且使用 UNLIT 材质及同类编排轨迹，单纯切换并不能解决物理与材质问题。
- 舞台整体 sway/breathe 让机器本体无缘由移动；号码盘始终朝向观众，缺少球体旋转。
- 固定 44dp 槽位加间距与分隔，双色球轨道约 377dp 宽，叠加左右边距在窄屏存在溢出风险。
- 现有时间轴实际约 19秒，与常青规格 ≤12秒不一致。旧截图中名为红球机的文件实际显示选号页，不能作为剧场验收依据。

## 用户故事

- US-2 / UC-2.2–2.4：观看有重量、接触、连续运动的摇奖全过程；等待有节奏，号码揭晓清楚。
- US-5：选号、开奖、票夹、详情具有统一且精致的票据视觉，减少表单与装饰堆叠感。
- 新增 US-6：反复观看仍流畅，跳过、后台恢复、窄屏与减弱动态均有明确行为。

## 方案

### 1. 真实三维物理状态

建立与渲染器独立的纯 Kotlin 固定步长模拟：位置、线速度、角速度、朝向、球半径；重力、局部气流、阻力、球球碰撞、球壳碰撞、摩擦与非完全弹性恢复。采用子步与接触修正，防穿透与能量爆炸。初始化球自然堆在下部，风机逐渐启动，形成下部上升、壁面回流的不规则翻滚；停机后重新沉降。本体固定。

开奖号由现有数据确定，物理只负责复现：目标球在出口附近平滑进入捕获阶段，身份、位置、大小与速度连续传递到管道，不瞬移、不宣称物理决定号码。

### 2. 连续出球机械链

统一世界坐标描述球壳、出口、透明导管、倾斜轨道和终端挡块。球被捕获后沿导管运行，进入轨道受重力切向分量驱动，旋转与行进距离相符；碰挡块有小幅回弹，随后摩擦停稳。删除空中飞往独立槽位的抛物线、拖尾与缩放落球。出球号码在停稳时出现一次轻触感。

### 3. 渲染与质感

优先修复并验证现有 Filament 生命周期及资源线程约束，再启用真 3D：透视、稳定相机、号码贴图随球旋转、哑光号码球、金属底座、克制透明球壳、环境光及接触阴影。玻璃不以高亮圆环冒充。Canvas 降级共用同一物理状态与管轨几何；不能把降级版记作 3D 验收通过。

若原生渲染仍不稳定，记录崩溃证据与实际交付路径，不自行以截图或接入依赖判定完成。依赖升级如必要另记 ADR。

### 4. 界面方向：收藏票据 + 精密机械

普通页面用暖白纸、石墨字、细分隔；红只用于主动作与球号，金仅作极少量材质细节。恢复展示标题与正文的层级，取消全站粗黑字、按钮金描边和重复 chip。

- 选号：图片种子作为视觉中心，玩法与单复式收成紧凑配置行，生成后展示完整票面；主动作与次操作清楚分级。
- 开奖：以机器静态预览为主内容，期号与日期并排，单一「开始开奖」入口；演示标注明确且克制。
- 剧场：顶栏分两行避免挤压；机器占主体、导管与轨道真实可见，号码板与字幕占辅助位置；背景为中性深墨，无舞台光锥、金框堆叠和无限脉冲。
- 票夹/详情：统一票根比例、编号、撕线、号码排布与图片种子缩略图；详情与导出保持同一渲染源。
- 深浅主题与 320–430dp 手机宽度均自适应，复式号码换行。

### 5. 节奏与无障碍

完整仪式目标 18–22秒（更新原 ≤12秒约束，以完整滚动旅程为理由），点击后 <100ms 反馈，随时跳过至结果；不增加额外暖场倒计时。只有摇奖主体自主运动。系统动画缩放为0沿用 it-002 的内容播放约定，关闭装饰弹簧；新增应用内「简化开奖」直接展示号码及验票结果。后台暂停，返回后继续，不补算巨大时间步。全 App 维持零音效。

## 验收标准

1. 物理单测覆盖球球/球壁接触、静止堆积、停风沉降、长时运行数值稳定及确定性复现；状态始终有限且无明显持续穿透。
2. 录屏可逐帧观察：静止堆积 → 风机启动 → 不同步碰撞翻滚 → 捕获 → 导管 → 滚动 → 挡块回弹 → 停稳；全程同一球连续运动，无瞬移、大小跳变或球体重叠成一团。
3. Filament 路径实际启用后连续完整重播三轮，退出重进及后台恢复零原生崩溃；渲染路径以运行证据核实。真机未验则明确标未验。
4. 选号、开奖、剧场、票夹、详情及导出逐屏截图；320dp窄屏、常用宽度、深浅主题均无截断、轨道越界及操作不可达。
5. 目标设备正常播放接近60fps，提供帧耗时统计与卡顿记录；不能仅以构建成功判动画通过。
6. 跳过、重复进入、简化开奖、后台恢复通过；中奖才庆祝，演示标注保留。
7. `assembleDebug` 与 `testDebugUnitTest` 成功；按 DESIGN §2–§5 回填评审，视觉质量需用户体验验收。

## 实施结果与边界

- 球群使用120Hz固定步长、四轮接触求解，重力、局部气流与阻力驱动速度，号码贴图跟随球旋转；球壳与号码球、金属底座通过Filament LIT材质实际绘制。
- 同一球从球堆捕获到出口、沿可见管道、斜轨滚动、挡块回弹与停稳；球位置不在不同动画组件间复制。为了复现指定的演示结果，捕获及管轨采用受约束的连续路径，尚非全程刚体管壁接触求解。球群碰撞为实际积分；不宣称精确真实设备的空气动力学。
- 透明球壳是Fresnel透明材质，阴影为投影近似；未实现光学折射与全场实时接触阴影。Canvas绘制管轨及首次GPU准备阶段的静态预览，正常播放的球体为实际3D。
- 页面采用暖白票纸、石墨字、低饱和红、细分隔与深墨剧场；复式号码自动换行，去除金描边/舞台摇摆/无奖庆祝。照片缩略图保留在当前选号页；历史票继续保存种子指纹，本迭代不扩充照片持久化。
- APK版本0.2.0(2)。保留原Filament1.57.1，删除运行时材质编译器依赖；材质源码与匹配版本的预编译产物入库，ADR-007记录。
