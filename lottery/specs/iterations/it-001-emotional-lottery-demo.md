# it-001 — 拾彩（lottery）：情绪价值彩票 demo（MVP 全闭环）

状态：**已完成（2026-09-30，构建/单测/走查全绿，见「验证记录」）**
日期：2026-09-30

## 背景与动机

Leo 常错过彩票直播开奖，损失了买彩票最核心的**情绪价值**；同时希望选号这件事本身
也有仪式感。需求两条腿：

1. **选号**：选玩法（双色球 6+1 / 大乐透 5+2，支持复式）→ **上传一张图片作种子**生成
   随机号码（本期不做手动指定号码）→ 导出为一张图片，去彩票店照着买。
2. **验票 + 开奖复现**：每天在 App 里看当日开奖号码；**看的过程用动画把开奖直播复现一遍**，
   把错过的仪式感补回来；顺手验自己票夹里的票。

业务本身极简单（生成 → 开奖 → 验票三步），**全部预算砸在交互与动画质感**上。

- 名字：**拾彩**（目录 `lottery`）——「把错过的开奖、把随手的好运，都捡回来」。
- 平台：**Android 原生 Kotlin + Compose**（Leo 拍板：先以安卓原生为准；不走 WebView）。
- 动画渲染：**Compose Canvas（Skia）+ 手写确定性物理与编排**，不引第三方 3D/Lottie 引擎
  （理由见 06-decisions ADR-002；仓库零新依赖原则 + 一夜 demo 的确定性）。

## 用户故事（本迭代范围）

- **US-1 图片种子选号**：选玩法 →（复式时选主区个数）→ 选一张图片 →「生成号码」，
  号码带出现动画落定；同一张图 + 同一玩法 + 同一批次（take）**恒生成同一组号**（可复现），
  「再换一批」换批次出新号。
- **US-2 开奖复现**：开奖页选期号（默认最新一期）→「复现开奖」进入全屏剧场动画：
  摇奖罐物理翻滚 → 逐个出球落槽（主区 → 换球 → 特号）→ 揭晓我票夹里该期票的验票结果，
  中奖给印章 + 彩屑。可跳过。
- **US-3 验票**：存入票夹的票在开奖后自动显示奖级（单式与复式都按官方奖级表逐注判定，
  复式聚合每级注数）。
- **US-4 导出购票图**：票详情把票渲染成一张竖版图片（含玩法、期号、号码、种子指纹、注数）
  存入相册 `Pictures/拾彩/`，去店里对着买。

## 验收标准

1. `cd lottery && ./gradlew assembleDebug` 绿；`./gradlew testDebugUnitTest` 绿。
2. 三屏（选号 / 开奖 / 票夹）+ 票详情全流程可点通：选图→生成→存票→复现开奖→看验票结果→导出图片成功（相册可见）。
3. 同一张图重复生成同批次号码一致（单测覆盖）；奖级判定与官方规则一致（单测覆盖各奖级）。
4. 开奖复现动画：物理翻滚、逐球出槽、特号换色、跳过按钮、中奖印章/彩屑、非中奖不庆祝；
   reduce-motion（系统动画缩放 0）时直接落到结果态。
5. 截图走查按 DESIGN.md §2–§5 对表，结论回填本文件「验证记录」。
6. 界面有「演示数据 · 非官方」诚实标注（开奖数据本期为本地确定性演示数据）。
