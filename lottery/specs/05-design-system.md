# 05 — 设计系统（it-003 收藏票据 + 精密机械）

基线见根[DESIGN.md](../../DESIGN.md)。普通页面以照片、号码和票面为主角；剧场把拟物预算集中在机器、球体和滚动，不铺金框、光锥或无限脉冲。

gold：#9B895E / #D6B35F，仅少量票据或中奖语义，按钮不描金。
玩法内容色：双色球红#E0342B、蓝#2264D8；大乐透前#2E8A54、后#E8962E；号码盘暖白、石墨字。

## 排版与形状

Display：Serif SemiBold 28sp（displayMedium 34sp），仅展示标题；Title 20/17sp，Body 15/14sp、说明12sp，标签11sp。正文Sans。
屏边20dp；卡片20dp、票面18dp、按钮16dp；分段控件44dp高，选中石墨底暖白字；强调朱红只给主要操作。
禁用按钮用hairline底与inkFaint字，避免粉底白字低对比。导航选中底为ink 5.5%，取消粉色胶囊。
普通页面不叠加系统栏insets；票面号码使用FlowRow，动画不改变布局占位。

## 舞台与材料

固定舞台深墨#293538→#151D20，正文#F3F2E9，次字#AAB6B5；台标两行，演示标注独立，不挤一行。
Filament默认启用：LIT哑光号码球（roughness .48 / reflectance .35）、旋转UV盘、金属底座（metallic .75 / roughness .38）、Fresnel透明球壳（roughness .10）。透明色使用预乘alpha，不用白色面片覆盖球色。
透视相机固定，近远大小与遮挡由3D产生；导管/轨道/玻璃高光及底影由Canvas同坐标绘制。球壳目前是透明近似，非光学折射模拟；机械导管为二维投影几何。
号码板是独立可读的结果区域，物理球保持恒定世界半径，不为了可读性在旅途中放大。舞台区域高度固定，揭晓不改变机器大小。

## 动效与触感

- 主运动：1/120秒三维碰撞模拟；空气启动、自然翻滚，球进入管轨后按连续受控路径滚动、回弹、停稳。
- 内容时长两玩法约20秒；GPU首帧就绪后计时，初入先显示静止球堆，随时跳过。
- 选号滚码约260ms、stagger22ms、末态180ms落定；不改变号码格占位。
- 普通导航crossfade220ms；返回/重播不新增入场编排。
- 每球停稳轻触感；保存/导出Confirm；中奖暖金结果标记与Confirm。未中平静文案，不使用印章弹跳或彩屑。
- 全App零音效。

## 偏移与无障碍

1. 剧场是单一深墨内容层，可关闭；普通页面仍为纸感同构。
2. 内容编排约20秒为开奖仪式例外；跳过与「简化开奖」随时可用。
3. 沿用it-002的内容/装饰区分：系统动画缩放0不跳掉开奖内容，关闭装饰动效；应用内简化开奖直接显示结果并不加载3D。此偏移在根DESIGN同步声明。
4. 后台暂停、配置重建恢复同一时间；弱设备不以无限catch-up的大时间步推进物理。
