# 05 — 设计系统（拾彩个性层）

基线红线见根 [DESIGN.md](../../DESIGN.md)（不可破）；本文件只声明**个性**与实现值。

## 个性定位：开奖仪式（broadcast ritual）

家族纸感骨底上，把**摇奖现场**的语义搬进界面：玩法红蓝是**内容色**（球的颜色），
界面强调克制；剧场段落允许一次「墨幕」沉浸（对基线的偏移，见 §4）。

## Token（六个语义 + 玩法内容色）

| token | light | dark（墨绿纸同构，非反转） |
|---|---|---|
| paper | `#F5F4F0` 暖纸 | `#15171A` |
| surface | `#FFFFFF` | `#1E2126` |
| ink | `#1A1A18` | `#F2F1EC` |
| inkFaint | `#6A685F` | `#A9A79E` |
| accent | `#C7372F` 朱红（CTA/选中 <10% 面积） | `#E0645B` |
| hairline | `#E2E0D8` | `#33363C` |

**玩法内容色**（不属于 accent 预算，是「球」的内容）：
SSQ 红球 `#D84B40`（渐变高光 `#E8756B`）、SSQ 蓝球 `#3A6FD8`；
DLT 前区 `#2F7A4F`（官方前区球绿）、后区 `#E0A93E`？——否：**DLT 后区用橙金 `#E08A2E`**
（与大乐透后区球色一致），前区墨绿 `#2F7A4F`。金评分色是 eats 的，不冲突（不同 App）。

剧场墨幕：`#141513`（**非纯 #000**，DESIGN §5.5）+ 球体自发光晕染。

## 排版

家族基线不变：Display 衬线 28–34sp（页大标题「拾彩/开奖复现」）、Body Sans 15sp、
Label 11sp 0.2em（期号/批次这类印刷小标签）。号码球数字用 Sans semibold（球面印刷感，
不做衬线）。

## 动效（EditorialMotion 落值）

| 动效 | 参数 | 归属 |
|---|---|---|
| 号码落定 | `pop`（damping .72 / stiffness 500），stagger 40ms | 随机落定（bouncy 合法区） |
| 出球弧线飞入槽 | tween 520ms + `pop` 落槽 | 剧场节拍 |
| 槽位翻牌 | tween 180ms 翻入 | 细节 |
| Tab 切换 | crossfade 220ms | 家族基线 |
| 印章 | scale 1.4→1 + `bouncy` 落定，仅中奖 | 庆祝特权 |
| 彩屑 | ≤900ms，仅中奖 | 庆祝特权（DESIGN §3） |

节奏预算：选号生成 ≤800ms；剧场总长 ≤12s（**声明式首演例外**：沉浸剧场类同 darkroom
显影全程，一次性仪式，必给「跳过」）；reduce-motion 直接落终态。

## 触感与声音

出球落槽：轻触感一次/球（抽中落定类）；存票/导出成功：`Confirm`；中奖印章：`Confirm`；
报错：DoubleTick。**全 App 零音效**（DESIGN §4）。

## 对基线的偏移声明

1. **剧场墨幕**：开奖 overlay 用 `#141513` 深墨沉浸（类电影院黑幕），仅此一层、可退出、
   有跳过；界面主体仍是纸感。同构原则：深墨 + 暖白字 + 玩法内容色，非纯黑白。
2. **首演时长例外**：剧场 ≤12s 自主编排，换「跳过 + reduce-motion 降级」两重保护。

## 空态

W1 未选图：图形（虚线票券 + 图片山图标）+ 行动按钮；W3 空票夹：图形（票根插画）+
「去选号」按钮（DESIGN §5.8）。
