# 02 — 线框与交互路径

导航壳：底部三 Tab（**选号 W1 / 开奖 W2 / 票夹 W3**），crossfade 220ms（DESIGN §3）；
票详情 W4 为压栈全屏页（返回回 W3）；开奖剧场为 W2 上的全屏 overlay（跳过/关闭退出）。

## W1 选号

```
[顶栏: 拾彩]
(玩法)  [ 双色球 6+1 ] [ 大乐透 5+2 ]     ← segmented
(玩法)  [ 单式 ] [ 复式 ]                 ← 复式时展开主区个数 stepper（− n +）
        注数实时: N 注
(种子)  ┌────────────────────────────┐
        │ 未选图: 插画 + 「选一张图片当种子」按钮
        │ 已选图: 缩略图 | 种子指纹 a1b2… | 「换一张」
        └────────────────────────────┘
[ 生成号码 ]   ← 未选图禁用
(结果区, 生成后)
        (●●●●●●) 主区 balls（落定动画）  (+ ○) 特号
        第 k 批 · 种子指纹 · N 注
        [ 存入票夹 ] [ 导出图片 ] [ 再换一批 ]
```

交互：生成 → 号码 scramble 约 500ms 后 stagger pop 落定；「存入票夹」后跳 W3 或 snackbar
提示可继续（demo：snackbar + 不跳）。「再换一批」take+1 重新落定。

## 关键状态与边界

- 选图后未生成：结果区隐藏，CTA 就绪。
- 该期无票：剧场揭晓段只显示开奖号码 + 「本期暂无票」。
- 生成后切玩法/复式档位：结果区失效（显示需重新生成），种子指纹保留。
- 导出失败（理论上不发生）：snackbar 报错 + DoubleTick 触感。
