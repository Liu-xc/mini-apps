导航壳：底部三 Tab（**选号 W1 / 开奖 W2 / 票夹 W3**），crossfade 220ms（DESIGN §3）；

后台暂停；简化开奖只呈现终态；普通系统动画缩放不截断内容序列。

## 关键状态与边界

- 选图后未生成：结果区隐藏，CTA 就绪。
- 该期无票：剧场揭晓段只显示开奖号码 + 「本期暂无票」。
- 生成后切玩法/复式档位：结果区失效（显示需重新生成），种子指纹保留。
- 导出失败（理论上不发生）：snackbar 报错 + DoubleTick 触感。


## it-003 页面修订

W1顺序改为：页标题 → 灵感图片（空态行动/已选缩略图）→ 玩法 → 单复式与注数 → 生成 → 同源票面 → 存票/导出/换批。
W2顺序：页标题 → 玩法 → 期号与日期 → 演示标注 → 静止机器预览 → 简化开奖开关 → 开始开奖/再看一次 → 号码/验票。
W3沿用收藏列表，统一票据色彩与文字层级；W4沿用票面预览，操作纵向排列适配窄屏；复式票面换行。
图片缩略图只存在于当前选号阶段，历史票继续凭种子指纹识别，不增加照片持久化。
