# 00 — 业务背景与核心价值流

## 定位

**拾彩（lottery）= 情绪价值优先的彩票 companion**。围绕中国福彩**双色球（6+1）**与体彩
**大乐透（5+2）**两玩法，只做三件事：

1. **选号**：上传一张图片当种子，确定性地生成随机号码（单式 / 复式），导出成购票图片；
2. **开奖复现**：错过直播不要紧——用剧场级动画把当日开奖过程在手机里重演一遍；
3. **验票**：票夹里的票按官方奖级表逐注判定，开奖后自动亮出结果。

一句话定位：**错过的开奖，动画还给你**。

- 不是购彩平台（非投注站）：不联网下单、不代购、不承诺收益；演示期开奖数据为本地
  确定性数据并全程标「演示数据 · 非官方」。
- 不是数据工具：奖级、走势、统计都不是重点；**仪式感才是**——选号有惊喜、开奖有剧场、
  中奖有印章。

## 核心价值流

```
选号（W1）：选玩法 双色球/大乐透 → 单式/复式（复式选主区个数）
  → Photo Picker 选一张图 → 解码 64×64 ARGB → SHA-256 = 种子指纹
  → Generator(seed, game, zoneSizes, take) 确定性出号 → 落定动画 → 存入票夹 / 导出购票图
开奖（W2）：选期号（默认最新一期）→ 全屏剧场：摇奖罐物理翻滚 → 主区逐球出槽
  → 换球 → 特号出槽 → 验票揭晓（票夹该期票亮结果；中奖印章 + 彩屑）
票夹（W3）：票列表（状态：未开奖 / 中奖 / 陪跑）→ 票详情（W4）→ 导出图片到相册
```
