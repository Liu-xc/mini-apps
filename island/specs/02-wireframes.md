## 交互路径

| 触发 | 行为 |
|---|---|
| 鼠标进入胶囊 | hover 展开（遮罩 spring(response 0.32, damping 0.9)，60ms 防抖） |
| 鼠标移出（未固定） | 收起（180ms 防抖；光标仍在可见卡片内不收） |
| 点击胶囊 | 固定展开 / 取消固定并收起 |
| 点击胶囊外（固定时） | 取消固定并收起 |
| ⟳ | 手动刷新（在途 1s 线性旋转，hover 高亮） |
| ⚙ | 打开设置窗口（激活 App） |
| 面板「去设置」 | 打开设置窗口（未配置引导） |
| 菜单栏图标 | 按源分组摘要 / 刷新 / 演示模式 / 设置 / 控制台 / 退出；图标=健康度色条 |
| 首启未配任何源 | 自动展开 + 双面板空态引导 |
| 屏幕参数变化 | 窗口帧按 IslandLayout 重新对位（贴新屏刘海） |
