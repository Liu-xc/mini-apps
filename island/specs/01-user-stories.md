# 01 — 用户故事与验收标准

## US-1 默认隐藏 + 刘海触发
**窗口永久固定为展开尺寸、永不改变大小**：可见区域由圆角遮罩驱动——hidden 态遮罩 =
刘海挖槽尺寸（180×safeTop，与黑区融合不可见），contentView hitTest 在遮罩外返回 nil
（事件穿透，菜单图标照常可点）。鼠标移到刘海 → **遮罩从刘海向下生长**（动画展开）；
移开对称缩回；点击可固定、点击外部收起。不抢键盘焦点；切空间/全屏 App 仍在。

**AC**：hidden 态窗口几何恒定（bounds 永不变化）且视觉完全隐形；hover 刘海一次展开零振荡；
展开/收起全程无黑条闪现、无横向位移（窗口几何恒定）；其他 App 前台打字不中断。

## US-2 展开卡片
从刘海中心向下生长：顶边贴屏幕顶沿（无标题栏，高度 = 刘海避让 + 档数；第三档 other 出现时加高），
内容 = 每档明细行（档位名 / 剩余% / 进度条 / 重置时间；**MCP 档不展示**）+
页脚「x 前已刷新」+ 刷新/设置按钮。剩余 ≤20% 转橙、=0% 转红。
未配 Key 时首启自动展开引导。

**AC**：三种交互全可用；动画无跳帧残影；数据与控制台同刻 ±1%。

## US-3 自动刷新
默认 5 分钟轮询官方接口（间隔可配 1/2/5/10/15/30）；失败指数退避（2^n，封顶 8×）；
快照落盘，重启/断网先显示陈旧数据；支持手动刷新；401 明示 Key 失效。

**AC**：断网显示陈旧快照 + 失败文案；恢复后下一轮自动刷新成功。

## US-4 剩余量语义
全部展示**剩余量**（接口 percentage=已用，剩余=100−已用）；行颜色恒定为档位身份色，
**不做预警变色**（Leo 明确）。数值本身就是状态：0% 即用尽，重置时间随行展示。

**AC**：阈值状态机单测覆盖（20/1/0 边界）。

## US-5 设置与安全
API Key 只存 Keychain（不入文件/日志）；设置窗口：平台端点（自动/bigmodel.cn/z.ai）、
刷新间隔、演示模式、开机自启（SMAppService）、控制台链接、诊断（原始响应查看/拷贝）。
菜单栏图标：用量摘要 / 立即刷新 / 演示模式 / 设置 / 打开控制台 / 退出。

**AC**：缓存文件与日志中无 Key；自启开关即时生效（.app 形态下）。

## US-6 离线韧性
断网、超时、解析失败均不崩溃；胶囊继续展示；解析宽松降级（字段缺失显示 --%）。

**AC**：malformed JSON / 空 limits / envelope 错误均有单测。
