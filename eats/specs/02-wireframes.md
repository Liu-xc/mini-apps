# 02 · 线框交互图（提案基线）

> 界面编号 W1–W6，与 [01-user-stories.md](01-user-stories.md) 的 UC 对应。用户确认后即为实现基线，实现后以截图对照验收。

## W1 吃什么（Tab1 · 首页）

```
┌───────────────────────────────┐
│  今天吃啥                       │ ← 衬线大标题
│ 类型: (堂食)(外卖)(自做)         │ ← 多选 chips，默认全选
│ 忌口: #辣 #香菜  (＋选标签)      │ ← 排除标签（从已有标签点选）
│ ☑ 排除最近 14 天吃过的   [14▾]  │ ← 开关 + 天数
├───────────────────────────────┤
│         ▼ 指针                 │
│       ╱───────╲                │
│      │ ▓▓▓▓▓▓▓ │              │ ← Canvas 转盘：扇形按类型着色
│      │ ▓▓ ★ ▓▓ │  候选 23      │   中心实时显示掠过的名称
│       ╲───────╱                │
├───────────────────────────────┤
│        [ 🎡 开始转 ]            │ ← 候选<2 时禁用并说明原因
│ （转后）───────────────         │
│  巷子深火锅 ●堂食 ★4 · 3 天前   │ ← 结果卡弹入
│  🔗 美团·双人套餐 ↗             │ ← 有链接时显示，转完直达下单
│  [ ✓ 就吃这个 ]   [ 重转 ]      │
└───────────────────────────────┘
```

- 「就吃这个」→ W6（预填食堂与时间=现在）；「重转」= 排除刚中的项再转

## 交互路径总览

```
[W1 吃什么] ─就吃这个─▶ [W6 记一笔] ─落账─▶ 数据更新（三 Tab 联动）
[W2 地图] ─点marker→ 摘要卡 ─点卡→ [W5 详情]
[W3 列表] ─点行→ [W5] · FAB ─▶ [W4 添加/编辑]（W5 的编辑也进 W4）
[W5 详情] ─记一笔→ [W6] · 在地图上看 → [W2 并定位到该点]
[W4] 位置栏 ─▶ 内嵌选点地图（长按放 pin，确认带回）
```
