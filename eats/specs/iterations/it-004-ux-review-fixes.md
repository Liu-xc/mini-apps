## 背景与动机

2026-09-20 全页面 UX 评审（15 页）坐实 eats 七页共 6 P0 / 7 P1 / 4 P2。核心系统性缺陷：
滑动无线索（C1）、保存不吸底（C2/C4）、键盘避让缺失（C3）、抽取落定按钮不可见（E2-P0，
两轮 uiautomator 复验）、地图 marker 无图例且三色挤冷色区（E3-P0）。

## 变更清单

### O1 · 首页卡组线索 + 抽取落定闭环（E1/E2，C1）

- **E1** 筛选区重构：类型多选 chips 保留（选中带 ✓），忌口标签 + 「排除最近吃过的」开关
  收进「筛选」弹层（角标显示生效数）；省出的行给卡组。
- **E1** 卡组常驻线索：‹ n/m › 卡序胶囊（index 来自 CardDeck controller.current，libs 补
  `currentIndex` 只读属性）+「候选 n 家」计数随筛选即时反馈；堆叠露边保持 14dp 并实测确认可见。
- **E1-P1** 评分语义统一：卡面评分胶囊标注「综合 x.x」，与详情页统计行（综合/均分/次数/上次）
  一套口径。
- **E1-P2** chips 语义分组：类型行与忌口分离（忌口入筛选弹层，见上）。
- **E2** 落定闭环：抽中后卡组收拢让位（同高度位切换），深色强调结果块（ink 底 paper 字）+
  彩屑环绕；「就吃这个 / 再抽」按钮常驻屏内可视区，不再依赖滚动；与底部导航留 12dp。

### O2 · 地图可读性（E3）

- 吸顶图例胶囊：●堂食 ●外卖 ●自做（类型语义色），与「N 条未上地图」入口同行或并列。
- 右上常驻「⌖ 回位」按钮：回到框住全部 marker 的初始视野。
- marker 配色回归 spec W2 基线：堂食=红 / 外卖=琥珀 / 自做=绿，拉开色相
  （改 `EatsPalette` 三枚类型语义色，浅/深两套；spec 05 同步）。
- 摘要卡信息补足：加菜系/标签一行（P1）。

### O3 · 表单吸底保存两态 + imePadding（E7，C2/C3/C4）

- 移除顶栏保存按钮（保留删除）；新增吸底保存栏：
  未就绪态（名称空）→ 描边按钮 + 灰字原因「填名称后可保存」；就绪态 → 实心按钮。
- 吸底栏接 `imePadding()`，键盘弹起时随之上移；表单滚动区底部留出等高占位。
- 必填标识「名称 *」已有，保留。

### O4 · 详情主操作吸底（E5/E6，C3/C4）

- **E5** 「＋ 记一笔今天吃了」移到 Scaffold bottomBar 吸底常驻（移除流内按钮）。
- **E5-P1** 统计行一套口径：`综合 ★x · 均分 x.x（n 次）· 上次 xx`，消除三处星级语义混读。
- **E5-P2** 链接 chip 去掉「打开链接」辅助图标（chip 本身可点）。
- **E6** 记一笔弹层内容列接 `imePadding()`：点花费/感想弹键盘时落账按钮随之上移不被遮挡。

### O5 · 列表筛选收纳单行化（E4，C6）

- 标题下只留单行工具条：搜索框（紧凑高度）｜排序（下拉）｜「筛选」按钮（角标=生效条件数）。
- 类型 chips + 标签 + 「未定位」全部收进底部筛选弹层（未定位不再混在类型 chips 里，语义归位）。
- 搜索框接 `imePadding()`（C3 键盘顶飞底部导航问题一并实测修复）。
- 排序入口随工具条常驻，滚动后可达（E4-P2 解决）。
