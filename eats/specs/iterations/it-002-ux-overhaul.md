# it-002 · 信息流与交互全面升级（第一梯队审美）

- **状态**：进行中
- **提案日期**：2026-09-20
- **范围**：W1–W6 全界面的动效编排、排版层级、微交互与信息流升级；不改变数据模型与功能语义

## 背景与动机

it-001 完成功能闭环后，界面达到"干净可用"但距顶尖 App（Linear / Airbnb / Things 一类）仍有差距：列表无入场编排、列表→详情无共享元素过渡、落账无成功反馈、转盘指针无物理感、地图选点无选中态放大。本迭代以动效编排与信息流为主线做全面升级，共 5 轮"修改→从头 review"。

## 实施步骤（对应 5 轮）

1. **R1 结构性升级**：列表↔详情共享元素过渡、列表瀑布入场 + 滑动删除、落账成功编排（✓ 形变 + 彩屑）、转盘指针拍动（flapper）与中心文案扫掠、地图 marker 选中态
2. **R2 排版与信息密度**：列表行层级重排、详情头部 hero 化、空态插画排版、深色模式对比度
3. **R3 微交互**：按压反馈、星标弹跳、统计数字滚动、chip 选中弹性
4. **R4 信息流**：列表长按快速记一笔、地图↔详情双向流转动线、表单滚动定位
5. **R5 终审**：亮/暗双模式全页面截图验收 + 遗留修复

## 验收标准

- 每轮结束：`./gradlew assembleDebug` 通过 + 模拟器截图 + 视觉模型评审，问题进入下一轮清单
- 出口条件：R5 全页面截图评审无 P0/P1 视觉或交互问题
