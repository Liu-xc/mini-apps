- **线框图**：[reports/2026-09-20-stats-recap-wireframes/](../../../reports/2026-09-20-stats-recap-wireframes/)（W7 回顾页 + 长图版式，确认后落 02-wireframes.md）

## 背景与动机

Visit 数据持续沉淀，但回看入口只有单店详情的时间线——「我平时都吃什么」这个 overview 层的问题没有答案。两件事补上它：

1. **年度食光**：网易云年度报告式的长图（「今年 286 顿 · ¥12,480 · 最爱巷子深火锅 23 次」），数据全部现成，只差聚合 + 渲染；兼顾分享传播。
2. **好久没去提醒**：`lastVisitAt` 派生数据目前只在列表里被动可见；把它变成主动推送——「那家烤肉你 3 个月没去了，想它吗？」。无服务端，WorkManager 本地通知即可。

## 方案

### 阶段A · 统计回顾页（W7）+ 年度食光长图

入口：W3 列表页标题行「食堂 · N 家」右侧加 📊 图标 → W7。

```
┌───────────────────────────────┐
│ ‹ 统计回顾        [今年 | 累计]  │ ← 时间档位切换
│   286 顿 · ¥12,480 · 41 家     │ ← 三大数字（顿/花费/去过）
│ ┌───────────┐┌───────────┐    │
│ │🏆 巷子深火锅││🥈 猪脚饭   │ →  │ ← 最爱 TOP3 横滑卡
│ │23 次 · ★4.8││12 次      │    │    （照片+次数+均分）
│ └───────────┘└───────────┘    │
│ 类型占比  ▉▉▉▉▉▉▉ 堂食 56% …    │ ← 堂食/外卖/自做 比例条
│ 月度节奏  ▁▃▅▂▇█▆▃▁▂▄▅         │ ← 12 柱（今年档）/ 近12月（累计档）
│ 连续记录  🔥 连续 5 天          │
│ [ 🎁 生成年终食光长图 ]          │ ← 主按钮
│ ────────────────────────      │
│ 回忆提醒        （阶段B）        │
└───────────────────────────────┘
```

- 统计口径（纯 Kotlin domain 层 `RecapCalculator`，输入快照、无副作用，JVM 单测）：
  总次数、总花费（仅统计有 cost 的 Visit）、去过的 Place 数（visitCount≥1）、最爱 TOP3（按次数，并列取评分高者）、类型占比（按 Visit 数）、月度分布、连续记录天数（连续 N 天每日 ≥1 条）、平均评分。
- **年度食光长图**：纵向多屏版式——封面（年份 + 「我的年度食光」）→ 三大数字 → 最爱 TOP3（带照片）→ 类型占比 → 月度节奏 → 精选照片墙（今年 Visit 照片最多 9 张宫格）→ 结尾条（App 名 + 生成日期）。视觉：奶油底 + 主题绿衬线标题 + 大数字（05-design-system 补年报版式 token）。
- 导出三通道对齐 wardrobe it-014 交互：**存相册**（MediaStore 写 `Pictures/Eats`，API 29+ 免权限）/ **分享** / 长按预览区保存。年份可选今年/去年。
- **长图管线在 eats 内自实现**（Composable → Bitmap → PNG），参考 wardrobe it-002 的实现思路但不跨应用复用代码。不抽 libs：两 App 版式完全不同，可共享的只剩渲染+保存约百行薄层，待第三个消费方出现再评估（ADR-012）。

### 阶段B · 好久没去提醒

- 引入 `androidx.work`（依赖变更记 ADR-013）：每日一次 PeriodicWork。
- 候选规则（`MemoryCandidateSelector`，JVM 单测）：`visitCount ≥ 3` 且 `rating ≥ 4`（无综合评分时回退 `avgVisitRating ≥ 4`）且距 `lastVisitAt ≥ N 天`；N 默认 90，可选 60/90/180。
- 每日至多 1 条，从候选随机；有照片时用 BigPictureStyle 大图。点击通知 → W5 详情。
- 设置 UI 在 W7 底部：开关 + 天数 chips。开关开启时请求 `POST_NOTIFICATIONS`（API 33+）。**默认关**，不打扰优先。
- 重复抑制：上次提醒过的 Place 在其余候选用尽前不再推（记最近推送 id 于本地 KV，不进 eats.json）。
- 演示模式兼容（it-006 架构）：演示模式开启时 cancel 全部任务、入口置灰提示「演示数据不推送」，退出后恢复。

## 验收标准

- W7 各数字与手算一致（伪造 Visit 快照断言 `RecapCalculator` 全部指标，含空数据/全缺 cost 边界）
- 年度长图：生成、存相册（`Pictures/Eats` 可见）、分享三通道可用；空数据时按钮置灰并提示
- 提醒：候选规则单测（边界=恰好 N 天、评分缺失回退、候选为空不推）；模拟器实测收到通知→点击进详情；默认关、开关联动权限请求
- `./gradlew assembleDebug test` 通过；W7 与长图样张截图对照验收
