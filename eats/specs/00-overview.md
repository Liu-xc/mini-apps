# 00 · 业务背景与总览

## 为什么做这个应用

解决「吃」这件日常小事上的三个问题：

1. **选择困难**：每到饭点「今天吃啥」都要纠结，靠翻聊天记录和模糊记忆做决定，缺一个能替自己快速拍板的工具。
2. **吃过就忘**：去过的餐厅、点过的外卖、做过的菜没有沉淀——哪家上次体验一般、哪家仨月没去、哪道菜翻过车，全靠脑子记。
3. **信息分散**：外卖记录锁在外卖 App 里，堂食体验留在脑子里，自做菜没有任何记录，没有一个统一的地方回看「我平时都吃什么」。

## 核心价值流

```
发现好店 / 想做道菜 → 新增「食堂」条目（名称 · 类型 · 地图选点 · 照片 · 评分 · 标签 · 外卖/点评链接）
        │
        ▼
吃的时候一键记一笔（时间默认现在，可加评分 / 花费 / 感想 / 照片）
        │
        ▼
「今天吃啥」转盘决策：过滤（类型 / 忌口标签）+ 降权（最近吃过）→ 抽中 → 一键落账
        │
        ▼
回看：地图（都在哪吃过）· 列表（多久没去 / 评分 / 次数）· 详情时间线（每一次的记录）
```

## 关键用户与设备

- 一台安卓手机，个人自用。无账号、无服务端、无云同步；数据全部存本机应用私有目录（JSON + WebP 图片）。
- 地图使用 osmdroid + 高德公开栅格瓦片（免 API Key，ADR-002 修订），瓦片按需在线加载并缓存。

## 范围外（明确不做）

POI 检索 / 逆地理编码（在线服务）、营养与卡路里、多角色、云同步、外卖订单自动导入、iOS。详见各迭代提案。
