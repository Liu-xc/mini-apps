# 赤峰环线 · 场景气氛原型（平面版）

2026-09-24 为「旅行 → RPG 游戏」方向做的**第一轮视觉探索**：单文件 Canvas 程序化绘制，
三站按行程顺序（阿斯哈图石林 → 达里诺尔湖 → 乌兰布统），含分层视差、风/雾/鸟/光柱/波光
等氛围动效、塞尔达式地名揭示卡、里程 HUD、站点切换（1/2/3 或 ←→）。

## 打开方式

- 直接双击 `index.html`（无外部依赖），或
- `python3 -m http.server 8791` 后访问 http://127.0.0.1:8791/

## 定位（重要）

Leo 已明确**方向不是平面**，而是塞尔达那样的 3D 网页游戏（PC web + mobile web，
Three.js + 高口碑 glTF 素材）。本目录因此降级为**配色/构图/气氛参考稿**，
为 3D 版的美术方向（三站各自的色板、光位、地平线构图）提供依据，不继续迭代。

## 已知坑（复盘）

- 零参 canvas 方法（save/fill/beginPath…）漏括号会导致整层静默不渲染——已踩过一次，156 处。
- IAB 浏览器截图会拿旧帧：连拍两次取第二张。
- 颗粒/云朵叠加用单路径一次填充，避免 alpha 叠出气泡边。
