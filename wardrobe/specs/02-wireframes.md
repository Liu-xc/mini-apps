```
┌───────────────────────────────┐
│ 👨 Leo ▾           🎲 随机一套 │ ← 角色名(衬线大字)，点▾=W2
├───────────────────────────────┤
│ 上装                      3/12 │ ← 品类名 + 当前序号
│  ‹   ┌─────────────────┐   ›  │
│      │                 │      │
│      │   白衬衫 照片     │      │ ← 中间卡片全尺寸
│      │                 │      │   两侧缩小变淡(轮播)
│      └─────────────────┘      │
│        白色牛津纺衬衫           │
│        WHITE · 04             │ ← 字距小标签
│        #通勤 #简约             │ ← 单品标签跟随
│·······························│
│ 下装 1/8 · 鞋 · 包 …(同样滑动)  │
│              ⋮                │
├───────────────────────────────┤
│  [ 📋 复制图片+文本 ]   [ ↗ ]   │ ← 底部常驻
└───────────────────────────────┘
  手势：槽位内 ◀滑▶ 换该品类；点卡片→W5(共享元素放大)
```

- 8 品类槽位纵向滚动；空槽位显示紧凑「+ 添加」条
- 底部按钮仅在有 ≥1 选中时可用

## 交互路径总览

```
[W1 搭配页] ◀── W2 切角色（全 App 数据按角色隔离）
   │ 槽位滑动组套 / 🎲 老虎机随机 / 点卡片→W5
   ▼
[W6 导出面板] 预览合成图 · 改文案
   ├─ 复制图片+文本 ──▶ 切到生图 Agent 粘贴生图
   └─ 分享图片（剪贴板图片兼容性兜底）
        │（生图完成后回到 App）
        ▼
  ☆收藏这套 ──▶ 建 Outfit ◀── ＋录入成品图 ──┘
                    │
                    ▼
[W8 穿搭记录] ─标签筛选▶ [W7 穿搭详情] ─点单品▶ [W5 衣物详情]
[W3 衣橱] ─标签筛选─点衣物▶ [W5] ◀─「相关穿搭」反查 ─ [W7]
     └─ FAB ─▶ [W4 添加/编辑]
W5 / W7 均可打标 + 评论
```
