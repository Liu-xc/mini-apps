## it-011 交互注记（UX 评审落地，2026-09-20）

- W1：格位序号胶囊改 ‹ n/n ›（可翻暗示）；首次进入格位做 150ms 微移 coach（仅一轮，Prefs 标记）；「复制长图」升实心主按钮、「保存这套」描边次按钮。
- W2：当前角色行浅底 + 「✓ 使用中」；新建=实心主按钮、管理=文字入口。
- W3：两列网格卡片（首屏 4–6 件）；it-012：品类 Tab 改图标圆 chip（「全部」保留文字）+「筛选」固定行尾（不再被挤出屏）；卡片右上 ··· 菜单=编辑/删除（长按保留快捷）；去品类小节标题按品类序平铺；颜色改胶囊与 #标签 分列。it-015（DEBUG 构建）：标题行「共 N 件」旁 Science 小圆钮=演示模式入口，按当前模式弹「进入/退出演示」确认——release 构建不渲染（修订：去掉常驻横幅）。
- W4：吸底保存两态（it-012 重构：中性灰原因+全宽两态，点击未就绪 toast 缺什么）；照片必填无照片时显示大虚线占位「拍照 / 选照片 · 第一步」。
- W5：大图统一浅底衬纸容器（Fit 完整呈现）；相关穿搭放大卡 + 「点开看整套 ›」。
- W6：打开即见长图预览；it-012：结构改「滚动区+底部固定动作栏」（复制/分享/只复制文本推不走）；预览高 42% 屏 + ContentScale.Fit 全貌（修内层滚动约束致 Coil 空白的历史 bug）；弹层全展开（skipPartiallyExpanded）。it-013：五维统一收进「风格与场景维度（全部可选）」折叠区（场景不再常驻，默认收起+选中计数徽标）；新增「自定义要求」多行输入（可选、追加到生成文案末尾「另外要求：…」、记住上次 custom_prompt），长图/复制文本通道均带出。it-014：动作栏三按钮「复制长图｜存相册｜分享」——存相册经 MediaStore 写 Pictures/Wardrobe（API 29+ 免权限，旧系统引导分享），成功反馈落在按钮上（「已存相册 ✓」，snackbar 会被 sheet 遮挡）。
- W7/W8：无成品图时 BodyCollage 人体拼贴作主视觉，it-012：「＋录入成品图」角标移拼贴右上（避空槽语义区）、「复制素材」更名「复制长图」；W8 下方网格缩略统一为迷你人形拼贴（含空槽）；卡面 ‹ n/m › 卡序常驻；「随机翻一套」。

## 交互路径总览

```
[W1 搭配页] ◀── W2 切角色（全 App 数据按角色隔离）
   │ 槽位滑动组套 / 🎲 老虎机随机 / 点卡片→W5
   ▼
[W6 导出面板] 预览合成图 · 改文案
   ├─ 复制图片+文本 ──▶ 切到生图 Agent 粘贴生图
   └─ 分享图片（剪贴板图片兼容性兜底）
        │（生图完成后回到 App）
        ▼
  ☆收藏这套 ──▶ 建 Outfit ◀── ＋录入成品图 ──┘
                    │
                    ▼
[W8 穿搭记录] ─标签筛选▶ [W7 穿搭详情] ─点单品▶ [W5 衣物详情]
[W3 衣橱] ─标签筛选─点衣物▶ [W5] ◀─「相关穿搭」反查 ─ [W7]
     └─ FAB ─▶ [W4 添加/编辑]
W5 / W7 均可打标 + 评论
```
