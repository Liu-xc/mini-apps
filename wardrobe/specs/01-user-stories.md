# 01 · 用户故事与验收标准

编号规则：`US-XX` 用户故事，`UC-XX` 对应用例/界面（W 编号见 [02-wireframes.md](02-wireframes.md)）。验收标准采用 Given/When/Then。

## 衣物管理

### US-01 录入衣物
作为用户，我想拍照/从相册选图录入一件衣物并填写名称、品类、颜色、描述、标签，以便后续组合与生成文案。
- **UC**：W3 → FAB → W4
- Given 衣橱页，When 点 FAB，Then 打开空白添加表单
- Given 未选照片，When 点保存，Then 阻止保存并提示照片必填
- Given 选好照片并填写名称与品类，When 保存，Then 照片压缩为 WebP 落盘、条目写入，返回列表可见新衣物

### US-02 编辑/删除衣物
- Given 衣橱列表，When 点条目，Then 进入编辑表单（数据回填），保存后列表即时更新
- Given 衣橱列表，When 长按条目，Then 弹删除确认；确认后照片文件与记录一并删除

### US-03 品类分组浏览
- Given 衣橱页，Then 衣物按 8 大品类分组显示并计数；按标签筛选时仅显示含所选标签的衣物

## 搭配组合

### US-04 滑动组合穿搭
作为用户，我想在每个品类槽位里左右滑动切换衣物，各槽位当前卡片组成一套，以便快速试组合。
- **UC**：W1
- Given 某品类有 ≥2 件衣物，When 左右滑动槽位，Then 卡片跟手移动、松手吸附到相邻衣物，序号 `n/总数` 同步更新
- Given 其他槽位，Then 当前选中不受影响（各槽独立）
- Given 品类无衣物，Then 槽位显示紧凑的「+ 去添加」引导

### US-05 随机一套
- Given 搭配页，When 点 🎲，Then 所有非空槽位高速连滚并按 ~0.1s 间隔依次停止，得到随机组合

### US-06 组合记忆
- Given 上次退出时各槽位选中项，When 再次打开 App，Then 恢复上次组合（按当前角色）

## 导出与生图

### US-07 导出生图素材
作为用户，我想把当前组合导出为「合成图 + 描述文案」，复制给生图 Agent 生成效果图。
- **UC**：W1 → W6
- Given 选中 ≥1 件衣物，When 点复制按钮，Then 弹出导出面板：合成图预览 + 自动生成的可编辑文案
- Given 导出面板，When 点「复制图片+文本」，Then 文本进剪贴板且图片以 content URI 写入剪贴板，按钮变 ✓ 动画
- When 点「分享」，Then 拉起系统分享面板分享合成图（剪贴板图片不被目标应用支持时的兜底）
- 文案自动拼装：每件选中单品的品类+颜色+描述，及该套的风格标签（如「通勤简约」）

### US-08 保存这套（it-004 修订：搭配页直达 + 去重）
- Given 搭配页底部，Then 显示 ☆保存这套 / ★已保存（当前组合与已有穿搭单品集合相同即为已保存，顺序无关）
- Given 未保存，When 点 ☆，Then 创建穿搭（空标签）并转 ★；Given 已保存，When 点 ★，Then 跳转该穿搭详情
- Given 导出面板点收藏同一组合，Then 不产生重复记录（复用并更新标签）

### US-09 录入成品图
作为用户，生图完成后我想把效果图录回并挂到对应穿搭上。
- Given 导出面板或穿搭详情，When 点「＋录入成品图」并从相册选择，Then 图片压缩存储并加入该穿搭的成品图集合（可多张、可删除）
- Given 穿搭未收藏时直接录入成品图，Then 自动创建穿搭记录

## 穿搭沉淀

### US-10 浏览穿搭记录
- Given 穿搭记录页，Then 已有成品图的穿搭显示成品图，否则显示合成图占位；支持按标签筛选
- When 点某套穿搭，Then 进入穿搭详情：成品图横滑 + 组成单品列表 + 操作按钮

### US-11 单品反查穿搭
- Given 衣物详情页，Then 显示「穿过这些穿搭」缩略图横滑（该单品出现在哪些穿搭中），点缩略图跳对应穿搭详情

## 多角色

### US-12 角色隔离
作为家长，我想在一台手机上分别记录多个人的衣橱。
- Given 首次启动，Then 自动创建默认角色「我」
- Given 搭配页顶部，When 点角色名，Then 弹出角色切换层；切换后三个 Tab 数据全部切换为目标角色的数据
- Given 角色管理，Then 可新建/改名/改 emoji/删除角色；删除时明确提示连带删除该角色全部衣物与穿搭，需二次确认

## 标注体系

### US-13 打标
作为用户，我想给单品和穿搭打标签（风格/季节/场合，可自定义），以便筛选与文案生成。
- Given 添加/编辑表单或详情页，Then 可从预设标签点选或输入自定义标签；标签以 chip 展示，可单个移除
- Given 衣橱/穿搭记录页，Then 标签筛选条生效（单选过滤）

### US-14 自然语言评论
- Given 衣物详情或穿搭详情，When 在评论输入框输入文字并提交，Then 追加到评论时间线（多条、按时间倒序、可删除）

## 录入去背景

### US-15 一键去背景（it-016 阶段 B）
作为用户，我想在录入衣物照片时把衣物从杂乱背景中抠出来（透明底），让卡片与合成图更干净、风格统一。全程离线：模型打包 assets，推理在本机。
- **UC**：W4（添加衣物）
- Given 已选新照片（W4），When 点「去背景 · 一键透明底」，Then 首次点击自动完成引擎预热（读 assets 建会话，一次性约 1s），推理完成预览切换为透明底（棋盘格提示），按钮行变「已去背景 · 透明底 + 还原」
- Given 已去背景，When 点「还原」，Then 删除抠图版回到原图预览，可再次去背景
- Given 已去背景，When 保存，Then 落盘抠图版（带 alpha WebP，格式不变）、原图文件即弃；还原态保存则落盘原图
- Given 推理失败（损坏图片等），Then toast 提示且原图不受影响，可重试
- Given 编辑既有衣物（非新选照片），Then 不出现去背景入口（补抠为演进候选）
- Given 人穿衣服的照片，Then 抠图结果为「人+衣服」整体且可能残缺（显著性分割边界，UI 如实呈现，用户可还原）

## 形象参考

### US-16 形象参考照（可选，it-017）
作为用户，我想给角色设置一张自己的照片（全身照或头像均可），导出时一并给生图 Agent，让生成的穿搭效果图更像本人。照片上传一次长期有效，每次导出默认使用，可临时关闭。
- **UC**：W2（编辑角色）→ W6（导出面板）
- Given 角色编辑对话框，When 点「选择照片」从相册选图，Then 图片压缩落盘（复用 1440px/WebP82 管线）、对话框内显示缩略图，可「更换」「移除」；移除后文件物理删除
- Given 未设置参考照，Then 导出面板与现状完全一致（不出现新开关）
- Given 已设置参考照且开关开（默认开，每次打开导出面板均默认开），When 导出长图，Then 长图 = Prompt（顶部）→ 参考照+「本人形象参考」标注条 → 人体比例拼贴（与 W1 同构），文案含形象还原要求；复制/存相册/分享三通道为同一版本
- Given 本次导出中关闭开关，Then 本次长图与文案与现状一致；关闭不跨会话记忆
- Given 杀进程重开，Then 参考照保留
- Given 删除角色，Then 参考照文件连带物理删除；旧版本备份 JSON（无该字段）导入后视为未设置

## 穿搭打卡

### US-17 穿搭打卡（it-018 阶段A）
作为用户，我想在穿搭详情一键记录「今天穿了这套」，沉淀真实穿着数据，供统计回顾、利用率和闲置判断使用。
- **UC**：W7 打卡按钮
- Given 穿搭详情，When 点「今天穿了这套」，Then 新增一条 WearLog（at=现在），按钮转为已打卡态
- Given 当日已打卡，Then 显示「今日已穿 · 再记一次」（同日多套允许）与「撤销今日」（删除当日该穿搭全部打卡）
- Given 删除穿搭/角色，Then 其打卡记录级联删除；旧版本备份 JSON（无 wearLogs 字段）导入后视为空表

## 统计回顾

### US-18 衣橱回顾页（it-018 阶段B）
- **UC**：W3 标题行 📊 → W9
- Given W9，Then 展示三大数字（现有单品/穿搭套/档内打卡次数）、最百搭 TOP3（按进过的穿搭数排序）、品类分布、利用率（穿过≥1 次单品占比）、闲置清单入口、出勤最高穿搭、连续打卡天数
- Given 时间档位切换（今年/累计），Then 打卡次数、出勤最高、照片墙随档位过滤；单品/穿搭数与利用率、闲置为结构指标（全量）
- Given 点闲置清单，Then 进入二级页（缩略图网格 + 拥有天数），点单品进详情

### US-19 年度衣橱长图（it-018 阶段B）
- Given W9 点「生成年度衣橱长图」，Then 按当前角色生成（封面角色+年份 → 三大数字 → 最百搭 TOP3 → 品类分布 → 成品图墙 ≤9 张 → 结尾），可存相册 Pictures/Wardrobe 与分享
- Given 档内无打卡数据，Then 按钮置灰；预览、存相册、分享为同一版本

### US-20 好久没穿提醒（it-018 阶段C）
- Given 开关开启（默认关，开启时请求通知权限），Then WorkManager 每日检查：穿过 ≥2 次且超过 N 天（默认 90，可选 60/90/180）没穿的单品，每日至多推 1 条（文案带角色名），点击进衣物详情
- Given 上次提醒过的单品仍有其他候选，Then 先推其余候选
- Given 演示模式，Then 不注册任务、入口置灰提示

## 心愿清单（it-019）

### US-21 想买单品管理（W10）
作为用户，我想把种草还没买的衣服/鞋/包先记进来（名称+品类即可，商品图/链接/价格可选），集中管理。
- **UC**：W3 标题行 🌟 → W10；FAB 种草弹层；点卡片详情弹层
- Given 种草弹层，Then 仅名称+品类必填即可保存；商品图可选（截图即可），无图用品类占位
- Given 详情弹层，Then 展示大图/价格/标签/种草时间，商品链接点击经 ACTION_VIEW 打开（无处理组件 toast）
- Given 已购入的愿望，Then 收进「已购入 N」折叠小节（默认收起），点击跳转转正后的单品详情
- Given 删除愿望，Then 二次确认，商品图物理删除，含该件的心愿穿搭同步移除（变空则整条删除）

### US-22 混搭预览与存为心愿（W1）
作为用户，我想把想买的单品混进搭配槽位和已有衣服拼成一套，导出长图让生图 Agent 出上身效果图，并把组合存为心愿穿搭反复回看。
- **UC**：W1 顶栏 🌟 开关 · 底部「🌟 存为心愿」
- Given 开关开启（默认关，仅会话内记忆），Then 各品类槽位数据源附加未购愿望单品；愿望卡带「🌟 想买」角标、虚线描边与降饱和，点卡片跳心愿页
- Given 组合含愿望件，Then 底部第二按钮变「🌟 存为心愿」（去重：itemIds+wishItemIds 集合判等）；复制长图照常，长图该槽位照拼、标签带「🌟想买」、文案追加「（种草未购入单品，生成时一并上身展示）」
- Given 组合含愿望件，Then 导出面板「收藏这套」置灰显示「🌟 心愿组合 · 仅预览」（Outfit 只收已有单品，ADR-020）
- Given 无愿望件的组合，Then 按钮与保存逻辑与原状完全一致

### US-23 心愿穿搭管理与购入转正（W10 穿搭段）
- **UC**：W10 分段「👗 心愿穿搭」；详情弹层
- Given 心愿穿搭卡，Then 显示件数、已有/想买构成与「还差 n 件 / 可升级」状态
- Given 详情弹层，Then 成员列表（已有件→W5，愿望件→心愿详情）、「📋 复制长图」（组合伪 Item 走 W6 导出面板）、「→ 去预览」（恢复组合到 W1 各槽位并自动开启混入）、「＋ 录入上身预览图」
- Given 愿望单品「已买到」，Then 转正表单全字段预填（照片可沿用商品图或补拍实物），保存=创建正式 Item + 回填 purchasedAt/purchasedItemId，含该件的心愿穿搭自动把它移入已有件并提示「n 套心愿穿搭已更新」
- Given 心愿穿搭全部愿望件已购，Then 「👗 升级为穿搭」高亮可用：创建正式 Outfit（tags 继承、预览图移交成品图）、心愿条目移除
- Given 删除角色，Then 其心愿单品/心愿穿搭与图片文件级联删除

## US-24 数据包导入导出（it-024）

作为衣橱主人，我能把全部数据（含图片）导出成一个结构化数据包，交给 AI 或其他工具加工后导回，实现批量打标、清洗与迁移；数据包同时天然是我的完整备份。

- **UC**：W9「数据」小节 · 系统分享/打开方式直达（④b）
- Given W9 数据小节点「导出数据包」，Then 经系统保存对话框生成 `wardrobe-backup-*.zip`（manifest.json + wardrobe.json + images/），完成 snackbar 带 [分享]
- Given 导入数据包（W9 入口或系统直达），Then 先自动校验，通过后弹预览确认（包来源 + ＋新增/↻更新/＝保留 差异摘要 + 合并/替换选择）
- Given 合并导入（默认），Then 按 id 去重：包内版本覆盖同 id 实体、新增实体追加、本地多出的保留（合并永不删数据）；「N 件导出后被本地改过」有警示行
- Given 替换导入，Then 二次确认后清空本地换为包内内容
- Given 错包（跨 app/坏 JSON/缺图/版本过新），Then 拒绝并列出原因，固定「本地数据未做任何改动」
- Given 演示模式，Then 导入导出入口置灰
