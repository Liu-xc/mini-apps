# 00 · 业务背景与总览

## 为什么做这个应用

使用者本人（及家人）希望解决三个具体问题：

1. **衣物分散难搭配**：衣服都拍过照、存在手机相册里，但想「今天穿什么」时没法快速把几件衣物组合起来看效果。
2. **AI 生图时代缺一个顺手的前置工具**：现在的生图 Agent 已经能把「几件单品的照片 + 一段文字描述」合成为真人穿搭效果图，但从相册里一张张挑图、手打描述非常繁琐。缺一个专门的衣橱管理 + 组合 + 导出工具。
3. **穿搭记忆无处安放**：生成过的好搭配、某件衣服实际穿过的反馈（显胖/被夸/缩水），记不住也查不回来。

## 核心价值流

```
录入衣物（拍照 + 品类/名称/颜色/描述 + 标签）
        │
        ▼
搭配页：品类槽位左右滑动组合一套 ←（🎲 随机一套碰运气）
        │
        ▼
导出面板：合成图（各单品拼图）+ 自动文案（品类+颜色+描述+风格标签，可编辑）
        │  复制图片+文本 / 分享
        ▼
切换到生图 Agent（豆包/ChatGPT/Kimi 等）→ 粘贴 → 生成真人穿搭效果图
        │
        ▼
回到 App：录入成品图，挂到这套穿搭上（☆ 收藏可发生在生图前后任意时点）
        │
        ▼
沉淀：穿搭记录页浏览所有套 · 衣物详情反查「这件衣服穿过哪些穿搭」
      全程可打标签（通勤/约会/早秋…）、写自然语言评论（时间线）
```

## 关键用户与设备

- 一台安卓手机，多个角色（如：Leo、老婆、宝宝），角色间数据完全隔离，顶部一键切换。
- 个人自用，无账号、无服务端、无云同步，数据全部存本机应用私有目录（JSON + WebP 图片），提供备份导出。

## 范围外（明确不做）

背景抠图、云端同步、桌面端、品类自定义编辑、角色间共享单品、电商链接。详见各迭代提案。
