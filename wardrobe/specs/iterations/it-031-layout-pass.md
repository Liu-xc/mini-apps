# it-031 · 版式收拢：名称条 / 翻页器 / 吸底动作栏 / 打卡层级 / 空态行动

- **状态**：已完成（2026-09-23，Leo 对 UI 审查报告拍板「实施」；走查全过、单测绿）

## 背景与动机

审查发现五处版式/层级问题，集中在高频页：

1. **C5（W1）**：窄格名称条「品类 · 名称」前缀挤占预算，名称截断至 1–2 字；相邻格间距仅
   ~3.7dp，深色名称条视觉连成长带。
2. **C6（W8）**：卡序翻页器浮层压在拼贴帽行上（牛仔帽 ~70% 被遮）；且胶囊外左右又各一枚
   圆钮，翻页语义冗余。it-015 修订二的「两侧 ‹ › 圆钮双向循环翻张」由本迭代废止（圆钮删除，
   胶囊本身移至卡下方居中、可点循环 + 横滑保留，‹n/m› 卡序记号沿 it-011 保留；spec 02 注记同步）。
3. **C9（W10）**：种草表单「吸底」主按钮在初始视口不可见（需滚动），末行被截断——吸底失效。
4. **C7（W7）**：打卡主按钮与「复制长图」同为主实底按钮堆叠，主次拉平（it-018 的全宽实心
   已满足，本迭代把复制长图降为描边次按钮）。
5. **C10（W9）**：「还没有穿搭打卡」空态卡只有图形+文案，无行动按钮，违 §5.8。

附带（同页顺手收口）：W1 序号胶囊 ‹n/n› 为纯 Text，点击穿透进详情（审查 P1）——改为可点
翻页（循环）；W1 愿望卡「想买」角标底色透明度过高致白字对比不足——加深；拼贴空槽「未配X」
文字/虚线对比贴近下限——加深一档。

## 用户故事

- **US-31a**：作为用户，W1 每格名称条优先显示名称、右侧仅配序号小字（品类由格位+图片承载），窄格不再截断成单字。
- **US-31b**：作为用户，W8 翻页器位于卡片下方，不遮挡拼贴内容。
- **US-31c**：作为用户，种草表单无论滚到哪里，主按钮都固定可见可点。
- **US-31d**：作为用户，W7 打卡主按钮是页面唯一实底主按钮，复制长图为描边次按钮。
- **US-31e**：作为用户，W9 打卡空态卡提供「去打卡」一键直达穿搭记录。

## 验收标准

- Given W1 窄格（包/配饰），Then 名称完整可读（名称优先，右侧纯「n/n」序号角标）
- Given W1 相邻格位，Then 间距 ≥12dp；点序号胶囊翻到下一页（循环）而非进详情
- Given W8 卡组，Then 翻页胶囊在卡片下方居中，帽行无遮挡；两侧圆钮删除
- Given W10 种草表单初始展开，Then 不滚动即可见「收进想买」主按钮（固定动作栏）
- Given W7 未打卡，Then 仅打卡按钮为实底主按钮
- Given W9 无打卡数据空态卡，Then 有「去打卡」按钮，点击切到穿搭记录 Tab
- 构建 + 单测绿；模拟器逐项走查 + 关键页截图对照线框

**口径勘定（C5，报告文字 vs 线框画稿）**：审查报告 C5 文字写「品类并入右侧计数角标」，
但报告线框（Leo 实际过目的画稿，`draw_wireframes.py slot()`）画的是纯 n/n 角标、无品类前缀，
两处不一致。裁定以线框为准——「杜绝截断」是绑定验收：小格物理上塞不下「名称+品类 n/n+✕」
（rev1 实测名称槽 0 宽），品类信息已由格位 + 图片承载。最终实现 = 名称优先（加粗）+ 纯 n/n
角标（可点翻页）+ ✕ 图标（Icons.Rounded.Close，✕ 文字被 fallback 全宽渲染占 32dp 故换图标）。

**rev2 格宽修正**：rev1 曾把全部格子比例放大到 1.55 试解截断，一屏布局被顶破（底部行溢出
折叠线下）后回退；最终仅小格（包/配饰）0.55→0.85、格间距 12dp、cell=(行宽-24dp)/3，
帽/下/鞋原比例不动，一屏未破。
