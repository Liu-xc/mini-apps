# it-052 · 黑白灰高级视觉与排版系统

- **日期**：2026-09-28
- **状态**：已实现；构建、单测与浅/深色视觉走查通过
- **来源**：衣橱整体视觉方向调整
- **类型**：全局视觉系统重构（色彩 + 字体 + 层级）

## 背景与动机

当前衣橱沿用“淡绿纸感 + 墨绿强调”的时装编辑风基线。经过多轮功能迭代后，页面数量、入口和信息密度已经明显增加，绿色在页面背景、选中态、按钮、标签和装饰中的存在感开始削弱黑白照片与服装内容的主角地位，也让不同页面的视觉气质不够统一。

本迭代将衣橱整体收口为黑、白、灰的高级编辑风：界面 chrome、容器、按钮、导航、空态、设置和顾问页全部使用中性灰阶；用户衣物照片、成品图和透明素材保留原始颜色，避免把内容误处理成滤镜。字体与字号同步重新定稿，明确中文正文、展示标题、字段标签、操作文字和数字信息的分工，减少当前 serif/sans 混用过多、中文标签字距过松的问题。

## 设计定位

「黑纸、白纸、石墨字」的时装画册，而不是黑底白字的纯暗色主题：

- 浅色是偏暖的纸白、深色是炭黑与石墨，不使用纯 `#000` 大面积铺底。
- 大图和真实服装照片是唯一允许保留丰富色彩的内容主体。
- 强调不再依赖绿色；选中、主操作和焦点使用高对比黑/白反差，层次依靠字号、留白、hairline 和局部实底。
- 功能图标统一使用 Material Icons；心愿、演示、状态等现有 emoji 图标改为中性图标或文字，避免破坏编辑风一致性。

## 用户故事

### US-54 · 全应用黑白灰视觉一致性

作为衣橱用户，我希望在搭配、穿搭记录、衣橱、顾问、详情、表单、设置和所有弹层中获得统一的黑白灰高级视觉，使服装照片成为真正的视觉主角。

- **UC**：W1–W13、底部导航、弹层、对话框、空态与系统入口
- Given 任一应用页面，Then 页面背景、Surface、文字、分隔线、按钮、选中态和图标均来自中性灰阶 token
- Given 页面包含衣物照片或成品图，Then 图片保留原始颜色和明暗，不被全局灰度滤镜处理
- Given 用户切换浅色/深色系统主题，Then 两套主题均为黑白灰同构，文本对比达到 WCAG AA

### US-55 · 可读且有层级的中文排版

作为衣橱用户，我希望标题、正文、标签和数字的字体与字号经过明确设计，在手机上快速浏览时既有杂志感又不糊、不挤、不散。

- Given 页面标题或单品/穿搭名称，Then 使用展示衬线体系，字号与行高稳定，不与正文抢层级
- Given 中文正文、说明、表单字段和按钮，Then 使用 Sans，正文不使用宽字距，行高适合连续阅读
- Given 标签、日期、数量和域名等元信息，Then 使用独立的 Sans 小字体系；宽字距只作用于短拉丁标签，不作用于中文句子
- Given 同一屏出现多个文字层级，Then 最多使用 Display / Title / Body / Meta 四个主要声部，不依赖颜色区分信息

## 视觉规格提案

### 1. 中性灰阶 token

| Token | 浅色 | 深色 | 用途 |
|---|---:|---:|---|
| `paper` | `#F7F7F5` | `#111110` | 全局背景，偏纸白/炭黑 |
| `surface` | `#FFFFFF` | `#1B1B1A` | 卡片、弹层、输入容器 |
| `ink` | `#111111` | `#F2F2EF` | 标题、正文、主图标 |
| `inkFaint` | `#6B6B67` | `#A6A6A0` | 元信息、占位、辅助说明 |
| `accent` | `#111111` | `#F2F2EF` | 选中态、图形焦点、主强调 |
| `accentContent` | `#111111` | `#F2F2EF` | 强调文字、链接、动作前景 |
| `hairline` | `#D9D9D4` | `#393936` | 分隔线、细边框 |

Material `primary` 在浅色使用 `#111111`、`onPrimary=#FFFFFF`；深色使用 `#F2F2EF`、`onPrimary=#111110`。系统 error 保留语义红，仅用于破坏性操作和错误反馈，不参与品牌视觉。

### 2. 字体角色与字号

实现优先复用系统 CJK 字体，避免无必要增加 APK 体积：展示使用系统 Noto Serif CJK fallback，正文使用系统 Sans CJK。若目标设备实测出现字形缺失，再单独评估打包字体。

| 角色 | 字体 | 字号 / 行高 | 使用范围 |
|---|---|---:|---|
| Display | Serif Semibold | 30sp / 38sp | 页面大标题、角色名、单品/穿搭实体名 |
| Title | Serif Medium | 20sp / 28sp | 卡片标题、弹层标题、主要字段名 |
| Section | Sans Semibold | 15sp / 22sp | 小节标题、分组标题 |
| Body | Sans Regular | 15sp / 23sp | 描述、评论、正文、表单输入 |
| Action | Sans Medium | 14sp / 20sp | 按钮、导航文字、可操作行 |
| Meta | Sans Medium | 11sp / 16sp | 日期、数量、品类、状态、短标签 |
| Numeric | Sans / tabular figures | 13–20sp | n/m、统计数字、日期和用量 |

排版规则：

- 中文正文、按钮、说明和字段标签 `letterSpacing=0`；不再把全局 `labelSmall` 的宽字距施加到中文。
- 只有短拉丁标签（例如 `LOOK 04`）允许约 `0.08em` 字距；域名、日期、Prompt 和连续句子归零。
- 正文最小 15sp；Meta 最小 11sp 且对比度不低于 3:1；重要说明使用 `ink` 而非 `inkFaint`。
- 页面标题最多两行，单品/穿搭名称最多两行；不通过缩小到难读的字号解决截断。
- 数字、日期、n/m 计数使用稳定的等宽数字特性，避免卡片网格抖动。

### 3. 组件表达

- 主 CTA：浅色黑底白字，深色白底黑字；同一屏只保留一个最高权重主 CTA。
- 次 CTA：透明底 + hairline 描边；文字使用 `ink`，不再使用绿色。
- 选中 Chip / Tab：黑底白字（深色反向），未选中为纸面底 + hairline；不以绿色铺底。
- 导航选中态：中性实心小 pill 或明确的黑/白图标状态，文字不再因选中变色。
- 卡片层级：保持 20dp 圆角、弹层 28dp 顶角和极轻阴影；主要靠留白与 hairline 分层。
- 空态与图形插画统一灰阶；照片、成品图和服装透明素材不套灰度。
- 破坏性操作仍使用系统 error，并保留二次确认或可撤销机制。

## 动效与触感

沿用现有 `EditorialMotion`、减弱动态降级和触感基线，不因为换色新增动画。需要调整的仅是视觉反馈：

- 选中/聚焦由灰阶对比、hairline 或黑白实底即时反馈，保持 `<100ms` 起步。
- 不新增黑白闪烁、反转滤镜或全屏色彩过渡。
- 复制、保存、打卡等确认动作继续使用现有 Confirm 触感；不新增音效。

## 验收标准

1. `W1–W13`、底部导航、二级页、弹层、对话框、空态、设置与顾问页面的 UI token 中不再出现品牌绿或其他非语义色；error 红只出现在破坏性/错误状态。
2. 浅色和深色主题均完成 token 对表：`paper/surface/ink/inkFaint/accent/accentContent/hairline` 全部为中性灰阶；`ink/paper ≥ 7:1`、`inkFaint/paper ≥ 3:1`、主按钮文字对比 ≥ 4.5:1。
3. 用户照片、成品效果图和透明素材的像素颜色不被主题层、图片容器或全局 modifier 灰度化；黑白灰只作用于 UI chrome。
4. 全局 Typography 收口到 Display / Title / Section / Body / Action / Meta / Numeric 角色；中文正文与按钮无宽字距，短拉丁标签才允许字距。
5. 关键页面在 320dp、360dp、411dp 宽度下检查标题、字段、按钮和底部导航，无新增截断、重叠或触控目标小于 44dp 的问题。
6. 原有功能、动效、减弱动态、触感、数据格式和导出图片内容不回归。
7. 完成 `:app:testDebugUnitTest`、`:app:assembleDebug`，并在浅色/深色模拟器逐页截图走查；按 `DESIGN.md` §2–§5 将 P0/P1/P2 结论回填本迭代。
