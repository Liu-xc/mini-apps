# it-005 · 搭配页人体布局（换装游戏式着装位）

- **状态**：已完成（QA 模拟器验证通过）
- **提案日期**：2026-09-20
- **来源**：用户反馈（2026-09-20）——「肯定不是这么罗列出来嘛。你应该知道我的世界？或者各类换装游戏。还是要分着装的布局位置的」

## 背景与动机

it-003 的 3×3 均匀网格虽然一屏，但品类排布与着装无关——用户预期是**我的世界装备栏 / 换装游戏式的人体着装位**：卡片位置对应它在身上的穿着位置，一眼读出「这套穿在哪儿」。

## 方案：中轴人体列 + 两侧挂件

```
            ┌────────┐
            │  帽子   │            ← 头部（小卡，中轴居中）
            └────────┘
   ┌────┐ ┌────┬────┬────┐ ┌────┐
   │ 包 │ │外套│上装│连衣裙│ │配饰│   ← 上身三格并排（左肩挂包/右颈挂配饰）
   └────┘ └────┴────┴────┘ └────┘
            ┌────────┐
            │  下装   │            ← 腿部（通栏长卡）
            └────────┘
            ┌────────┐
            │   鞋   │            ← 脚部（通栏扁平卡）
            └────────┘
```

- 品类→着装位固定映射：帽子=头、外套/上装/连衣裙=上身、下装=腿、鞋=脚、包=左侧挂件、配饰=右侧挂件
- 每格仍是独立 HorizontalPager（滑动换衣）、品类徽标+序号+图下名（改为卡内底部遮罩条，省纵向空间）
- 卡片比例按部位区分：帽近方、上身竖长、下装通栏竖长、鞋扁平
- 一屏无滚动（垂直居中；极小屏滚动兜底）；🎲/组合记忆/保存去重/复制长图全部沿用
- 第 9 格「添加」移除：空品类格本身即 ＋ 入口

## 验收标准

- 布局呈人体着装位（中轴：帽→上身三格→下装→鞋；两侧：包/配饰），一屏无滚动
- 各格滑动换衣、徽标/序号/名称、组合记忆、保存去重（☆/★）不回归
- QA 模拟器截图 + dump 全格可视区核验
