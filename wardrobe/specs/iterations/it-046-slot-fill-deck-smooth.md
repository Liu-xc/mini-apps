# it-046 · 槽位卡内容撑满（去黑边距）+ 穿搭卡组动画丝滑化

- **状态**：已实现，验收通过
- **来源**：Leo 2026-09-26 反馈——「切换衣服的组件出现了黑色的边距，衣服没有撑满」+「穿搭卡片那个地方的动画不是很丝滑」
- **关联**：US-46；05-design-system「形状与间距」；libs/carddeck（卡组 SDK，无独立迭代编号）

## 背景与动机

**问题一：槽位卡黑色边距（W1 切换衣服组件）**

`SlotCell` 走 `PhotoCard(mat=true)` 衬纸模式：`ContentScale.Fit` + 衬底
`surfaceVariant.copy(alpha=0.55f)`。两个后果：

1. 照片与格位宽高比不匹配时上下/左右留边（"衣服没撑满"）——格比极端：上身 0.78、
   下装 0.6、鞋 2.6，而照片实际为 1.0（方图）或 1.29（横图），留边最多可达格高的 40%+；
2. 衬底颜色**跟随主题**：深色模式下 `surfaceVariant` 为深色，半透明叠在近黑页面底
   （像素实测 #10150F）上，留边即 Leo 所见的「黑色边距」。

**问题二：穿搭卡组动画不丝滑（W8 卡组）**

反编译 `compose-swipeable-cards 1.1.4` 实证两处结构性问题：

- 飞卡动画默认 `spring(dampingRatio = 0.6f, stiffness = 100f)`——偏软偏弹：单张飞出
  首次到位 ≈0.32s、完全稳定 ≈1s，且 0.6 阻尼带来 ~9% 过冲晃尾，落定后可见回摆；
- `drawRandom`（随机一套）以 55ms 起步 ×1.24 递增至 340ms 连发 12+n 步：步频远高于
  飞行时长（同屏最多 ~20 张同时在飞），且过末张时走 `setCurrentIndex(0)` **纯瞬移**
  （该分支不触发甩出动画，与相邻步的动画断裂）——观感为卡牌瀑布抖动 + 闪跳。

**动画注入面已确认**：`LazySwipeableCards` 公开 `animations: SwipeableCardsAnimations`
参数（卡组封装层此前未透传）；`onSwipe` 回调在甩出**起始**同步触发（`moveNext` + 回调
连续字节码），末张经包装层回卷 = 甩出+揭示，本身是顺滑路径——只需每步都真正 `swipe`。

## 用户故事

- **US-46a**：作为用户，槽位里的衣服照片撑满卡格、没有黑边留白；极端比例（帽/鞋）例外
  用固定浅色衬纸保全衣物完整，且衬纸不随深色主题变黑。
- **US-46b**：作为用户，穿搭卡组的甩出与随机抽取落定干净利落（不回摆晃尾、不闪跳），
  随机抽取像一台有节奏的老虎机而不是卡牌瀑布。

## 验收标准

- 槽位卡分档：`aspect < 0.95`（上身 0.78 / 下装 0.6 / 包·配饰 0.85）→ `Crop` 撑满、
  无衬纸；`aspect ≥ 0.95`（帽 1.0 / 鞋 2.6）→ `Fit` + **固定浅色衬纸** `#F2F3F5`
  （主题无关，深色下不变黑）。分档依据 PIL 内容包围盒实测：帽横构图裁方会剪帽檐
  （内容占宽 85%）、鞋 2.6 裁切会剪鞋底（内容 y 占高 67% vs 裁切窗 50%），其余品类
  居中裁切均落在背景/安全区（如方图下装内容宽 52%，0.6 裁切窗保留 60%）。
- W1 序号 n/m 末页回卷：不再反向动画滚过全部页，改即时落位（内容原位换页）。
- 卡组飞卡注入 `spring(dampingRatio = 0.9f, stiffness = 500f)`：首次到位 ≈0.32s、
  过冲 <0.5%、≈0.5s 内稳定；旋转分量保持库默认（`spring()` 临界阻尼）。
- `drawRandom`：每步必为真实 `swipe`（去掉末张瞬移分支，回卷由包装层甩出+揭示完成）；
  步数 `4 + Random.nextInt(n)`（对 n 取模落点均匀）、步距 260ms 起 ×1.24 封顶 460ms
  （与新飞行时长同量级，允许 1 张在飞的连锁而非 20 张瀑布）、收尾 480ms 等落定。
- `assembleDebug`/`test` 绿；模拟器深色模式像素探针验证撑满与衬纸；随机抽取实跑
  无空组、无闪跳；回填本文件验证记录。
- 常青 spec：05 补「槽位卡内容呈现」与「卡组动画节奏」两条；01 补 US-46；
  `libs/carddeck/specs/00-overview` 同步 `animations` 参数与 drawRandom 新节奏。
