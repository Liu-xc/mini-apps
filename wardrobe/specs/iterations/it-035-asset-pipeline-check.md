# it-035 · 素材管线统一（根因修复：比例/残片/边距校验）

- **状态**：已实施（2026-09-24）
- **来源**：[2026-09-24 UI 走查报告](../../../reports/2026-09-24-wardrobe-ui-audit/衣橱UI走查报告-2026-09-24.pdf) · it-035 提案
- **关联**：US-35

## 背景与动机

走查发现 mock 素材两批出图比例混用（item-01~24 为 362×362、item-25~36 为
410×319），是 W1/W3 卡片图片留白/出血不统一的根因；单品底缘带邻物残片 **6 张（视觉实锤：item-03/04/06/16/19/20，
成因=裁剪窗口跨进源图相邻衣物，如 item-19 底部混入整件牛仔夹克领）；effect-commute 脚部贴边 <3%。管线缺校验，问题会随新素材再次混入。

## 用户故事

- **US-35a**：作为开发者，一条命令即可校验素材目录的比例、尺寸一致性、背景
  纯净度与底缘残片风险，新素材入库前拦截脏图。
- **US-35b**：作为开发者，已知问题素材有明确清单与修复指引，不靠记忆维护。

## 验收标准

- `wardrobe/tools/mock-data/validate_assets.py`：
  - 全部 item-*.png 统一宽高比（当前应报 FAIL：两批混用）；
  - 四角背景纯净度（标准差阈值）检测；
  - 底缘残片风险行检测（底部若干行与背景差异异常）；
  - effect-*.png 上下安全边距 ≥5% 检测；
  - `--strict` 模式非零退出可挂 CI/pre-commit。
- 已知问题清单（6 张残片、item-25~36 比例、effect-commute 边距）在脚本输出中
  明确点名；启发式误判由 KNOWN_DEBRIS 视觉实锤优先级兜底。
- 脚本对当前素材实际跑通并产出报告（默认模式 exit 0，仅告警）。

## 影响范围

仅 `wardrobe/tools/mock-data/`（新增脚本）；**不改动素材二进制**——素材归属
并行会话 it-032 的未提交资产，重出/规范化待其合入后单独执行（避免跨会话踩踏）。
