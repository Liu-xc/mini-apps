# it-038 · 衣橱强调色与文字对比度

- **状态**：已实现，验收通过
- **来源**：[第三轮走查报告](../../../reports/2026-09-24-wardrobe-ui-audit-r3/衣橱UI第三轮走查报告-2026-09-24.pdf) C3–C4；色阶证据见报告内 fig-contrast
- **关联**：US-38

## 背景与动机

走查测得浅色主题品牌绿 `#429E68` 上的白字只有约 3.1–3.3:1，低于仓库 `DESIGN.md` §2.2 的 4.5:1 要求，影响复制长图、打卡、随机、价格等按钮/文字。角色「使用中」、名称条计数、演示标识等弱化文字也有组合低于对应阈值。品牌绿同时承担纯图形强调和文字/实心按钮底色，单一颜色难以在所有用途下兼顾可读性与现有视觉。

本轮按当前 token 复算：白字 / `#429E68` 为 `3.32:1`；`#429E68` / `#DDF0E4` 为 `2.79:1`；仓内深绿 `#1D6845` / 白字为 `6.73:1`。

## 用户故事

- **US-38**：作为用户，我在浅色和深色模式下都能读清主操作文字、状态说明和计数，不必猜测浅色字或低对比辅助字的含义。

## 验收标准

- 将强调色拆分为有明确用途的语义 token：装饰/图形强调可继续使用品牌绿；小字号文字与实心按钮使用满足对比度的前景/填充配对。浅色方案可复用仓内已有深绿 `#1D6845`，但具体映射以复算后的对比度结果为准。
- 所有白字实心按钮与状态文字背景组合 ≥4.5:1；普通正文 ≥4.5:1；次级文字/计数与其实际表面组合至少符合 `DESIGN.md` §2.2 的 3:1 要求。禁用态仍可降级，但文字保持可辨。
- 覆盖 W1/W2/W3/W6/W7/W9/W10 与 `WardrobeRecapLongImage` 中的主题色使用点；深色继续保持墨绿纸同构，不引入纯黑底/纯白字。
- 保持品牌绿在纯图形、选中轮廓和装饰块上的既有编辑风表达；不要通过降低文字透明度掩盖对比度问题。
- 更新 `05-design-system.md`、必要的 `02-wireframes.md` 色彩说明及 `01-user-stories.md`；新增决策若形成不可逆 token 语义，补记 `06-decisions.md`。
- 浅色/深色实际配色复算并截图核对：每个受影响文字/底色组合均记录前景、背景和对比度；构建与单元测试通过。

## 影响范围

`ui/theme/DesignTokens.kt` · `ui/theme/WardrobeTheme.kt` · `ui/recap/WardrobeRecapLongImage.kt` · 全局 CTA、选中态及状态文字使用点 · `specs/01-user-stories.md` · `specs/05-design-system.md` · 可能的 ADR。
