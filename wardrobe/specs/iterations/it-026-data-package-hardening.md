## 验收标准

1. 选中「替换全部」后：胶囊出现、该单选行红底红字红描边、确认按钮变「替换…」且红色；切回合并全部还原。
2. 替换摘要与二次确认文案中的删除/导入两侧均含图片数，且数字与本地/包内实际引用图片数一致。
3. 二次确认对话框内点「先导出一份当前数据（推荐）」直接打开系统保存对话框；保存完成后回到确认对话框可继续替换。
4. 合并态差异行三个符号分别呈绿/琥珀/灰；错误弹窗 ✗ 红色、✓ 绿色。
5. 既有流程行为不变：合并/替换/预检/直达导入等 it-024 验收项不回归。
6. 单测全绿；模拟器实走截图留档于走查报告目录。
