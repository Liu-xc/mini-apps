# it-074 · 导出省略人台占位与人物参考素材

状态：已实施（2026-09-30）

## 背景与用户故事

用户反馈 W6 长图带黑色人台会干扰真人穿搭生图，要求无人物形象时不要放人台，并生成白色打底全身模特图。属于 US-07/US-16 的导出错误修复，按 bugfix 流程直接实施。

## 修法与影响范围

- 演示种子移除 `person-ref.png` 默认引用，解析旧演示 JSON 时清除此占位引用。
- 导出面板与合成器统一排除已知人台占位文件；无参考图不出现开关、形象还原提示或参考图区。
- 用户主动选择的其他人物照片保持正常导出。生成男女成年模特各一张，正面全身、白 T 恤/白长裤/白鞋，供用户主动设置参考。
- 代码涉及 mock 数据、W6、长图合成器；同步 US-16 与 W6 规格。

## 验收标准

1. 演示模式初始角色无参考照，旧人台引用也不能进入导出长图或提示词。
2. 无参考照时仅输出提示词与单品拼贴，不保留人物区域空位。
3. 用户上传真人参考照时仍可开关并正常附图。
4. 构建与单测通过；生成素材保存于 `wardrobe/docs/model-references/`。

## 验证记录

- `./gradlew :app:testDebugUnitTest :app:assembleDebug` 通过；新增回归验证无参考/旧人台引用被忽略、正常上传引用保留、旧演示 JSON 清理占位。
- 修改内置 JSON 后 `assembleDebug` 再次通过，最新版安装到 `wardrobe_test` 并重启。
- W6 实测长图预览 = 提示词 → 帽子 → 上身 → 下装/配件 → 鞋；无黑色人台、无人物标注、无五官身形还原要求。截图：[export-without-mannequin.png](../../reports/2026-09-30-it074/export-without-mannequin.png)。
- 内置 imagegen 生成男女虚构成年模特各一张；全身正面、头脚完整、白色基础服装，已逐张视觉检查并保存到 `docs/model-references/`。提示词与使用方法见该目录 README。
