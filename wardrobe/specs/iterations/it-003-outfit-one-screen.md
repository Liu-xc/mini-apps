# it-003 · 搭配页改版：一套穿搭一屏展示（3×3 紧凑网格）

- **状态**：已完成（QA 模拟器验证通过）
- **提案日期**：2026-09-20
- **完成日期**：2026-09-20
- **来源**：用户真机反馈（2026-09-20）——「预期一套穿搭应该在一屏里展示，现在放上图片之后都会出现滚动的效果」

## 背景与动机

it-001 的 W1 搭配页把 8 个品类槽位做成纵向大卡片流（每卡宽幅 4:5 大图）。空数据时观感尚可，装入真实照片后每个槽位占屏过高，一套穿搭需要滚动多屏才能看全——**违背「滑动组合、一眼看全一套」的核心体验**。

## 方案

### 布局：3 列 × 3 行固定网格（一屏）
- 8 个品类格 + 第 9 格「＋ 添加衣物」，网格居中占据主区域；顶部角色/🎲 与底部复制栏不动，**整页无滚动**
- 每格：品类徽标（左上半透明）+ 序号 n/m（右上）+ 照片卡（宽高比 4:5，圆角 12dp）+ 当前单品名（图下一行）
- **滑动换衣保留**：每格内是独立 HorizontalPager，横滑换该品类衣物；迷你尺寸下取消两侧缩放形变（保留吸附、随机连滚）
- 空品类格：浅底占位 + ＋，点击直达添加表单
- 点卡片 → 衣物详情（共享元素保留）
- 网格整体在屏内垂直居中；若极小屏设备放不下则允许滚动兜底

### 不变的部分
🎲 老虎机随机、组合记忆、底部「复制长图」入口、导出面板、点格看详情——逻辑全部沿用。

## 验收标准

- Given 8 品类均有衣物，When 打开搭配页，Then 全部 8 格 + 添加格在一屏内可见、无滚动条
- 格内左右滑动换衣，序号/单品名/组合记忆/随机正常
- 空品类格显示占位并可跳转添加
- QA 模拟器（含真实导入照片）截图 + UI dump 逐项核对
