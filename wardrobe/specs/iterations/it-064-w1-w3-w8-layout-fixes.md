# it-064 · W1 一屏鞋槽 / W8 卡组溢出丝滑 / W3 底部与筛选遮挡 四修

> 状态：**已完成**（2026-09-29，Leo 真机 it-061 包验收反馈）
> 来源：①「鞋子还是只展示一半，要往上滚一下才能全，上面留白过多」；②「穿搭卡片会贴屏幕边、遮挡上面筛选 tag，切换不丝滑应该有 bug」；③「衣橱页 FAB 下还有一段米色空白遮挡，屏幕利用率不高」；④「筛选器旁边默认有一段白色遮挡」。

## 诊断

1. **W1 鞋槽出屏**：四区+间距总高超出内容视口 ~60dp（it-061 鞋格 2.2 增高后），鞋槽初始被视口裁半——需压缩垂直预算让四区一屏放下。
2. **W8 卡组**：
   - 「切换不丝滑」= **it-061 引入的回归**——W8 hero 挂了 `sharedPhoto`，卡组高频切换时 SharedTransition 的 bounds 跟踪参与每次卡的进出组合，与甩卡飞行动画互相干扰。撤销 W8/W7 两端接线（W1/W3→W5 保留，低频导航场景无此问题）。
   - 「贴边/遮挡筛选 tag」：卡组容器**不能裁剪**（it-048：甩卡真实飞行需溢出空间），飞行轨迹向上越过容器盖住筛选行、向侧贴近屏边——容器与筛选行间留缓冲（top 14→20dp）、卡组高度微收（380→368dp）。
3. **W3 米色空白**：网格 `contentPadding bottom=96dp`（it-063 为 FAB 避让）在滚动尾形成全宽空白带；FAB 只占右下角，全宽 96 过度——收到 76dp（FAB 56+16+4 余量）。
4. **W3 筛选旁白遮挡**：`FadingScrollRow` 渐隐带默认（未滚动、内容超宽）即显示，44dp 宽带在「筛选」钮左侧形成一段底色遮挡——改为**滚动离开起点后才显示**（value>0），起点与尽头都隐去。

## 方案

- W1：分区 Spacer 8→6dp、内容列 top 16→12dp、aspect 微调（帽 1.0→1.03、上身 0.78→0.80、下装 0.6→0.63、鞋 2.2→2.3），合计压缩 ~32dp；以 dump 实测鞋槽底 vs 导航顶校验，不足再补。
- W8：撤销 W8 hero/W7 轮播两端 `sharedPhoto`（it-061 修2 的该路径接线移除，恢复整页转场）；卡组容器 top 14→20dp、height 380→368dp。
- W3：网格 bottom 96→76dp；`FadingScrollRow` 的 fadeActive 加 `value > 0` 条件（默认起点不渲染渐隐带）。

## 验收标准

- W1 默认视口内鞋槽完整可见（dump：鞋槽底 ≤ 导航顶），不需初始滚动。
- W8 静止与甩卡时卡片不再越过筛选行区域（缓冲带内），切换流畅无跳变。
- W3 滚到底末卡紧贴 FAB 上缘不再有大段空白；筛选行默认状态无渐隐遮挡、滑动中正常提示。
- `./gradlew :app:testDebugUnitTest :app:assembleDebug` 全绿。

## 实施记录

- **修 1（W1 一屏）**：`OutfitScreen.kt`——内容列 top 16→12dp、分区 Spacer 8→6dp×3、aspect 四档微收（帽 1.0→1.03 / 上身 0.78→0.80 / 下装 0.6→0.63 / 鞋 2.3），垂直预算压缩 ~32dp。
- **修 2a（W8 丝滑回归）**：撤销 it-058 C2 给 W8 hero / W7 轮播挂的 `sharedPhoto`（两端恢复整页转场）——卡组高频切换（甩卡飞行 + 卡片进出组合）与 SharedTransition bounds 跟踪互相干扰，即 Leo 反馈「切换不丝滑」的根因；W1/W3→W5 的共享元素保留（低频导航无此问题）。
- **修 2b（W8 贴边/遮挡）**：卡组容器 top 14→20dp（与筛选行的飞行溢出缓冲）、height 380→368dp（补偿增量整页不涨）。
