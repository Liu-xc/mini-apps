# it-072 · 品类清单直选的可发现性升级

- 状态：**已确认**（2026-09-30；Leo 会话内三选项全选：名称条整条可点 + 清单图标 + 长按开清单）
- 提出日期：2026-09-30
- 涉及应用：wardrobe

## 背景与动机

it-061 修2 已在 W1 槽位落地「品类清单直选」——点名称条 `n/m` 序号弹出该品类全部衣物的 BottomSheet（缩略图+名称+当前件高亮+愿望件标），点选 `scrollToPage` 直达。但 2026-09-30 Leo 反馈「搭配页单品没有交互能进入列表页」——**功能在而入口不可见**：触发区只是名称条上一小段数字文本，没有任何视觉暗示。这属于可发现性缺陷，不是新功能。

## 涉及的用户故事

- **US-39 修订**（窄槽全名可见兜底）：长按照片区的兜底路径从「toast 读全名」改为「打开品类清单」——清单内名称完整呈现（两行，超长省略），是全名可见的超集；a11y contentDescription 完整名称不回退。
- **it-061 修2 条款扩展**：清单入口从 `n/m` 单点扩展为三通道（名称条整条 / 长按 / n/m 原位），其余语义不变。

## 提案内容（W1 槽位 · SlotGrid.kt SlotCell）

1. **名称条整条可点**（items>1 时）：底部名称条 Row 整条点击打开品类清单；点照片仍进 W5 详情、✕ 触控覆盖层（28×44dp，it-033）在最上层不受影响。items==1 时名称条不挂 clickable——点击继续穿透进详情（单件无清单可开，不给假入口）。
2. **名称条加清单图标**：`n/m` 前加 GridView 小图标（14dp、白、随名称条），组成「⊞ n/m」视觉组——名称条有列表入口的显性暗示。名称列让位优先级不变（缩字号>省略，it-033/039）；items==1 时不渲染图标（只留 1/1 计数）。
3. **长按开清单**：照片区 `onLongClick` 从 toast 全名改为打开品类清单（`onLongClickLabel = "打开品类清单"`）；`SlotCell.onLongPress` 参数随之移除（唯一调用方 W1 同步）。清单项名称 `maxLines 1→2`，承载全名可见兜底（原 US-39 的 toast 路径废止）。
4. a11y：名称条 clickable 挂 `onClickLabel`/contentDescription「打开品类清单」；`n/m` 既有语义更新为实际行为。

不改动：清单本体形制（it-061：52dp 缩略图+当前项高亮+愿望副行）、老虎机随机、组合记忆、coach 动画、W7 BodyCollage、✕ 移除语义。

## 验收标准

1. 名称条任意位置（名称/序号/图标）点击 → 弹品类清单；点选直达、序号同步、愿望件带「想买」标（it-061 全部回归）。
2. 长按照片区 → 弹同一清单（不再 toast）；清单内当前件全名两行完整可见。
3. 点照片进 W5 详情、✕ 移除、格内左右滑、老虎机、混入心愿——全部不回退。
4. 单件槽位：名称条点击进详情（无假入口）、不渲染清单图标。
5. 窄格（包/配饰 ≈100dp）名称仍单行可读（省略兜底），图标不挤爆布局。
6. 构建/单测全绿；AVD 走查截图回填本文件。
