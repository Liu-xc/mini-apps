## 用户故事

### US-43 新三面 P1 呈现收口（W5/W12/W11）
作为用户，我在新页面上看到的主次、状态与文案与应用其余部分同一套语言，且关键状态不会因重进页面而丢失。
- **UC**：W5；W12；W11
- Given W5 原图态，Then「去背景」为实心高对比主按钮（唯一主动作），颜色/材质描述用主文本色（O1）
- Given W5 候选/已抠状态条，Then 容器加 hairline 边界，与页面底可分辨（O1，报告 C7）
- Given W12 空态，Then 空态块垂直居中、示例为可点 chip 一键提问、标题与占位措辞错开（O2）
- Given W12 会话任意长度，Then 列表底部锚定：最新消息/流式/错误恒贴输入栏上方，无需手动追（O2，报告 C2）
- Given 模型调用历史，Then 工具条折叠为「查了衣橱 · n 次」中文摘要可点展开，不铺 raw 工具名（O3，报告 C3）
- Given 一轮失败，Then 错误以容器化状态条紧贴该轮次呈现，含图标与「重试/知道了」，Key/网络类附「去设置」直达（O3，报告 C4）
- Given 设置页重进，Then 上次自检结果（通过/错误 + 时间）常驻显示（O4，报告 C6）
- Given 关于区，Then 版本行不出现 ADR 编号等内部决策黑话（O4，报告 C3）；「清除 Key」等回退动作用中性弱色与主 CTA 分层（O4，报告 C8）

## 验收标准

1. 构建与单测绿；W5/W12/W11 关键状态模拟器走查（dump 断言 + 截图）。
2. W12：发消息后最新内容贴输入栏（底部锚定）；空态 chip 可点即发；工具条默认折叠可展开；错误条在消息序列内紧贴失败轮次。
3. W11：force-stop 重开后自检状态仍在（含时间）；版本行无「ADR」字样；清除 Key 为中性色。
4. W5：原图态 CTA 为实心填充；描述行为主文本色；候选/已抠状态条有可见边界。
5. specs 同步：01（US-43）、02（交互注记）、CHANGELOG、本文件验证记录。
