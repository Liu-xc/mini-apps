# it-017 · 角色形象参考照——导出素材带上本人照片，生图更还原

- **状态**:已完成（2026-09-20，实现 + UI 走查，验证记录见文末 §8）
- **提案日期**:2026-09-20
- **来源**:Leo 口头需求（「支持上传自己的照片，全身照或头像，导出长图时给生成穿搭的 AI 一个参考，生成更还原的形象。可选功能」）
- **涉及用户故事**:新增 US-16（形象参考照的设置与导出携带）
- **涉及 ADR**:wardrobe ADR-017（单图通道：参考照拼入长图，而非剪贴板/分享多图）
- **备注**:编号顺延——it-016 与 US-15 已被并行提案 it-016-cutout-sdk（录入去背景）占用，两者无依赖冲突

## 1. 背景与动机

现在导出给生图 Agent 的素材 = 单品拼图 + 文案，生成的真人形象（脸、身形、发型）
完全由 AI 自由发挥，效果图「不像本人」。用户手机里本来就有自己的照片——
可能是全身照、也可能只是头像——传一张给 AI 做形象参考，五官身形的还原度会大幅提升。

**可选功能**：不设置照片时，导出链路与现状完全一致，零感知。

## 2. 方案要点

### 2.1 数据（挂在 Person 上，一张可选照片）

- `Person` 新增 `refImageFile: String? = null`（可空 + 默认值，旧 JSON 缺字段反序列化为 null，天然向后兼容；按 store SDK 的 schemaVersion 惯例确认是否需 bump，迁移为 no-op）。
- 照片复用现有 `ImageFileStore` 管线：EXIF 摆正 + 最长边 1440px + WebP 质量 82，落 `images/` 目录。
- **一个槽位，不区分全身照/头像类型**——用户传手里最顺手的一张即可，App 不做裁剪、不做类型校验。文案里提示「全身照效果最佳，头像也可以」。
- 生命周期：换照片删旧文件；删除角色级联物理删除（扩展不变量 4）。
- 备份 zip（wardrobe.json + images/）无需改动，天然覆盖。
- 演示模式（it-015）种子**不带**参考照（保持 null），演示时展示「未设置」空状态。

### 2.2 上传入口：W2 角色编辑对话框

- `PersonEditDialog`（AlertDialog）新增「形象参考照」区：未设置 → 「+ 选择照片」入口；已设置 → 缩略图 + 「更换」+ 「移除」。
- 选图走 Photo Picker，与录入衣物同管线。
- 对话框内容改为可滚动，避免加区后溢出。

### 2.3 导出侧：开关 + 拼入长图 + 文案追加

- ExportSheet 新增「附形象参考照」开关，**仅在该角色已设置照片时显示**。
- 交互预期（Leo 定调）：**照片上传一次，长期有效；每次导出默认使用**。开关状态不持久化——
  本次导出手动关闭仅影响本次，下次打开导出面板仍默认开。与 custom_prompt「记住上次」
  的语义有意区分：文字是资产要保留，参考照的使用偏好合理默认就是「用」。
- 开关开 → 长图**顶部**拼入参考照 + 标注条「本人形象参考 · 五官身形以此为准」，生成文案末尾追加一句：
  「已附本人形象参考照（长图顶部第一张），生成时请保持其五官、发型与身形还原，仅将服装替换为本套穿搭。」
- 开关关 → 长图与文案与现状完全一致。
- 「复制长图 / 分享 / 保存相册」三通道**天然全带**（拼进同一张图）——单图通道兼容性最好，不碰剪贴板多图 / 分享多选的目标 App 兼容坑（ADR-017）。

### 2.4 备选方案（已否决，记录理由）

- **B 分开两张图导出**：豆包等目标 App 对剪贴板多图支持不稳，分享多图需用户手动二次挑选，链路长、易漏。
- **C 只加文案提醒**（「请从相册补传一张本人照片」）：零图片工程但把负担推给用户，每次导出都要手动补传。

### 2.5 明确不做

照片裁剪/质量打分、多张参考照、全身/头像分槽、角色切换层头像替换 emoji、参考照进入合成图网格（只进导出长图）。

## 4. 用户故事与验收标准（US-16）

### US-16 形象参考照（可选）

作为用户，我想给角色设置一张自己的照片，导出时一并给生图 Agent，让生成的穿搭效果图更像本人。

1. Given 角色编辑对话框，When 点「选择照片」从相册选图，Then 图片压缩落盘、对话框内显示缩略图；When 点「移除」，Then 文件物理删除、UI 回到空状态
2. Given 未设置参考照，Then 导出面板与现状完全一致（不出现新开关）
3. Given 已设置参考照且开关开，When 点「复制长图」，Then 长图顶部含参考照与标注条、文案末尾含形象还原要求；「分享」「保存相册」产出同一版本
4. Given 已设置参考照，When 打开导出面板，Then 开关默认为开；When 本次关闭后导出，Then 长图与文案与现状一致；When 下次再打开导出面板，Then 开关恢复默认为开（关闭不跨会话记忆）
5. Given 设置过参考照后杀进程重开，Then 参考照保留且导出开关仍默认为开
6. Given 删除角色，Then 参考照文件连带物理删除；Given 更换照片，Then 旧文件删除不残留
7. Given 旧版本备份 JSON（无 refImageFile 字段），Then 导入后正常加载，参考照视为未设置
