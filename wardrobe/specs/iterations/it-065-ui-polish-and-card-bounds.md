# it-065 · 穿搭卡组边界与全应用 UI 质感收口

状态：**提案中**（2026-09-29）

## 背景与动机

Leo 真机体验与本轮 Android 14 演示包走查发现，上一轮 it-064 虽然处理了部分 W8/W3 几何问题，但仍有几处直接影响完成度的视觉缺陷：

1. W8 穿搭记录卡组的层叠偏移只给了 start 内缩，顶卡仍贴右边界，深层卡从左侧溢出，主卡与筛选条之间的安全感不足。
2. W3 衣橱网格的底缘渐隐会在首屏底部把纸面色重新盖回照片与标签，形成一段米白色遮挡；W4 添加衣物页的吸底保存栏也会让最后一行颜色 chip 只露出半截，滚动前观感像被遮住。
3. W8/W10 的横向标签行在初始位置直接硬切屏边，缺少「右侧还有内容」的轻提示；W3 有固定的「筛选」按钮，因此不能复用同一块渐隐带，否则会在筛选按钮旁制造白色遮挡。
4. W4 表单源码重复渲染「颜色」小节标题；部分页面仍有由历史修复留下的注释/间距不一致，需要一并收口。

## 涉及的用户故事

- **US-03 品类分组浏览**：衣橱网格首屏内容不被装饰性遮挡，筛选入口与横滑品类保持清晰。
- **US-10 浏览穿搭记录**：卡组卡片在屏幕内保持对称安全边距，筛选标签、卡组、计数器和网格之间不互相覆盖。
- **US-01 录入衣物**：表单底部保存栏不影响继续查看和操作最后一组字段，分组标题不重复。

## 验收标准

### W8 穿搭记录

- 顶卡静止状态左右均保留可见安全边距，不贴屏、不出现深层卡从左侧越界。
- 甩卡过程中允许真实飞出，但静止卡组不会盖住筛选条；计数器与下方「全部 N 套」之间保持稳定间距。
- 横向标签在未滚动时用轻渐隐提示右侧仍有内容；滑到尽头时渐隐自动消失。

### W3 衣橱

- 网格照片和颜色/标签文字不再被 `fadingBottomEdge` 的米白渐隐带盖住。
- 末行内容可以自然滚到导航栏上方，FAB 仍保持触控目标与右下角安全距离。
- 品类横滑行初始位置不出现覆盖「筛选」按钮的白色渐隐带；滑动时不遮挡固定筛选入口。

### W4 添加衣物

- 「颜色」小节标题只出现一次。
- 未选图状态下，底部保存栏仍固定可用，但最后一组表单字段滚动到保存栏上方时完整可见，不出现不可恢复的遮挡。

### 全局质量

- 不新增色彩、音效或无意义动效；沿用 wardrobe it-052 的黑白灰 token、it-058 的 EditorialMotion 和触感基线。
- `./gradlew :app:testDebugUnitTest :app:assembleDebug -PdemoDefault=true` 全绿。
- Android 14 演示包重新走查 W1/W3/W4/W8，截图与 UI dump 证明上述边界和遮挡问题消失。

## 实施方案

1. `RecordsScreen.kt`：卡组 modifier 改为左右对称内缩，保留 carddeck 的不裁剪飞出能力；必要时微调卡组高度/外部间距以维持现有首屏节奏。
2. `WardrobeScreen.kt`：移除 W3 网格上的底缘渐隐绘制，改以真实滚动边界和适量 bottom content padding 保证末行可达；品类行使用「仅横滑中显示」的渐隐策略，固定筛选按钮不被覆盖。
3. `ScrollFade.kt`/`Tags.kt`：为横滑渐隐增加落点策略，W8/W10 标签行可在起点提示右侧内容，W3 固定筛选布局关闭起点渐隐。
4. `ItemEditScreen.kt`：删除重复「颜色」标题，给滚动内容补齐吸底保存栏所需的可达空间并复核键盘/导航栏 inset。
5. 同步更新 `specs/05-design-system.md` 的组件行为注记与 `CHANGELOG.md`；若验证中发现跨页面可复用的遮罩底色教训，再按根 `LESSONS.md` 容量规则沉淀一条。
