# it-009 · 衣橱列表品类 Tab 筛选

- **状态**：已完成
- **提案日期**：2026-09-20
- **范围**：W3 衣橱页新增品类 Tab 行（单选筛选），替代纯滚动查找

## 背景与动机

用户反馈：衣橱列表按品类分组纵向排布，想看鞋/裤子要滚动很久；
期望顶部 Tab 直接筛选品类。

## 变更

- 标题下新增**品类 Tab 行**（横滑）：`全部` + 8 品类（FilterChip + 3D 图标 + 文案，单选、再点取消）
- 选中品类时：标题变为「鞋 · Leo」、计数为筛选后件数、列表只显示该品类（平铺，无分组头）
- 「全部」保持原分组视图；品类 Tab 与标签筛选行可叠加生效
- 空筛选结果有空态提示
