## 背景与动机

it-001 的导出把「合成图 + 文本」同时放入剪贴板，用户实际使用中发现体验不符合预期，期望改为：

1. **复制一张长图**即可：按穿搭顺序从上到下把各品类衣物照片拼成一张纵向长图，不再需要剪贴板里同时放图片和 prompt 文本。
2. **Prompt 附着在图片本身**：图片底部绘制完整 prompt 文字，同时写入图片 **EXIF 元数据**（ImageDescription），供支持的生图 Agent 读取。
3. **Prompt 由预设维度选择器（表单式 chips）组装**：分为场景、氛围、季节等多个维度，点选即组句，引导生成结果包含**人物穿搭 + 环境的完整信息**。
4. 保留「只复制文本」「分享」作为辅助通道。

## 方案

### 长图规格（OutfitImageComposer 重构）
- 宽 1024px，白底；按当前选中顺序（品类槽位序）从上到下排列
- 每件单品：品类·名称 标签条 + 等比缩放照片，间距 16px
- 底部 Prompt 区：StaticLayout 自动换行绘制完整 prompt（浅米底、墨字，与正文区隔）
- 输出 JPEG（质量 90），prompt 写入 `ExifInterface.TAG_IMAGE_DESCRIPTION`

### Prompt 维度预设（domain 常量 PromptPresets）
| 维度 | 选项（单选，可不选） |
|---|---|
| 场景 | 城市街头 / 办公室 / 咖啡馆 / 公园 / 海边 / 居家 / 商场 / 校园 |
| 氛围 | 通勤简约 / 休闲随性 / 优雅正式 / 街头潮流 / 温柔知性 / 度假轻松 / 运动活力 |
| 季节 | 早春 / 春 / 夏 / 早秋 / 秋 / 冬 |
| 光线 | 自然日光 / 黄昏暖光 / 夜晚霓虹 / 阴天柔光 / 室内灯光 |
| 构图 | 全身照 / 半身照 / 全身+环境远景 / 街拍视角 |

外加「人物描述」自由文本（一次输入，记住上次，PrefsStore 持久化）——引导生成包含"本人"特征。

### Prompt 模板（BuildOutfitPrompt 重构，策略可替换）
```
请根据这张长图中从上到下排列的服装单品，生成一张真人穿搭效果图。
场景：{场景}；氛围：{氛围}；季节：{季节}；光线：{光线}；构图：{构图}。
人物描述：{人物描述}
单品：上装：白色 牛津纺衬衫；下装：…（文本通道保留单品清单）
要求：画面包含完整的人物穿搭与环境场景信息，保持每件单品的颜色与款式一致，自然真实。
```
未选维度自动省略对应分句；单品清单仅进「只复制文本」通道，长图内不重复（照片+标签已承载）。

### W6 导出面板改版
预览（长图纵向滚动预览）→ 五行维度 chips 选择器 → 人物描述输入 → 实时生成可编辑文案 → [复制长图(主)] [分享] [只复制文本] | [☆收藏] [＋录入成品图]。收藏时穿搭标签 = 已选维度值。

## 验收标准

- Given 组合 ≥1 件，When 点「复制长图」，Then 剪贴板仅含一张纵向长图：按槽位顺序排列的单品照片 + 底部 prompt 文字；按钮变 ✓ + 彩屑
- Given 任选若干维度，Then prompt 文案实时更新且图片底部的文字同步；维度可点选/再点取消
- Given 导出文件，Then EXIF ImageDescription == 完整 prompt
- 人物描述输入后再次打开面板自动回填

**过程中发现并修复的问题**
1. **EXIF 中文必损**：androidx ExifInterface 以 US-ASCII 写文本字段，中文全部变 `?`；且 saveAttributes 重建 EXIF 段时把宽高写成 0，导致 sips 等解析器报尺寸无效。**决策：放弃 EXIF，Prompt 元数据唯一通道改为 XMP**（JpegXmp：APP1 段 UTF-8 XML，dc:description + exif:UserComment 双字段，插入在 APP0/JFIF 之后，标准合规、兼容性已验证）。ADR-007 已同步。
2. ModalBottomSheet 全展开后，adb 从屏幕底部发起的快速滑动会被 sheet 手势拦截——换起点/慢速滑动可正常滚动内层（真机触摸无此问题，adb 注入手势的副作用）。
