# 01 — 用户故事与验收标准

## US-1 常驻胶囊
胶囊**智能避让**菜单栏图标后落位：优先贴刘海右缘（空隙 ≥118pt），其次左缘，都不够则悬浮在
刘海正下方菜单栏之下；紧凑态 118×26pt 纯黑胶囊，三根迷你进度条 = 三档用量（5h 蓝 / 每周绿 / MCP 橙）。
不抢键盘焦点；切空间/全屏 App 仍在（canJoinAllSpaces + fullScreenAuxiliary）。

**AC**：任何菜单栏排布下胶囊都不遮挡状态图标；重启 App 后位置正确；其他 App 前台打字不中断；
全屏 App 下可见；菜单栏图标增减后 ≤30s 自动重算落位。

## US-2 展开详情
hover spring 展开（352×228pt）、移开自动收起、点击固定/取消固定、点击胶囊外收起。
展开面板与控制台一致：档位名 / 剩余% / 进度条 / 重置时间点，页脚「x 前已刷新」+ 刷新/设置按钮。
未配 Key 时首启自动展开引导。

**AC**：三种交互全可用；动画无跳帧残影；数据与控制台同刻 ±1%。

## US-3 自动刷新
默认 5 分钟轮询官方接口（间隔可配 1/2/5/10/15/30）；失败指数退避（2^n，封顶 8×）；
快照落盘，重启/断网先显示陈旧数据；支持手动刷新；401 明示 Key 失效。

**AC**：断网显示陈旧快照 + 失败文案；恢复后下一轮自动刷新成功。

## US-4 状态预警
剩余 ≤20% 该行转橙、=0% 转红显示「已用完 · X 重置」；紧凑迷你条同步变色。

**AC**：阈值状态机单测覆盖（20/1/0 边界）。

## US-5 设置与安全
API Key 只存 Keychain（不入文件/日志）；设置窗口：平台端点（自动/bigmodel.cn/z.ai）、
刷新间隔、演示模式、开机自启（SMAppService）、控制台链接、诊断（原始响应查看/拷贝）。
菜单栏图标：用量摘要 / 立即刷新 / 演示模式 / 设置 / 打开控制台 / 退出。

**AC**：缓存文件与日志中无 Key；自启开关即时生效（.app 形态下）。

## US-6 离线韧性
断网、超时、解析失败均不崩溃；胶囊继续展示；解析宽松降级（字段缺失显示 --%）。

**AC**：malformed JSON / 空 limits / envelope 错误均有单测。
