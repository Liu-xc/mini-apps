# 01 — 用户故事与验收标准

## US-1 默认隐藏 + 刘海触发
默认状态**完全不展示**：窗口即刘海挖槽矩形（180×safeTop，内容全透明），隐形且不与
任何菜单栏图标冲突。鼠标移到刘海 → **动画展开**明细卡片；移开动画收起；点击可固定、
点击外部收起。不抢键盘焦点；切空间/全屏 App 仍在。

**AC**：默认帧=刘海矩形且完全透明；hover 刘海一次展开零振荡（变形补发事件被防抖状态机吸收）；
展开卡片顶边贴屏幕顶沿、顶部两角直角，与刘海/顶边之间无缺角缝隙；其他 App 前台打字不中断。

## US-2 展开卡片
从刘海中心向下生长：顶边贴屏幕顶沿（352×178pt，第三档 other 出现时 222），内容 =
「剩余额度」标题 + 每档明细行（档位名 / 剩余% / 进度条 / 重置时间；**MCP 档不展示**）+
页脚「x 前已刷新」+ 刷新/设置按钮。剩余 ≤20% 转橙、=0% 转红「已用完 · X 重置」。
未配 Key 时首启自动展开引导。

**AC**：三种交互全可用；动画无跳帧残影；数据与控制台同刻 ±1%。

## US-3 自动刷新
默认 5 分钟轮询官方接口（间隔可配 1/2/5/10/15/30）；失败指数退避（2^n，封顶 8×）；
快照落盘，重启/断网先显示陈旧数据；支持手动刷新；401 明示 Key 失效。

**AC**：断网显示陈旧快照 + 失败文案；恢复后下一轮自动刷新成功。

## US-4 状态预警
剩余 ≤20% 该行转橙、=0% 转红显示「已用完 · X 重置」（展开卡片内）。

**AC**：阈值状态机单测覆盖（20/1/0 边界）。

## US-5 设置与安全
API Key 只存 Keychain（不入文件/日志）；设置窗口：平台端点（自动/bigmodel.cn/z.ai）、
刷新间隔、演示模式、开机自启（SMAppService）、控制台链接、诊断（原始响应查看/拷贝）。
菜单栏图标：用量摘要 / 立即刷新 / 演示模式 / 设置 / 打开控制台 / 退出。

**AC**：缓存文件与日志中无 Key；自启开关即时生效（.app 形态下）。

## US-6 离线韧性
断网、超时、解析失败均不崩溃；胶囊继续展示；解析宽松降级（字段缺失显示 --%）。

**AC**：malformed JSON / 空 limits / envelope 错误均有单测。
