- 快照缓存落盘（断网/重启显示陈旧数据）；Key 只进 Keychain；
- 刘海胶囊双态：紧凑 118×26（三迷你条）↔ 展开 352×228（三行明细 + 刷新/设置），
  hover 展开/移开收起/点击固定/点击外收起，spring 动画 + 轻触感；无刘海屏回退顶部居中；
- 状态机：剩余 ≤20% 警戒橙、=0% 红「已用完 · X 重置」；紧凑迷你条同步变色；
- 设置窗口：Key 管理 / 端点 / 间隔 1-30 分钟 / 演示模式 / 开机自启（SMAppService）/ 诊断原始响应；
- 菜单栏图标（三彩条）+ 用量摘要菜单；演示模式（假数据走查 UI，不请求接口）；
- 构建：SPM + CLT（无 Xcode），swift-testing 14 测全绿；`tools/make-app.sh` 打包 ad-hoc .app；
  `tools/spike-usage.sh` 一键抓真实响应；
- 已知限制：系统全屏截图不合成该层窗口（`screencapture -l` 可验，不影响真实显示）；
- 落位修复 v2（Leo 二轮反馈「还差很多 + hover 一直闪」）：避让方案胶囊落在刘海左缘与刘海分离，
  改为**刘海正中锚点**——刘海挖槽天然无冲突，紧凑态融进刘海黑区、展开态贴顶向下生长（ADR-005 定稿）；
  hover 闪烁根因 = 窗口变形动画中窗口服务器补发成对 enter/exit 引发振荡，
  修复 = 假离开守卫（exit 时光标仍在面板内则忽略）+ enter 60ms / exit 180ms 可取消防抖；
  CGEvent 模拟悬停实测：一次展开→稳定→真离开一次收起，零振荡。
- 触感移除（Leo 反馈「不要震动」）：hover 展开不再触发 NSHapticFeedbackManager，动画保留。
- 信息结构调整（Leo 反馈）：**ZCode MCP 档不再展示**（解析/数据保留，displayRows 过滤）；
  紧凑态升级为**两行全信息**（180×36）：每档「标签 + 迷你条 + 百分比 + 重置时间」，
  不展开即可读全量；演示数据每周改为 18% 以展示警戒橙。
- 落位修复 v4（Leo 反馈「默认不该展示、hover 刘海再动画展开、顶部与刘海间有缺角」）：
  **默认完全隐藏**——窗口即刘海挖槽矩形（180×safeTop 全透明），隐形但可收 hover（ADR-006）；
  hover 刘海动画展开 352×178 卡片，**顶边贴屏幕顶沿、顶部两角直角**，与刘海/顶边之间无缺角；
  移开动画收起。CGEvent 实测：隐藏(645,0,180×32) → 一次展开(559,0,352×178) → 移开一次收起，零振荡。
- 动画与 UI 减法（Leo 反馈「动画应从刘海向下延伸而非斜向生长、文字避开刘海、整体太花」）：
  生长动画改为 **SwiftUI 圆角遮罩 reveal**——窗口瞬移就位，遮罩矩形在 刘海尺寸↔卡片全尺寸 间
  spring（**宽高一起**：展开从刘海长出、收起对称吸回；先渲染起始帧再延迟 50ms 触发，ADR-007）；
  卡片内容顶边 = safeTop+6 避开刘海；
  简化：删演示徽章/顶部高光线/冗余提示块，标签改白色、颜色只留进度条，行收敛为
  「标签 + 百分比 · 重置时间 / 进度条」，演示状态并入页脚文案。
- 收起动画修正（Leo 反馈「宽度也应一起缩，现在是先变矮再被藏进刘海」）：遮罩方案天然对称——
  收起时宽高同时缩回刘海尺寸，中间帧为对称缩小的小黑卡；窗口在动画结束后才瞬移归隐。
