## 交互路径

| 触发 | 行为 |
|---|---|
| 鼠标进入胶囊 | hover 展开（spring 0.36/0.85 + 轻触感 alignment） |
| 鼠标移出（未固定） | 收起 |
| 点击胶囊 | 固定展开 / 取消固定并收起 |
| 点击胶囊外（固定时） | 取消固定并收起 |
| ⟳ | 手动刷新（旋转指示） |
| ⚙ | 打开设置窗口（激活 App） |
| 菜单栏图标 | 用量摘要 / 刷新 / 演示模式 / 设置 / 控制台 / 退出 |
| 首启未配 Key | 自动展开 + 「去设置」引导 |
| 屏幕参数变化 | 重新定位（贴新屏刘海） |
